Action Understanding with Multiple Classes of Actors

2017-04-28 · 原文 · 翻译 · 1704.08723

论文要解决的是“动作主体默认等于成人”的狭窄设定：在同一框架中同时理解多类 actor 与其 action，并覆盖视频级单/多标签识别和像素级时空分割。 面向 YouTube 野外视频中的成人、婴儿、动物、球和车辆等多主体动作理解；论文以自动驾驶必须区分冲入道路的儿童、鹿与松鼠来说明 actor 类别会直接影响后续避让。 核心检验是：显式联合建模 actor 与 action 是否优于彼此独立建模，以及能否把较可靠的视频级识别响应作为 label costs，改善更难的像素级分割。 研究背景：论文把全面动作理解界定为同时理解 action、执行它的 agent 及 agent movement；这种细粒度语义既服务大规模视频语义索引，也服务需要据主体类别做决策的自动驾驶。 核心痛点：既有工作通常把 actor 固定为成人，并把 action recognition 简化为封闭类别中的预裁剪片段分类；独立预测 actor 与 action 还可能组合出数据集中无效的 adult-flying。 任务定义：输入视频 V 可表示为空间—时间体素格，也可表示为 supervoxel 图 G=(V,E)。输出随粒度变化：单标签时 x、y 是 actor/action 标量，多标签时是二值存在向量，分割时则为每个体素或 supervoxel 赋 actor 与 action 标签。 研究目标：研究目标依次是形式化多 actor—多 action 理解并覆盖多种粒度，检验联合建模是否优于独立建模，以及用多尺度信息把视频级识别与像素级分割连接起来。

Card 02 论文概述

论文概述

  • 论文要解决的是“动作主体默认等于成人”的狭窄设定：在同一框架中同时理解多类 actor 与其 action，并覆盖视频级单/多标签识别和像素级时空分割。
  • 面向 YouTube 野外视频中的成人、婴儿、动物、球和车辆等多主体动作理解；论文以自动驾驶必须区分冲入道路的儿童、鹿与松鼠来说明 actor 类别会直接影响后续避让。
  • 核心检验是：显式联合建模 actor 与 action 是否优于彼此独立建模，以及能否把较可靠的视频级识别响应作为 label costs，改善更难的像素级分割。
  • 研究背景：论文把全面动作理解界定为同时理解 action、执行它的 agent 及 agent movement；这种细粒度语义既服务大规模视频语义索引，也服务需要据主体类别做决策的自动驾驶。
  • 核心痛点：既有工作通常把 actor 固定为成人，并把 action recognition 简化为封闭类别中的预裁剪片段分类；独立预测 actor 与 action 还可能组合出数据集中无效的 adult-flying。
  • 任务定义：输入视频 V 可表示为空间—时间体素格，也可表示为 supervoxel 图 G=(V,E)。输出随粒度变化：单标签时 x、y 是 actor/action 标量，多标签时是二值存在向量，分割时则为每个体素或 supervoxel 赋 actor 与 action 标签。
  • 研究目标：研究目标依次是形式化多 actor—多 action 理解并覆盖多种粒度，检验联合建模是否优于独立建模，以及用多尺度信息把视频级识别与像素级分割连接起来。
Card 03 核心贡献

核心贡献

  • 构建 A2D v2：包含 3782 个短视频和 31 个未裁剪长视频，并在七类 actor、九个含 none 的 action 标签下形成 43 个有效 actor-action tuples。
  • 把同一 actor-action 问题实例化为视频级单标签识别、视频级多标签识别与像素级时空分割，使不同输出粒度可在统一问题定义下比较。
  • 系统比较独立 Naïve Bayes、JointPS、Bilayer、Conditional 与 Trilayer 图模型；Trilayer 同时保留 actor、action、联合乘积空间及条件关系。
  • 把分割图模型重写为满足子模条件的多标签 graph-cut 形式；论文称新的推理方案相较会议版快 10 倍。
  • 把视频级 actor-action 识别响应变成分割的 label costs，以全局标签使用代价引导较难的像素级推理。
  • 为未裁剪长视频定义 actor-action track 的时间覆盖召回，并在 727 条 track（validation 128、testing 599）上评估动作持续与切换。
Card 04 方法描述

方法描述

  • 所属模块：方法按层次组织职责：视频识别端比较 actor/action 独立分类、JointPS 联合乘积空间与融合二者的 Trilayer；像素分割端比较 unary、邻接 pairwise 与完整 label-cost 三个阶段，并由视频级识别为全局标签使用提供代价。
  • 输入与表示：视频 V 由 n 个体素构成空间—时间格，或由 n 个 supervoxels 构成图 G=(V,E)。actor 标签集 X 为 adult、baby、ball、bird、car、cat、dog；action 标签集 Y 为 climbing、crawling、eating、flying、jumping、rolling、running、walking、none。单标签用标量，多标签用存在向量，分割用逐节点随机变量。
  • 模型结构：Naïve Bayes 用两个 flat CRF 分别建模 actor 与 action；JointPS 把 z 放在 Z=X×Y 的单层 CRF 中；Bilayer 在每个位置连接 actor 节点 x 与 action 节点 y；Trilayer 再加入联合节点 z 和两组条件势 μ、ν，使独立空间、乘积空间与 actor-conditioned/action-conditioned 关系共同进入 P(x,y,z|V)。
  • 数据流：先用 TSP 把视频切成 supervoxels（k=400，约 400 个 supervoxels 接触每帧），在向外扩 10 pixels 的体积上统计 texton、dense SIFT、RGB/HSV、dense optical flow，并注入 dense trajectories；随后用 one-versus-all linear SVM 产生 actor、action、联合及条件 unary，叠加相邻节点 pairwise 势；完整短视频模型再加入视频级识别 label costs，最后以 graph cut 推理并回填为稠密时空体素标签。
  • 关键技术：关键机制有三类：以 contrast-sensitive Potts 势按邻接 supervoxel 特征差异平滑标签；为同一 action 针对不同 actor 训练条件分类器以捕获 tuple 特有外观；把重写后的子模 pairwise 能量交给 alpha-expansion 或 alpha-beta-swap graph cuts，并用识别分数控制 label cost，而不是均匀惩罚所有标签。
  • 公式与超参数：总目标为 (x*,y*)=arg max P(x,y|V)。异标签的 Potts 势为 exp[-θ/(1+χ²_ij)]，θ由训练数据学习。分割使用 TSP 的 k=400，特征体积向外扩 10 pixels；识别 SVM 使用 LIBSVM 的 RBF-χ² kernel，分割与条件分类器使用 linear kernels，图模型参数通过 empirical search 调节。
Card 05 数据集与资源

数据集与资源

  • 数据集：A2D v2 短视频集：来自 YouTube 的 3782 个视频，覆盖 43 个有效 actor-action tuples。
  • 数据集：A2D v2 长视频扩展：31 个未裁剪视频，actor 可在时间上切换动作，并以跟踪框和时间稠密动作标签标注。
  • 规模与划分：短视频平均 136 帧（24–332），划分为 3036 个 training 与 746 个 testing，并从每段选三至五帧，共 11936 个像素级标注帧；长视频平均 1888 帧（593–3605），划分为 8 个 validation 与 23 个 testing，31 段合计超过 58K 帧。长视频共 727 条 track，其中 128 条用于 validation、599 条用于 testing。
  • 模型：实验栈由 dense trajectory 特征、TSP supervoxels、one-versus-all SVM、CRF 与 graph-cut 推理构成；全文方法和实验未报告预训练基础模型名称、版本或参数量，deep representations 只被列为未来工作。
  • 硬件：通读短视频实验设置、长视频实验设置、结论、脚注与文末后，正文仍未报告训练或推理 CPU/GPU 型号、设备数量、内存或计算节点配置。
  • 代码：论文声明已发布完整数据集、预计算特征、codebase 与 evaluation regimen，地址为 http://www.cs.rochester.edu/~cxu22/a2d/；顶层 code_url 仍按目录元数据原样保留为空。
  • 训练平台：视频采集平台是 YouTube；短视频标注由 MTurk 配合 LabelMe 完成并人工过滤，长视频 actor 轨迹由 VATIC bounding boxes 标注，动作在时间上稠密标注。
Card 06 评估与结果

评估与结果

  • 评估基准：A2D v2 短视频：评测单标签识别、多标签检索式识别和像素级 actor-action segmentation。
  • 评估基准：A2D v2 的 31 个未裁剪长视频：只评估分割在动作持续与切换上的时间覆盖，不评价精确空间重叠。
  • 评估指标：单标签识别使用 classification accuracy（越高越好）；多标签识别按 retrieval 口径使用 mAP（越高越好）。
  • 评估指标：短视频分割使用 average per-class segmentation accuracy（百分比，越高越好），并且只在有 ground-truth 的稀疏标注帧上计分。
  • 评估指标：长视频使用 track recall Recall(σ)：逐帧只要正确标签分割与轨迹框有任意空间重叠即计覆盖，σ 从 0 到 1、步长 0.1；指标越高越好，但不衡量空间重叠质量。
  • 对比方法：识别主表比较 Naïve Bayes、JointPS 与 Trilayer。
  • 对比方法：分割主表比较 Naïve Bayes、JointPS、Conditional、Bilayer 与 Trilayer，并分 unary、+pairwise、+label costs 三个设置。
  • 对比方法：额外分割强基线为 robust P-N model 与 fully-connected CRF，后者使用相同 supervoxels 和特征并基于 JointPS unaries 实现。
  • 关键结果：联合 actor-action 识别中，Trilayer 的单标签 accuracy 表值为 64.88，高于 Naïve Bayes 的 56.17；多标签 mAP 表值为 66.86，高于 60.13（均按百分数刻度报告，越高越好）。
  • 关键结果：完整 +label costs 分割中，Trilayer 的联合 average per-class accuracy 表值为 30.53，高于 Naïve Bayes 的 22.00（按百分数刻度报告，越高越好）。
  • 关键结果：强 CRF 基线上，robust P-N 的联合 average per-class accuracy 为 13.7%，fully-connected CRF 为 25.4%（越高越好）。
  • 关键结果：长视频 track recall 中，Trilayer 在 σ=0 时为 45%，在要求整条轨迹逐帧都有正确 segment 的 σ=1 时仍约为 10%（越高越好）。
  • 消融实验：Trilayer 的联合分割 accuracy 表值从 unary 22.59 提升到 +pairwise 26.46，加入 label costs 后达到 30.53（按百分数刻度报告，越高越好）。
  • 消融实验：Bilayer 的联合分割 accuracy 表值从 16.35 提升到 23.43，再到 27.89（按百分数刻度报告，越高越好），显示 actor-action 边与 label costs 的逐步收益。
  • 消融实验：阶段性可视化显示 label costs 可纠正部分错误分割，但论文也明确指出视频级识别预测差时会把错误传入像素级分割。
  • 实验条件：短视频遵循既定 training/testing split；单标签真值取自用于 YouTube 检索与选片的 query，分割只在有 ground-truth 的稀疏标注帧上评分。长视频不使用视频级识别或 label costs，unary classifiers 由短视频 training set 训练，图模型参数在长视频 validation set 上经验调节。
