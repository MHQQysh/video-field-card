ProcessPainter: Learn Painting Process from Sequence Data

2024-06-10 · 原文 · 翻译 · 2406.06062

这篇论文解决的不是“把一张图逐步去噪出来”，而是生成可被人理解的绘画过程：从空白或粗略色块出发，按画家的构图与细化顺序逐帧走向成画。作者指出，笔触渲染通常只优化与目标图的像素差，扩散模型的去噪轨迹也不是画家从抽象到具体的创作轨迹，因此二者都难以直接成为真实的教学过程。 它覆盖三种具体使用方式：给文字生成一段绘画过程；把现成作品放在序列末帧位置，反推出从空白到该作品的关键帧；把半成品放在较早的指定帧，再依据文字继续完成。后两种方式都由 Artwork Replication Network 把参考图绑定到任意时间位置，位置越靠前，可补全的幅度越大。 论文真正检验的问题是：在真实画家过程数据稀缺时，能否先用合成笔触序列学到通用的时序绘画先验，再用少量画家序列的空间/时间 LoRA 学到个人风格与作画策略，并通过任意帧条件和噪声替换兼顾过程自然度与参考图重建一致性。作者分别用重建误差、视觉消融和人类偏好研究回答这一问题。 研究背景：绘画是一条从抽象到具体、从宏观构图到局部细节的逐步实例化过程；这种过程既能形成可观察的“怎么画”教程，也能服务艺术教育、创作分析和半成品辅导。论文因此把绘画关键帧视为一种特殊视频，而不是把扩散去噪中间态当作作画步骤。 核心痛点：传统 stroke-based rendering 多以缩小当前画布与目标图的差异为目标，能排笔触，却没有从真实画家的过程关键帧中学习不同题材、画种与个人策略；普通文本到图像扩散的迭代去噪在 VAE 解码后只是模糊中间图，也不符合人类作画顺序。真实网络绘画视频又常被手部遮挡、视角变化和缩放污染，难以直接作为稳定时序训练数据。 任务定义：输入与输出分成三类：Text2Painting 从文字直接输出从粗到细的绘画序列；Image2Painting 将任意参考作品约束为序列的最终帧，输出从空白到该作品的过程关键帧；Semi2Complete 将半成品约束在序列中前部，并结合文字输出其后续完成过程。 研究目标：目标是建立一个可插拔的时序扩散框架：通用 Painting Model 先从可规模化合成的绘画序列获得跨帧先验，Painting LoRA 再用少量真人过程分离学习最终视觉风格与作画时序策略，Artwork Replication Network 则把任意参考帧的约束传播到整个序列，从而同时提供无参考生成与可控复制/续画。

Card 03 核心贡献

核心贡献

  • 首次把文本到绘画过程明确建模为视频生成：输出不是扩散去噪可视化，而是从抽象轮廓、色块到最终细节的时间有序绘画关键帧。
  • 提出“合成序列预训练 + 画家少样本 Painting LoRA”路线，并把 LoRA 拆成最终帧训练的 Spatial-Attention LoRA 与完整序列训练的 Temporal-Attention LoRA，以分别吸收成画风格和过程策略。
  • 提出可接收任意帧参考图的 Artwork Replication Network：把作品指定为末帧即可重建其绘画过程，把半成品指定为前部帧即可续画，并通过 DDIM inversion 与指定帧噪声替换增强参考一致性。
Card 04 方法描述

方法描述

  • 所属模块：Painting Model 负责文字条件下的通用绘画过程先验；插入 UNet 各扩散层后的 Temporal-Attention 负责让当前帧利用其他帧信息；Painting LoRA 以低秩增量适配单个画家的静态风格与时序策略；Artwork Replication Network 是带时间注意力的 ControlNet 变体，把指定参考帧的信息逐层加到冻结的去噪 UNet 上。
  • 输入与表示：主干接收文字提示和带噪潜变量序列。每个空间位置把特征沿时间轴重排为长度 f 的序列 z={z1,…,zf}，其中每帧向量维度为 (b×h×w)×c，再做跨帧自注意力。参考图先由 VAE encoder 编为潜变量 li；系统初始化标准高斯噪声，并在目标时间位置 τ 用 li 替换对应噪声，从而明确哪一帧必须匹配参考图。训练与推理默认序列含 8 帧、分辨率为 512×512。
  • 模型结构：整体由冻结的预训练 Stable Diffusion（VAE 与 UNet）、追加到 UNet 各层的 AnimateDiff Temporal-Attention、可挂载的 Spatial/Temporal Painting LoRA，以及并联的 Artwork Replication Network 构成。后者在每个 Spatial-Attention 后也加入 Temporal-Attention，其第 n 层特征以加法方式注入去噪 UNet，因此可以在纯文字生成时完全不启用，也可切换不同 Painting Model/LoRA 控制作画策略。
  • 数据流：训练分三段：先用合成绘画序列预训练时间模块；冻结 Painting Model 后训练 Artwork Replication Network，让随机抽取的参考帧约束同一序列；最后针对每位画家，先仅用末帧训练 Spatial-Attention LoRA，冻结它后再用完整序列训练 Temporal-Attention LoRA。推理时，纯文字任务只走 Painting Model；参考图任务先做 DDIM inversion 得到参考图初始噪声、替换指定 τ 帧的噪声，再由参考网络逐层向主 UNet 注入条件并迭代生成整段序列。
  • 关键技术：合成数据先从 DiffusionDB 按审美分筛图，再分别用 Learn-to-Paint、Stylized Neural Painting、Paint Transformer 生成笔触序列，并用 Segment Anything 与 Depth Anything 按深度从近到远把分区加入空画布，补充“逐对象绘制”的策略；对 SBR 后期变化很小的问题采用非均匀帧采样。真实画家数据则在 caption 中加入触发词 sks，并为每位画家单独训练 LoRA；LoRA 优化器使用 Prodigy。
  • 公式与超参数：时间注意力为 Softmax(QK^T/√c)V，Q=WQz、K=WKz、V=WVz，因而每个当前帧可聚合其他帧；LoRA 将冻结权重改写为 W'=W+AB^T，A∈R^(m×r)、B∈R^(n×r)，只在注意力层训练秩 r 的残差；参考网络按 Ŝu_n=Su_n+λARN_n 注入，其中 λ 控制参考影响强度。实验学习率为 2×10^-5、batch size 为 1；预训练与正式训练各 50,000 steps；DDIM sampling 和 inversion 推理各运行 50 steps。
Card 05 数据集与资源

数据集与资源

  • 数据集：合成部分从 DiffusionDB 依审美分选 10,000 张静态图，经三种 SBR 方法转换为序列；方法正文最终表述为 30,000 条合成绘画序列。
  • 数据集：另用 Segment Anything 与 Depth Anything 生成按前景到背景逐分区显现的合成过程。
  • 数据集：真人部分共收集 95 条绘画序列，来自三位画家，覆盖厚涂肖像、风景速写和线稿上色；每位画家训练独立 Painting LoRA。
  • 规模与划分：每条训练序列固定 8 帧、512×512。实验设置写明预训练实际使用 30,000 条视频序列训练 50,000 steps，随后 Artwork Replication Network 再训练 50,000 steps；参考帧每次抽取 0–3 帧，首帧与末帧各以三分之一概率采样，中间帧按中心峰值正态分布采样。论文没有给出独立训练/验证/测试划分。需注意数据构建小节和实验设置小节均写 30,000，而总览图注写“40,000 synthetic data points”，文内存在口径不一致。
  • 模型：基础生成器是冻结 VAE/UNet 的预训练 Stable Diffusion，时间模块取自 AnimateDiff；个性化使用 attention-only LoRA，参考控制采用带 Temporal-Attention 的 ControlNet 变体。合成数据还调用 Learn-to-Paint、Stylized Neural Painting、Paint Transformer、Segment Anything 与 Depth Anything；LoRA 训练采用 Prodigy 优化器。论文未给出 Stable Diffusion 的具体版本或参数规模。
  • 硬件：预训练和 LoRA 训练均在 NVIDIA A100 GPU 上完成。正文用单数表述一块 A100，但没有报告显存容量、CPU、节点、总训练时长或正式训练 Artwork Replication Network 是否使用不同硬件，因此不能据此外推完整算力配置。
  • 代码：论文明确给出代码仓库 https://github.com/nicolaus-huang/ProcessPainter；目录元数据中的 project_url 与 code_url 均指向该地址。
  • 训练平台：这是数字图像/视频生成实验：输入为文字、参考作品或半成品，输出为绘画过程帧/GIF；全文方法、实验与限制部分均未使用机器人、实车或物理仿真平台，也没有报告专用绘画软件运行平台。
Card 06 评估与结果

评估与结果

  • 评估基准：Image-to-Painting-Process 最终帧重建：比较输出序列末帧与参考图的一致性；论文未命名测试集，也未给出评测图像数量或划分。
  • 评估基准：人类偏好研究：受试者观看 ProcessPainter 与各基线的成对绘画过程 GIF，分别选择更像人类作画者与主观更偏好的结果。
  • 评估指标：Mean MSE、Mean LPIPS、Mean L1 衡量末帧与参考图的差异，三者均为越低越好。
  • 评估指标：Anthropomorphic (%) 与 Preference (%) 分别统计更像人类绘画过程和更受偏好的选择比例，均为越高越好。
  • 对比方法：重建表与可视化对比四个 stroke-based rendering 基线：LearnToPaint、Paint Transformer、Intelli-Paint、Stylized Neural Painting；量化结果来自各方法官方代码库的推荐参数。
  • 对比方法：论文声称文本到绘画过程与逐步续画没有现成同任务方法，因此没有为这两项功能设置直接量化基线；正式数值比较集中在 Image-to-Painting-Process。
  • 关键结果：ProcessPainter 在末帧重建上取得 Mean MSE 0.014820、Mean LPIPS 0.024517、Mean L1 0.082165，三项均为表中最低。
  • 关键结果：最接近的 LearnToPaint 对应为 0.016181、0.033240、0.087082；其余 Paint Transformer、Intelli-Paint、Stylized Neural Painting 在三项误差上也均高于 ProcessPainter。
  • 关键结果：在人类感知比较中，ProcessPainter 相对 LearnToPaint 的 Anthropomorphic/Preference 为 78.2/68.2，相对 Paint Transformer 为 80.4/65.9；表头单位均为百分比。
  • 关键结果：相对 Intelli-Paint 的 Anthropomorphic/Preference 为 84.5/78.4，相对 Stylized Neural Painting 为 78.6/71.6；表头单位均为百分比，四组配对中两个比例都超过半数。
  • 消融实验：图示做了定性组件消融：完整模型同时使用 Artwork Replication Network 与 DDIM inversion/noise replacement 时，末帧最贴近参考图；去掉噪声替换时只剩有限一致性，去掉参考网络而只保留噪声替换时一致性很差。论文未给这组消融提供数值表。
  • 实验条件：末帧重建只评参考图与 Image2Painting 输出的最后一帧，三项误差均按官方代码库推荐参数获得。用户研究包含 44 名参与者，每人观看 28 组成对序列；每段以总时长 5 秒的 GIF 呈现，并分别回答“更像人类画法”和“更喜欢哪一个”。这不是盲测协议的完整报告，论文未说明受试者背景、随机化方式或显著性检验。
