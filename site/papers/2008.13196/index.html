Finding Action Tubes with a Sparse-to-Dense Framework

2020-08-30 · 原文 · 翻译 · 2008.13196

Card 02 论文概述

论文概述

  • 它解决时空动作检测中逐帧或逐片段密集检测再链接既只看到短期上下文、又重复计算的问题：从视频流的一次前向中产生时间区间、演员框轨迹与动作类别组成的动作管。
  • 适用场景是需要在视频中同时判断动作发生区间、定位区间内演员并分类动作的时空检测；论文在 UCF101-24 未裁剪体育视频，以及动作贯穿全片的 JHMDB-21、UCFSports 短视频上验证。
  • 论文真正检验的是：长短期信息融合能否提高稀疏帧上的检测与关联可靠性，以及按动作动态程度自适应决定采样量，能否让插值得到的稠密动作管在维持 video-mAP 的同时显著减少推理开销。
  • 研究背景：时空动作检测比视频级动作识别或时间定位更细：它既要确定动作发生区间，又要在区间内定位演员，还要给出动作类别；目标因而是带类别与逐帧框序列的动作管，而不是单一视频标签。
  • 核心痛点：既有 detect-and-link 管线先以每帧或短片段信息密集检测框，再用 Viterbi 等启发式算法链接。短期观察会混淆前段相似、后段才分化的 Long Jump 与 Pole Vault；逐帧检测在计入光流后还会进一步放大计算成本。
  • 任务定义：给定视频 V，输出动作管集合 A={Φ_j}；每条 Φ_j 具有类别 c_j、起止帧 s_j/e_j，以及该区间内各时刻的四维边界框集合 B_j={b_t}。
  • 研究目标：在单次前向中先稀疏地产生时间与空间候选，再借助框关联和线性插值恢复稠密动作管；同时显式融合长短期上下文，使速度—精度折中优于逐帧密集检测。
Card 03 核心贡献

核心贡献

  • 提出单次前向的 sparse-to-dense 时空动作检测框架：先在稀疏采样位置检测，再沿预测时间区间关联并插值为稠密动作管。
  • 设计 LFA：由时序金字塔产生全时域权重图，把每个时刻的三维特征与所有时刻的加权组合做残差融合，并将增强特征用于提议、框检测和关联。
  • 设计 DTS：以插值框和真值管的平均 IoU 达到阈值所需的最小均匀采样数作为动态等级，学习每个时间提议的采样量，按动作复杂度而不是固定点数或固定步长采样。
Card 04 方法描述

方法描述

  • 所属模块：时序金字塔先给出动作时间提议；LFA 将全时域上下文注入原始三维特征；DTS 为每个时间提议预测动态等级并抽取稀疏二维特征；空间检测器产生框、类别、嵌入和位移；关联器与插值器最终恢复稠密动作管。
  • 输入与表示：输入视频被时间采样为长度 T 的帧张量，由三维卷积网络输出特征 F，其通道、时间和空间维记为 C、T_f、H、W。空间池化后的单维时序特征进入金字塔，时间提议表示为归一化区间 (s,e)，动作管以类别、起止帧和四维框序列表示。
  • 模型结构：主干采用 I3D；其后是由步长为 2 的一维卷积下采样路径和反卷积上采样路径组成的时序金字塔。LFA 的映射 R 由三个一维卷积块及批归一化、ReLU 构成；空间检测器含二维卷积的分类/回归分支与三维卷积的嵌入/位移分支。
  • 数据流：视频经主干得到三维特征；空间平均池化后建立时序金字塔并回归时间提议；LFA 计算全时域权重并增强原特征；DTS 按每个提议的预测动态等级，在 (s,e) 内用线性插值抽出若干二维特征；空间分支检测框，关联分支给出嵌入与位移；从首个样本中类别分数最高的框出发，逐次选择连通度最大的框，最后线性插值补齐逐帧框，管分数为各框平均分乘时间提议 actionness。
  • 关键技术：动态等级 d 的真值从少到多均匀抽样真值框，插值回整段并计算逐帧 IoU 均值，第一个达到 ε 的样本数即 d；训练时预测 d̂，推理取 n=min(⌈d̂⌉,N_max)。相邻框连通度对外观距离 D_a 与位移距离 D_s 的平均值取负指数。
  • 公式与超参数：LFA 先计算 S=σ(R(F_p;θ))，再令 F̂ 等于原特征 F 加上由 S 加权、以 T_f 归一化的全时域特征和。动态等级用加权 smooth L1 损失约束 d 与 d̂；嵌入损失以平方 L2 距离和间隔 α 拉近同实例、推开不同实例，位移损失监督 δ_i 接近下一采样框的中心偏移。实验设 α=2、ε=0.7、γ=0.1；N_max 在 UCF101-24、JHMDB-21、UCFSports 分别为 10、4、8；训练张量长度 T 分别为 96、32、48 帧。

Card 06 评估与结果

评估与结果

  • 评估基准：UCF101-24：第一划分上的时空动作检测。
  • 评估基准：JHMDB-21：三个划分取平均，并另用于推理时间测试。
  • 评估基准：UCFSports：标准划分上的时空动作检测。
  • 评估指标：video-mAP（越高越好）：预测管只有与尚未匹配真值管的 tube overlap 大于阈值 Δ 才算正例；主结果在 JHMDB-21、UCFSports 的 Δ=0.2/0.5 与 UCF101-24 的 Δ=0.3/0.5 报告。
  • 评估指标：推理效率同时报告每视频平均时延（秒，越低越好）与近似 FPS（越高越好）。
  • 对比方法：主结果表同时比较只用 RGB 的方法和使用 RGB+Flow 的方法；本模型输入仅为 RGB，因此跨方法解读时需保留输入模态差异。
  • 对比方法：采样消融比较 fixed point-avg、fixed point-4、fixed point-10、fixed step-avg 与 DTS；固定策略分别控制采样点数或时间步长。
  • 关键结果：JHMDB-21：仅 RGB 的本方法在 Δ=0.2/0.5 时 video-mAP 为 76.1/74.3（越高越好）。
  • 关键结果：UCFSports：仅 RGB 的本方法在 Δ=0.2/0.5 时 video-mAP 为 94.3/93.8（越高越好）。
  • 关键结果：UCF101-24：仅 RGB 的本方法在 Δ=0.3/0.5 时 video-mAP 为 71.1/54.0（越高越好）。
  • 关键结果：JHMDB-21 上每视频平均推理时间为 0.21 秒，约 168 FPS；作者报告相对最近竞争者最高加速 7.6×。
  • 消融实验：LFA 消融：完整模型在 UCF101-24、Δ=0.3 时为 71.1 video-mAP；去掉 LFA 后为 62.2，下降 8.9%（越高越好）。
  • 消融实验：关联向量消融：完整模型为 71.1；去掉 embedding 得 68.9（下降 2.2%），去掉 shift 得 69.6（下降 1.5%）video-mAP@0.3。
  • 消融实验：DTS 为 71.1 video-mAP@0.3、0.569 秒/视频；fixed point-avg 为 67.4、0.551 秒，DTS 在近似时延下准确率更高。
  • 消融实验：fixed step-avg 为 66.9、0.571 秒/视频，低于 DTS 的 71.1、0.569 秒；作者据此认为按动作复杂度自适应优于只按持续时间设步长。
  • 消融实验：固定点数采样呈精度—速度权衡：fixed point-4 为 63.3、0.412 秒，fixed point-10 为 67.5、0.654 秒；二者准确率均低于 DTS 的 71.1，后者为 0.569 秒。
  • 实验条件：所有消融均在 UCF101-24 上且只用 RGB。训练分两阶段：先冻结空间检测器和 LFA，训练主干与时间检测器学习提议及动态等级，再端到端联合训练；优化器为 SGD，累积 batch size 为 16。主结果是给定视频上的检测评测，不涉及机器人开环/闭环或实车；JHMDB-21 另跑一个 epoch 统计平均推理时间。
