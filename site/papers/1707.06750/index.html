论文概述

  • 研究目标：研究目标是集中提高时间动作提议的质量，并检验高质量候选能否在复用视频级分类结果时同步提高时间动作定位表现。
Card 03 核心贡献

核心贡献

  • 把 SSAD 改成只做提议的 Prop-SSAD：输入删除 C3D、仅保留 two-stream 特征，把锚点层从三张扩展到七张时间特征图，并把联合分类、重叠与位置损失改为只使用 overlap loss。
  • 自行实现 TAG：用一个含单隐层的 MLP 为每个 snippet 预测 actionness，再以多个阈值分组生成候选；当 TAG 候选与 Prop-SSAD 候选的最大 IoU 高于 0.75 时，用 TAG 边界替换对应 Prop-SSAD 边界。
  • 构建完整的提议—定位流程：从视频抽取 two-stream snippet 特征，Prop-SSAD 与 TAG 分别生成候选，边界精修后再用视频级动作分类结果为候选赋类。
  • 在 ActivityNet 验证集上将边界精修带来的 AR-AN 从 61.52 提到 64.40，并在测试集取得 32.26 average mAP，展示提议质量可转化为定位收益。
Card 04 方法描述

方法描述

  • 所属模块：框架包含特征提取、时间动作提议和时间动作定位三部分：two-stream 网络把视频变成 snippet 特征序列；Prop-SSAD 生成主候选，TAG 负责候选边界精修；视频级分类结果最后为精修候选赋予动作类别。
  • 输入与表示：视频被切成不重叠的 16 帧 snippet；中心帧经 ResNet 的 Flatten-673 层形成 appearance feature，中心附近连续 6 帧计算光流后经 BN-Inception 的 global-pool 层形成 motion feature。两者拼接为每个 snippet 的 3072 维向量，并用线性插值把整段特征序列缩放到长度 256。
  • 模型结构：SSAD 的基本结构把多个 temporal anchor 关联到多尺度时间特征图，并由时间卷积预测锚点的动作类别、overlap score 和位置偏移。Prop-SSAD 只用 two-stream 输入，把锚点关联到长度为 1、2、4、8、16、32、64 的时间特征图，并只使用 overlap loss 训练。
  • 数据流：先抽取并定长化 snippet 特征序列；随后 Prop-SSAD 得到候选集 Pssad，TAG 得到候选集 Ptag。对每个 pt∈Ptag，计算它与全部 Pssad 候选的 IoU；若最大 IoU 高于 0.75，就用 pt 的边界替换对应 ps 的边界，形成最终精修候选集，最后把视频级分类类别赋给这些候选。
  • 关键技术：关键机制一是把 YOLO、SSD 式锚点思想迁移到一维时间定位，并在多尺度时间特征图上用卷积预测；关键机制二是用 MLP actionness 与多阈值 grouping 形成 TAG 候选；关键机制三是以候选间 IoU 触发边界替换，而不是把两个提议器的候选简单并集。
  • 公式与超参数：边界精修可写成：对 pt∈Ptag 取 ps*=argmax_{ps∈Pssad} IoU(pt,ps)，若 max IoU>0.75，则以 pt 的边界替换 ps*；正文未给出这一过程的独立损失公式。其他明确超参数包括输入特征序列长度 256、锚点图长度集合 {1, 2, 4, 8, 16, 32, 64}，且 Prop-SSAD 只优化 overlap loss。

Card 06 评估与结果

评估与结果

  • 评估基准：ActivityNet 时间动作提议：在 validation set 上评测候选时间片段。
  • 评估基准：ActivityNet 时间动作定位：在 validation set 与 testing set 上评测带类别的时间区间。
  • 评估指标：提议指标是 Average Recall–Average Number of Proposals per Video 曲线下面积 AR-AN；AR 是 tIoU 从 0.5 到 0.95、步长 0.05 的 recall 均值，AR@100 表示使用 100 个候选时的平均召回，均为越高越好。
  • 评估指标：定位指标是 mAP；官方 average mAP 对 tIoU 阈值 0.5 到 0.95、步长 0.05 逐点计算后取平均，越高越好。
  • 对比方法：提议对比包含 Uniform Random baseline 以及未精修的 Prop-SSAD，用于分别衡量模型本体和 TAG 边界精修的增益。
  • 对比方法：定位对比包含 Wang et al.、Shou et al.、Xiong et al.，测试集还包含 Zhao et al.；Ours@n 表示仅用前 n 个候选进行定位。
  • 关键结果：验证集提议：Uniform Random 的 AR@10、AR@100、AR-AN 为 29.02、55.71、44.88；Prop-SSAD 为 50.44、69.54、61.52；Refined Prop-SSAD 为 52.50、73.01、64.40，三项均越高越好。
  • 关键结果：验证集定位：Ours@100 在 tIoU 0.5、0.75、0.95 下的 mAP 分别为 44.39、29.65、7.09，average mAP 为 29.17；对比方法中最高的 Xiong et al. average mAP 为 23.98，指标越高越好。
  • 关键结果：测试集定位：Ours result 的 average mAP 为 32.26，高于 Zhao et al. 的 28.28、Xiong et al. 的 26.05 与 Wang et al. 的 14.62（越高越好）。
  • 消融实验：论文未设置独立命名的消融节；Table 1 的模块级对照显示，加入 TAG 边界精修后，AR@10 从 50.44 升至 52.50、AR@100 从 69.54 升至 73.01、AR-AN 从 61.52 升至 64.40。
  • 消融实验：候选数量敏感性：Ours@1、Ours@5、Ours@10、Ours@25、Ours@100 的 average mAP 依次为 25.17、27.86、28.56、28.96、29.17，说明主要收益集中在前几个候选；论文据此认为 AR-AN 对小候选数的权重应更高。
  • 实验条件：特征网络仅用 ActivityNet v1.3 training set 预训练且没有外部数据；提议在 validation set 报告，定位在 validation 和 testing set 报告，定位类别直接采用文献 [17] 的视频级分类结果。论文脚注说明先前使用 [13] 的分类结果，因其准确率异常高而改用 [17] 并更新相关实验；这些都是离线基准结果，未报告零样本、在线闭环或机器人实测条件。
