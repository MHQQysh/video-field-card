TAM: Temporal Adaptive Module for Video Recognition

2020-05-14 · 原文 · 翻译 · 2005.06803

它解决的是固定时序卷积对所有视频共享同一卷积核、难以覆盖相机运动和速度变化等多样时序动态的问题；TAM 根据当前视频特征生成视频专属时序核，同时尽量保持二维卷积网络的计算效率。 具体用于离线 RGB 视频动作分类：可把 TAM 插入现有二维 CNN 构成 TANet，在 Kinetics-400 的外观与动作识别，以及 Something-Something V1/V2 的细粒度、运动主导对象交互场景中建模短期与长期时序关系。 论文真正检验的是：把视频专属动态核拆成位置敏感的局部重要性图和位置不变的全局聚合权重，是否比固定池化或卷积、时序移位、自注意力等模块更准确，并在相近计算预算下保持模块化和跨主干可迁移性。 研究背景：视频的时序动态会随相机运动、动作速度和活动类型而显著变化；视频理解因此需要既能灵活捕获复杂时序结构、又能控制高维视频计算开销的时序模块。 核心痛点：标准时序卷积对不同视频共享固定权重，难以适应视频间变化；只分配逐时刻权重的时序注意力没有显式时序交互，可能忽略长程依赖；直接使用三维卷积又缺少针对视频时序属性的专门设计，并可能带来较高计算成本。 任务定义：给定视频片段的特征张量 X∈R^{C×T×H×W}，TAM 只沿时间维建模并输出同形状特征 Y；把 TAM 嵌入二维 CNN 后，网络对每帧产生分类分数，再对所有帧分数做平均得到片段级动作类别预测。 研究目标：目标是设计兼具高效率和强灵活性的自适应时序算子：让局部分支选择短期判别特征，让全局分支依据整段视频生成聚合核，并验证该设计能以接近二维 CNN 的计算量改进多种动作识别主干。

Card 02 论文概述

论文概述

  • 它解决的是固定时序卷积对所有视频共享同一卷积核、难以覆盖相机运动和速度变化等多样时序动态的问题；TAM 根据当前视频特征生成视频专属时序核，同时尽量保持二维卷积网络的计算效率。
  • 具体用于离线 RGB 视频动作分类：可把 TAM 插入现有二维 CNN 构成 TANet，在 Kinetics-400 的外观与动作识别，以及 Something-Something V1/V2 的细粒度、运动主导对象交互场景中建模短期与长期时序关系。
  • 论文真正检验的是：把视频专属动态核拆成位置敏感的局部重要性图和位置不变的全局聚合权重，是否比固定池化或卷积、时序移位、自注意力等模块更准确，并在相近计算预算下保持模块化和跨主干可迁移性。
  • 研究背景：视频的时序动态会随相机运动、动作速度和活动类型而显著变化；视频理解因此需要既能灵活捕获复杂时序结构、又能控制高维视频计算开销的时序模块。
  • 核心痛点：标准时序卷积对不同视频共享固定权重，难以适应视频间变化；只分配逐时刻权重的时序注意力没有显式时序交互，可能忽略长程依赖；直接使用三维卷积又缺少针对视频时序属性的专门设计，并可能带来较高计算成本。
  • 任务定义：给定视频片段的特征张量 X∈R^{C×T×H×W}，TAM 只沿时间维建模并输出同形状特征 Y；把 TAM 嵌入二维 CNN 后，网络对每帧产生分类分数，再对所有帧分数做平均得到片段级动作类别预测。
  • 研究目标：目标是设计兼具高效率和强灵活性的自适应时序算子：让局部分支选择短期判别特征，让全局分支依据整段视频生成聚合核，并验证该设计能以接近二维 CNN 的计算量改进多种动作识别主干。
Card 03 核心贡献

核心贡献

  • 提出两级自适应 TAM，把视频专属时序核解耦为位置敏感的局部重要性图和位置不变但随视频变化的全局聚合核，分别处理短期显著性与长期结构。
  • 给出高效实现：先做全局空间平均池化，再以通道独立方式建模；局部分支用时序 Conv1D 产生逐位置权重，全局分支用全连接层生成归一化时序核。
  • 把 TAM 作为模块插入 ResNet bottleneck 构成 TA-Block 与 TANet，可复用二维 ResNet 权重、保持通道数，并在分类头前不做时序下采样。
  • 总体评测覆盖 Kinetics-400、Something-Something V1/V2；探索性消融仅在 Kinetics-400 上进行，检查参数、感受野、插入位置、模块数量、分支互补性与跨主干迁移，并在补充材料中可视化局部权重和全局动态核。
Card 04 方法描述

方法描述

  • 所属模块：TAM 是 TA-Block 内的纯时序算子，默认放在 ResNet bottleneck 的第一层 Conv2D 之后；用 TA-Block 替换各阶段的 ResNet-Block 形成 TANet，空间模式仍由二维卷积负责。
  • 输入与表示：输入为 X∈R^{C×T×H×W}，其中 C、T、H、W 分别表示通道、时间、高和宽。先对 H×W 做全局平均得到 X̂∈R^{C×T}；局部分支由它生成 V∈R^{C×T}，全局分支生成每个通道的时序核 Θ_c∈R^K。
  • 模型结构：局部分支由两层时序 Conv1D、BN、ReLU 与 sigmoid 组成，先降通道再输出随时间位置变化的重要性图；全局分支由两层全连接层、ReLU 和 softmax 组成，在整段压缩时序信号上生成通道独立、位置不变的正聚合权重。
  • 数据流：首先把 X 空间池化为 X̂；随后局部分支把重要性图 V 在空间维复制，与 X 逐元素相乘得到增强特征 Z；同时全局分支由 X̂ 生成 Θ；最后按通道用 Θ 对 Z 做时序卷积，得到 Y，并在网络末端平均各帧分类分数形成视频片段预测。
  • 关键技术：关键是把位置敏感激励与位置不变聚合分开学习：局部窗口负责短期判别性，全局感受野负责长期依赖；通道独立的动态卷积避免显式建模通道相关性，softmax 保证聚合权重为正，堆叠 TAM 扩展长程建模能力。
  • 公式与超参数：核心计算为 X̂_{c,t}=1/(H×W)∑_{i,j}X_{c,t,j,i}，Z=F_rescale(V)⊙X，Θ_c=softmax(F(W_2,δ(F(W_1,φ(X)_c))))，Y_{c,t,j,i}=∑_kΘ_{c,k}·Z_{c,t+k,j,i}。局部分支核长 K=3、首层把通道从 C 降为 C/β；消融后默认 α=2、β=4。

  • 数据集：Something-Something V2：V1 的扩展版本，任务类别保持不变。

Card 06 评估与结果

评估与结果

  • 评估基准：Kinetics-400 验证集：用于消融、时序模块公平对比与公开方法比较。
  • 评估基准：Something-Something V1 验证集：以单片段、中心裁剪口径比较细粒度动作识别。
  • 评估基准：Something-Something V2 验证集：同时报告单视图与多片段、多裁剪口径。
  • 评估指标：Top-1 与 Top-5 分类准确率均以百分比报告，越高越好；FLOPs/GFLOPs（单视图及视图数）与参数量用于比较计算开销，准确率相近时数值越低越高效。
  • 对比方法：公平时序模块对比覆盖逐帧 C2D、时序池化、固定时序卷积、通道级时序卷积、膨胀三维卷积、TSM、TEINet 与 Non-local block；另以单独局部/全局分支、Global branch+SE 和 TANet-R 检验互补性。
  • 对比方法：公开方法比较覆盖 TSN、ARTNet、I3D、SlowFast、X3D、CorrNet、ip-CSN、TRN、GST、ECO 与 bLVNet-TAM 等，并按各表规定的训练输入和测试视图报告复杂度与准确率。
  • 关键结果：同训练与推理协议下，8-frame ResNet50 TANet 以 43.02G 单视图 FLOPs、25.59M 参数取得首位准确率 76.3%、前五准确率 92.6%；C2D 的首位准确率为 70.2%，比 TANet 低六点一个百分点（准确率越高越好）。
  • 关键结果：Kinetics 公开方法表中，TANet-152 以 16×224×224 输入和 242×12 GFLOPs×视图取得首位准确率 79.3%、前五准确率 94.1%，是表内 TANet 变体的最高准确率。
  • 关键结果：Something-Something V1 的单片段中心裁剪表中，TANetEn 使用 8f+16f、99G FLOPs，取得首位准确率 50.6% 与前五准确率 79.3%；同表 TSMEn 为 49.7% 与 78.5%。
  • 关键结果：Something-Something V2 上，16f TANet 在 2 clips×3 crops 下取得首位准确率 64.6%、前五准确率 89.5%；8f+16f 的 TANetEn 在相同视图口径下为 66.0% 与 90.1%。
  • 消融实验：参数消融中，8-frame、α=2、β=4 得到首位准确率 76.28%、前五准确率 92.60%，高于表内其他 α/β 组合，因而成为默认设置。
  • 消融实验：感受野消融中，8-frame 时 K=3 的 76.28%/92.60% 高于 K=5 的 75.62%/92.14%；16-frame 时 K=5 的 77.19%/93.17% 高于 K=3 的 76.87%/92.88%，但后续实验统一取 K=3。
  • 消融实验：插入位置上，第一层 Conv2D 后的 TANet-b 为 76.28%/92.60%，高于 TANet-d 的 75.20%/91.78%；模块数量从 res5 的 3 个增至 res2-5 的 16 个时，首位准确率从 74.12% 升至 76.28%。
  • 消融实验：分支消融的首位/前五准确率分别为：Global branch 75.6%/91.9%，Local branch 73.3%/90.7%，Global branch+SE 75.9%/92.1%，TANet-R 76.0%/92.2%，完整 TANet 76.3%/92.6%。
  • 消融实验：跨主干消融的 Top-1 准确率（越高越好）为：ShuffleNet V2 62.1%→67.3%（表中 ΔAcc. +5.2%）、MobileNet V2 64.1%→71.6%（+7.5%）、Inception V3 71.4%→75.6%（+4.2%）、ResNet-50 70.2%→76.3%（+6.1%）、I3D-ResNet-50 76.6%→77.2%（+0.6%）；均为不带 TAM→带 TAM，I3D-ResNet-50 使用 32 帧，其余主干使用 8 帧。
  • 实验条件：训练均从 ImageNet 权重初始化；Kinetics 模型输入 8 或 16 帧，从连续 64 帧中采样并训练 100 epochs，Something-Something 训练 50 epochs。测试时 Kinetics 的 8-frame 模型取 10 clips、16-frame 模型取 4 clips，均用 3 crops；V1 用单 clip 中心 crop，V2 同时报 1 clip×1 crop 与 2 clips×3 crops。所有实验均为有监督离线闭集动作分类，不是零样本、闭环或实车评测。
