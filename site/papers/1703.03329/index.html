UntrimmedNets for Weakly Supervised Action Recognition and Detection

2017-03-09 · 原文 · 翻译 · 1703.03329

问题：如何在训练时只有未裁剪视频及视频级动作标签、没有动作实例时间边界的条件下，直接学出既可做弱监督动作识别又可做弱监督动作检测的模型。 场景：面向 YouTube 等天然未裁剪的长视频；逐个标注、裁剪动作时段昂贵且耗时，而且动作的精确时间范围本身可能主观、标注者之间不一致。 研究问题：仅靠视频标签，分类模块与选择模块能否联合学习“片段是什么动作”和“哪些片段重要”，并让同一端到端模型在 THUMOS14、ActivityNet 的识别与时间检测上与依赖时间标注的强监督方法竞争。 研究背景：传统动作识别通常把训练动作实例从长视频中人工裁成短片，再把模型用于裁剪或未裁剪视频；这种精确时间监督不适合扩展到真实的大规模视频。 核心痛点：去掉时间标注后，学习器不能只做类别外观建模，还必须从大量背景片段中自动推断可能动作实例的时间位置；而动作边界又可能没有唯一、稳定的定义。 任务定义：给定未裁剪视频与视频级动作标签，训练阶段不使用任何动作实例的时间信息；测试时输出整段视频的动作类别（WSR），或定位动作发生的时间区间（WSD）。 研究目标：目标是用可微的特征提取、分类与选择组件，把片段级分类分数和片段重要性汇成视频级预测，以该预测反向传播并联合优化网络。

Card 02 论文概述

论文概述

  • 问题：如何在训练时只有未裁剪视频及视频级动作标签、没有动作实例时间边界的条件下，直接学出既可做弱监督动作识别又可做弱监督动作检测的模型。
  • 场景：面向 YouTube 等天然未裁剪的长视频；逐个标注、裁剪动作时段昂贵且耗时，而且动作的精确时间范围本身可能主观、标注者之间不一致。
  • 研究问题：仅靠视频标签，分类模块与选择模块能否联合学习“片段是什么动作”和“哪些片段重要”，并让同一端到端模型在 THUMOS14、ActivityNet 的识别与时间检测上与依赖时间标注的强监督方法竞争。
  • 研究背景：传统动作识别通常把训练动作实例从长视频中人工裁成短片，再把模型用于裁剪或未裁剪视频；这种精确时间监督不适合扩展到真实的大规模视频。
  • 核心痛点：去掉时间标注后，学习器不能只做类别外观建模，还必须从大量背景片段中自动推断可能动作实例的时间位置；而动作边界又可能没有唯一、稳定的定义。
  • 任务定义：给定未裁剪视频与视频级动作标签，训练阶段不使用任何动作实例的时间信息；测试时输出整段视频的动作类别（WSR），或定位动作发生的时间区间（WSD）。
  • 研究目标：目标是用可微的特征提取、分类与选择组件，把片段级分类分数和片段重要性汇成视频级预测，以该预测反向传播并联合优化网络。
Card 03 核心贡献

核心贡献

  • 提出 UntrimmedNet：无需动作实例时间标注，直接以未裁剪视频和视频级标签训练同一弱监督框架，服务动作识别与时间检测。
  • 把长视频先变成均匀采样或基于镜头切换的短片提案，再以可替换的深层网络提取片段表示，使后续分类与选择在可控候选集上学习。
  • 设计互补的选择机制：硬选择以多实例学习的 class-wise top-k 提案聚合，软选择在全部提案上学习 attention 权重，并分别与分类分数融合为视频预测。
  • 将特征提取、分类、选择和视频级交叉熵放入统一可微数据流，以标准反向传播端到端优化，并把软选择的注意力直接用于时间检测。
Card 04 方法描述

方法描述

  • 所属模块：特征提取模块把每个 clip proposal 编码为视觉表示；分类模块独立判断各提案的动作类别；选择模块挑选或排序更可能含动作的提案；二者输出融合成整段未裁剪视频的预测。
  • 输入与表示：输入视频 V 先被表示为一组带起止位置的短片提案 C；每个提案 c 映射为 D 维特征 φ(V;c)。实验中的两流输入由 RGB 空间流和 TVL1 光流时间流组成。
  • 模型结构：流水线依次为 clip sampling、预训练特征网络、片段级线性分类器、硬或软选择器、视频级融合。特征网络可采用 Two-Stream CNN 或 Temporal Segment Network，后者用 segment consensus 建模较长时间范围。
  • 数据流：先从未裁剪视频采样多个短片；逐提案提特征并得到类别分数；硬分支按每一类别选 top-k 原始分类分数后平均，软分支对提案选择分数做跨提案 softmax 得到注意力；最后用选择权重聚合分类结果为视频预测，再与视频标签计算损失并反传到全部模块。
  • 关键技术：均匀采样把视频等分；镜头采样以相邻帧 HOG 差异检测切换，并把长镜头按 K=300 帧切成固定时长提案。硬选择遵循 MIL，软选择采用 attention；探索实验默认改用镜头采样。
  • 公式与超参数：分类为 x_c(c)=W_c φ(c)，并在动作类别维做 softmax；软选择为 x_s(c)=w_s^T φ(c)，在提案维做 softmax，视频概率是各提案分类概率按注意力的加权和。硬选择则按类别平均 top-k 原始分数后再归一化；提案数探索实验的训练期 hard selection 令 k 取 N 的二分之一向下取整，其中 N 是每视频采样提案数，需与识别推理聚合的 k=20 区分。训练用视频级交叉熵；多标签先做 L1 归一化，weight decay=0.0005。SGD 的 batch size=256、momentum=0.9；空间流初始学习率 0.001、每 4,000 次迭代降 10 倍并在一万次迭代停止，时间流初始学习率 0.005、每 6,000 次迭代降 10 倍并在一万八千次迭代停止；dropout 为空间流 0.8、时间流 0.7；数据增强包括 cropping augmentation 与 scale jittering。

Card 06 评估与结果

评估与结果

  • 评估基准：THUMOS14：弱监督动作识别与弱监督时间检测；探索实验按 validation→test，检测按多档 IoU 评估。
  • 评估基准：ActivityNet release 1.2：弱监督动作识别，覆盖 train→validation 与 train+validation→test server。
  • 评估指标：动作识别采用 mean average precision（mAP，越高越好），表格以百分比报告。
  • 评估指标：动作检测报告 IoU α=0.5、0.4、0.3、0.2、0.1 下的 mAP（越高越好）。
  • 对比方法：识别对比覆盖 iDT+FV、Two Stream、EMV+RGB、Objects+Motion、C3D、Depth2Action 与 TSN；带星号方法使用强监督训练。
  • 对比方法：检测对比覆盖 Oneata、Richard、Shou、Yeung 与 Yuan 等方法；检测表将这些对手标为使用强监督训练。
  • 关键结果：THUMOS14 主识别比较使用 training 与 validation 视频学习 UntrimmedNet；其中 training data UCF101 已经裁剪，整段视频 clip 直接作为 proposal。在这一口径下，UntrimmedNet-soft 为 82.2%，对比 TSN 的 78.5%，绝对相差三点七个百分点，而非相对提升百分比；hard 版本为 81.2%（mAP，越高越好）。
  • 关键结果：ActivityNet test server 上，UntrimmedNet-hard 为 91.3%，对比强监督 TSN 的 88.8%，高 2.5%；soft 版本为 90.9%（mAP，越高越好）。
  • 关键结果：THUMOS14 检测中，UntrimmedNet-soft 在 IoU α=0.5/0.4/0.3/0.2/0.1 时的 mAP 依次为 13.7/21.1/28.2/37.7/44.4；这些弱监督结果低于各阈值下表中最佳强监督数值，但处于可比较范围。
  • 消融实验：选择模块消融（THUMOS14 mAP）：TSN 3-segment/21-segment 为 67.7%/68.5%，加入 hard/soft selection 后为 73.6%/74.2%，说明增益不只是增加采样 segment。
  • 消融实验：采样消融的 soft-selection mAP 为：shot-based 71.6%，uniform 70.2%；作者随后默认采用 shot-based sampling。
  • 消融实验：特征提取消融的 soft-selection mAP 为：Temporal Segment Network 74.2%，Two Stream CNN 71.6%，其后实验采用前者。
  • 消融实验：每视频采样提案数比较 5、7、9；soft selection 下 7 和 9 略优于 5，作者为兼顾准确率与效率固定为 7。
  • 实验条件：训练监督只有视频级标签，不用动作时间标注。识别测试每 30 帧取 1 张 RGB（或 5 帧光流堆叠），以 top-k（k=20）或 attention 加权汇成视频分数；检测每 15 帧测试一次，以 attention 阈值 0.0001 去背景，再以分类阈值 0.5 生成区间。探索实验在 THUMOS14 上用 validation 训练、test 评估，并同时报告 hard 与 soft selection。
