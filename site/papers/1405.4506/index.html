Bag of Visual Words and Fusion Methods for Action Recognition: Comprehensive Study and Good Practice

2014-05-18 · 原文 · 翻译 · 1405.4506

这篇论文解决的不是再发明一个孤立的动作特征，而是把视频动作识别的 BoVW 工程链拆开审计：局部特征、预处理、码本、编码、池化与归一化的选择会相互抵消，过去分散在不同场景里的经验无法直接拼成可靠系统。 具体使用场景是从现实世界动作视频中判断正在发生的动作类别：系统把外观、光流和运动边界等局部描述子汇成视频级表示，再交给线性 SVM；论文在 HMDB51、UCF50 与 UCF101 上检验从稀疏 STIPs 到密集 iDTs 的不同组合。 论文真正验证的问题是：在逐项比较局部特征、预处理、编码、池化归一化和融合层级时，哪些选择能提高动作分类准确率；以及能否把不同描述子与不同编码统计的互补性合成 hybrid representation。效率不是主结果，作者另以随机抽取的 50 段 UCF101 视频总编码时间作辅助比较。 研究背景：局部时空特征驱动的 BoVW 曾是现实视频动作识别的主流：它不要求先检测人体或逐帧跟踪身体部位，而把动作体积看成刚性时空对象，以局部外观、运动与运动边界描述子构成视频级表示。 核心痛点：动作类内差异来自运动速度、视角变化与背景杂乱，视频数据又高维且质量偏低；更关键的是，既有工作分别优化特征、编码或池化，如何选择 BoVW 每一步仍不明确，而多描述子融合方法多在不同场景中提出、尚缺动作识别下的系统比较，所以某一步的不当选择可能抵消其他步骤的收益。 任务定义：输入是一段视频中抽取的局部描述子集合；经预处理、码本学习、逐描述子编码、池化与归一化得到一个全局视频表示，再用 one-vs-all 线性 SVM 输出得分最高的动作类别。 研究目标：在同一批公开动作分类数据与协议上，对稀疏 STIPs、密集 iDTs、不同编码家族、池化归一化组合及描述子级/表示级/分数级融合做受控比较，归纳可复用实践，并据此构造互补的混合表示。

Card 03 核心贡献

核心贡献

  • 把 BoVW 的完整链条置于同一动作识别实验中，覆盖两类局部特征、十种实际评估的编码方法、八种池化归一化策略，并指出预处理、编码和归一化都可能决定最终结果。
  • 从 hard/soft assignment、global/local assignment 与零阶到高阶统计三个维度解释编码方法关系，并用统一潜变量生成模型说明 VQ、SA、VLAD、FV 与 sparse coding 的联系。
  • 系统比较描述子级、表示级与分数级融合，发现融合选择取决于描述子在 cuboid 层和视频层的相关性；对 iDTs，各类编码在三个数据集上都以表示级融合最好。
  • 提出 hybrid representation：对 iDTs 的 HOG、HOF、MBHx、MBHy 分别产生 FV 与软化 SVC 输出，再在表示层组合，从而同时利用多描述子和不同统计阶数的互补性。
  • 把上述经验落实为可复现实验基线，在三套公开动作识别数据上给出统一分类协议、运行时间分析和相对既有最好结果的精确提升，而不只报告单一最终准确率。
Card 04 方法描述

方法描述

  • 所属模块：流水线由局部特征抽取、PCA-whitening 预处理、k-means 或 GMM 码本生成、局部编码、池化归一化五个环节组成；前四步把时空 cuboid 变为稳定的码字统计，最后的视频级向量进入线性分类器。
  • 输入与表示：输入表示覆盖两种采样范式：STIPs 用 3D-Harris 找高运动显著性的稀疏点并计算 HOG/HOF；iDTs 通过像素轨迹和相机运动校正密集采样，提供 trajectory shape、HOG、HOF、MBHx、MBHy，分别刻画形状、外观运动与运动边界。
  • 模型结构：编码层分为 voting、reconstruction 与 super-vector 三族：前两族产生码字权重或重构系数，super-vector 额外聚合相对码字中心的高阶统计；池化后可在 cuboid 的描述子级、视频表示级或分类器分数级融合，最终采用 one-vs-all 线性 SVM 决策。
  • 数据流：逐视频先抽取多路局部描述子并做 PCA 去相关与 whitening；用训练描述子学习 k-means/GMM，把每个局部向量编码到码字空间；在时间和空间样本上求和或取最大并归一化；若用表示级融合则先独立走完各路 BoVW 再拼接，hybrid 路径进一步拼接 FV 与 SVC-k，最后由最高 SVM 分数给出类别。
  • 关键技术：关键经验包括：soft assignment 降低硬量化的信息损失，局部近邻约束减少高维空间中远码字带来的噪声，super-vector 保留码字归属及一阶/二阶统计；sum pooling 配合 power 与最终 l2-normalization 抑制 feature burst，密集 iDTs 还通过 intra-normalization 按码字块平衡背景响应。
  • 公式与超参数：预处理写成 x=ΛU^T f，把原描述子投影到主成分并按协方差特征值 whitening；实验中 SA-k 取 β=1、k=5，近似 LLC 取 k=5，SVC 的平衡系数 α=0.1；融合实验的 super-vector 码本/GMM 大小取 512，其他编码取 8, 000，power normalization 的 α=0.5。

数据集与资源

  • 数据集：HMDB51：现实场景动作视频，按官方训练/测试划分求平均分类准确率。
  • 数据集：UCF50：同组视频背景相似，按 Leave One Group Out 交叉验证报告平均准确率。
  • 数据集：UCF101：UCF50 的扩展，按 THUMOS 挑战发布的训练/测试划分评估。
  • 规模与划分：三套数据合计 26,704 段视频；HMDB51 含 51 类、6,766 段视频和三个官方划分；UCF50 含 50 类、6,618 段视频，每类分为 25 组；UCF101 含 101 类、13,320 段视频，固定 25 FPS、320×240，并使用三个划分。
  • 模型：论文实际实现的算法组件是 STIPs/iDTs 手工局部时空特征、k-means 或 GMM 码本、VQ/SA-k/LLC/FV/VLAD/SVC 等 BoVW 编码器，以及 LIBSVM 线性 SVM；多类分类采用 one-vs-all 训练并选择最高分标签。

Card 06 评估与结果

评估与结果

  • 评估基准：HMDB51：高类内变化的真实世界动作分类基准。
  • 评估基准：UCF50：面向网页视频动作分类并采用分组交叉验证的基准。
  • 评估基准：UCF101：更大类别规模、按 THUMOS 协议划分的动作分类基准。
  • 评估指标：核心指标是分类 accuracy（越高越好）：HMDB51 对三个官方训练/测试划分求平均，UCF50 用 LOGO cross validation 求平均，UCF101 对 THUMOS'13 的三个训练/测试划分求 mean average accuracy；效率实验另报告随机抽取 50 段 UCF101 视频的总编码时间（越低越快）。
  • 对比方法：最终结果表的百分数列中，hybrid representation 相对当时表内最好结果分别为：HMDB51 从 57.2 提至 61.1，UCF50 从 91.1 提至 92.3，UCF101 从 85.9 提至 87.9；正文报告对应提升为 3.9%、1.2%、2.0%。
  • 关键结果：HMDB51 上 hybrid representation 的平均分类准确率为 61.1%，论文报告比此前最好结果高 3.9%。
  • 关键结果：UCF50 上 hybrid representation 的平均分类准确率为 92.3%，论文报告比此前最好结果高 1.2%。
  • 关键结果：UCF101 上 hybrid representation 的 mean average accuracy 为 87.9%，论文报告比此前最好结果高 2.0%。
  • 消融实验：Figure 5 是本文内部的预处理对照：在 UCF101、STIPs、descriptor-level HOG+HOF、sum pooling 与 power l2-normalization 条件下，分别绘制 FV/LLC/VQ 的 PCA+Whiten 与 No PCA+Whiten 曲线。正文另报告本系统 VQ 为 56.1%，并与外部数据集论文 [40] 的 43.9% 比较；43.9% 不是本文内部 no-PCA 分支，不能当作 56.1% 的同次消融对照。
  • 消融实验：码本规模扫描表明 super-vector 方法在 256 个 GMM 分量后趋于饱和，其他编码约在 8, 000 个码字后饱和；STIPs 继续增大还出现过拟合波动。
  • 消融实验：最终融合对照表的 Accuracy (%) 列显示，HMDB51 的 iDT+FV 在描述子级、表示级、分数级融合下分别为 58.37、60.22、59.62，说明表示级融合在该设置下最好。
  • 消融实验：池化归一化对照的结论是 sum pooling + power l2-normalization 总体最佳；intra-normalization 对密集 iDTs 有额外收益，但对稀疏 STIPs 可能削弱与动作相关码字。
  • 实验条件：最终系统使用 iDTs 的 HOG、HOF、MBHx、MBHy，多路分别计算 FV 与 SVC-k；对表示做 power 操作和 intra l2-normalization，再采用 representation-level fusion。结果属于离线、监督训练的视频级分类，不是时序定位、在线推理或零样本评测。
