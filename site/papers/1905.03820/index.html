Hierarchical Cross-Modal Talking Face Generationwith Dynamic Pixel-Wise Loss

2019-05-10 · 原文 · 翻译 · 1905.03820

论文解决“任意语音加一张目标人脸”生成写实说话视频的问题：口型要与语音自然同步，帧间过渡要平滑，并要能适应不同脸型、视角和噪声音频。 具体使用场景包括从电话语音生成可供听障者唇读的画面，以及为电影、游戏中的虚拟角色合成与语音同步的面部运动；身份图还可以来自真人、卡通或动物。 论文真正检验的是：先把语音投影到削弱非语音视觉因素的地标空间，再用时序生成器、动态像素权重以及序列级与帧级判别约束生成像素，能否同时改善同步、清晰度、时间连续性和跨身份稳健性。 研究背景：说话人脸生成不仅是逐帧成像问题，还必须建模视频的时间依赖：观众会察觉微小像素抖动，也会察觉面部运动与语音之间的轻微错位。网络视频又包含转头、机位变化等不能从语音推出的视觉动态。 核心痛点：直接从音频回归像素容易拟合与语音内容无关的音画相关性；若把头部运动、背景等非语音动态也塞进像素空间，画质会下降。已有方法常在生成阶段独立地产生每帧，因而难以同时抑制非相关区域抖动并保持口型同步。 任务定义：输入是一段任意语音、目标身份的一张示例人脸及其地标；输出是该身份说出这段语音的写实视频。目标要求自然唇音同步、连续的帧间过渡，并能泛化到不同脸型、视角、面部特征和噪声条件。 研究目标：作者希望用“语音到地标、地标到像素”的层级桥接隔离非语音视觉因素，再在像素生成阶段显式建模相邻帧、让损失聚焦音画相关区域，并让判别器同时评价单帧形状和整段序列。

Card 02 论文概述

论文概述

  • 论文解决“任意语音加一张目标人脸”生成写实说话视频的问题：口型要与语音自然同步，帧间过渡要平滑，并要能适应不同脸型、视角和噪声音频。
  • 具体使用场景包括从电话语音生成可供听障者唇读的画面，以及为电影、游戏中的虚拟角色合成与语音同步的面部运动；身份图还可以来自真人、卡通或动物。
  • 论文真正检验的是：先把语音投影到削弱非语音视觉因素的地标空间，再用时序生成器、动态像素权重以及序列级与帧级判别约束生成像素，能否同时改善同步、清晰度、时间连续性和跨身份稳健性。
  • 研究背景：说话人脸生成不仅是逐帧成像问题，还必须建模视频的时间依赖：观众会察觉微小像素抖动，也会察觉面部运动与语音之间的轻微错位。网络视频又包含转头、机位变化等不能从语音推出的视觉动态。
  • 核心痛点：直接从音频回归像素容易拟合与语音内容无关的音画相关性；若把头部运动、背景等非语音动态也塞进像素空间，画质会下降。已有方法常在生成阶段独立地产生每帧，因而难以同时抑制非相关区域抖动并保持口型同步。
  • 任务定义：输入是一段任意语音、目标身份的一张示例人脸及其地标；输出是该身份说出这段语音的写实视频。目标要求自然唇音同步、连续的帧间过渡，并能泛化到不同脸型、视角、面部特征和噪声条件。
  • 研究目标：作者希望用“语音到地标、地标到像素”的层级桥接隔离非语音视觉因素，再在像素生成阶段显式建模相邻帧、让损失聚焦音画相关区域，并让判别器同时评价单帧形状和整段序列。
Card 03 核心贡献

核心贡献

  • 提出解耦级联结构：AT-net 先把语音转成低维面部地标，VG-net 再以地标和示例身份图生成视频，从而避免直接学习语音与无关像素动态的伪相关。
  • 在 VG-net 中使用多模态卷积循环网络，把相邻帧相关性放进生成阶段，而不是只在特征提取端使用循环单元，以减轻帧间不连续。
  • 提出动态运动—注意力分解和动态像素损失：注意力指出哪些像素需要改变，运动分支给出如何改变，并用停止梯度的注意力图逐像素调节重建惩罚。
  • 提出回归式判别器：帧级分支从图像回归地标形状，序列级分支聚合循环状态判别整段真伪，使生成器同时受到口型形状、图像质量和时间同步约束。
Card 04 方法描述

方法描述

  • 所属模块：AT-net 负责跨模态变换，把音频与目标身份地标编码成随时间变化的地标；VG-net 负责把预测地标、示例图和示例地标还原为视频帧。VG-net 内的注意力/运动头负责空间变化，判别器的 Dp 分支负责逐帧地标回归，Ds 分支负责整段序列真伪判断。
  • 输入与表示：模型接收任意语音片段、单张身份示例图 i_p 及其地标 p_p，语音以 MFCC a_t 表示。AT-net 的地标路径是 p_p 经 PCA 得到身份条件 h_p，LSTM 预测与音频配对的 PCA 系数 h_t，再由 PCA_R 重建 p̂_t。VG-net 走另一条表示路径：把当前或预测地标 p_t/p̂_t 与示例地标 p_p 分别直接送入 f_lmark，用特征差描述图像变化、用特征拼接形成地标条件注意力；这一路不把两组地标先表述成 PCA 系数。
  • 模型结构：AT-net 是条件 LSTM 编码—解码器，由音频编码器、地标编码器、LSTM、地标解码器和 PCA 重建组成。VG-net 把示例图特征与当前—示例地标特征差按通道拼接，并以两组地标特征的拼接产生中间注意力 att_p_t；CRNN 由 Conv-RNN、残差块和反卷积层组成，在这一门控下融合示例图特征。后续卷积加 Sigmoid 的头输出最终像素注意力 α_t，另一卷积加 tanh 的头输出运动 m_t；α_t 与 att_p_t 的角色不同。
  • 数据流：AT-net 与 VG-net 解耦训练；VG-net 训练时以真实目标地标做 teacher forcing，避免把 AT-net 的预测误差带入。推理时，AT-net 从语音生成地标序列；VG-net 对每个时刻直接编码预测地标和示例地标，并与示例图特征融合，经循环特征更新、地标门控和最终注意力—运动分解后，把运动区域与保留的示例像素混合为连续视频。
  • 关键技术：PCA 用来削弱头动等非音频相关因素；通道拼接比逐元素相加更完整地保留身份图信息。最终像素注意力 α_t 既是合成掩码，也是动态像素损失的空间权重，但反向传播时切断该权重的梯度以防全暗注意力的平凡解。判别器训练时学习地标回归与序列真伪，训练生成器时冻结判别器，使 Dp 约束脸颊和唇形，Ds 约束整段图像质量。
  • 公式与超参数：级联关系写作 p̂=Ψ(a,p_p)，v̂=Φ(p̂,i_p,p_p)。VG-net 的帧合成为 v̂_t=α_t⊙m_t+(1−α_t)⊙i_p；动态像素损失为 L_pix=Σ_t||(v_t−v̂_t)⊙(ᾱ_t+β)||_1，其中 ᾱ_t 是停止梯度的注意力权重，β=0.5。总目标为 L=L_gan+λL_pix，λ=10.0；判别器回归项还用预定义掩码 M_p 加重唇部误差。训练采用 Adam 和固定学习率 2×10⁻⁴；全部网络层采用随机正态初始化（论文原文写作 random normalization），mean=0.0、std=0.2。
Card 05 数据集与资源

数据集与资源

  • 数据集：核心定量与定性数据是 LRW 和 GRID：前者是野外多说话人单词视频，后者是受控条件下的视听语料。
  • 数据集：跨来源可视化和用户研究还取样 VoxCeleb、TCD 与 YouTube，并把真实人物、卡通角色以及训练数据之外的身份图作为泛化输入。
  • 规模与划分：论文沿用 LRW 原工作的训练—测试划分；LRW 含 500 个不同单词。GRID 写明 1000 段短视频、33 位说话人。人脸以 25FPS 采样并缩放到 128×128；每个音频片段为 280ms，以 10ms 窗提取 MFCC，去掉首系数后得到 28×12 特征。
  • 模型：模型资源是论文自建的 AT-net 与 VG-net，定量表说明论文自己的模型均从头训练。架构、实验设置及参考文献尾部未给出参数量，也未把外部预训练网络作为 ATVGnet 的基础模型。
  • 硬件：所有模型均在单张 NVIDIA GTX 1080Ti 上训练和测试；AT-net 约 3 小时收敛，VG-net 约 24 小时稳定。
  • 代码：论文正文明确称代码已经发布，地址为 https://github.com/lelechen63/ATVGnet；顶层 code_url 仍按给定目录元数据逐字保留为空。
  • 训练平台：实现平台为 PyTorch 0.4，并用 Dlib 提取的眼、鼻关键点对齐人脸。论文实验设置、结论及参考文献尾部没有报告机器人、实车或仿真器平台；这是离线人脸视频生成流水线。
Card 06 评估与结果

评估与结果

  • 评估基准：主定量与定性基准是 LRW 和 GRID；视频级用户研究扩展到 VoxCeleb、TCD、GRID、LRW 与 YouTube，另用地标噪声和不同身份姿态检查稳健性。
  • 评估指标：PSNR 和 SSIM 衡量单帧图像质量，越高越好；LMD 衡量口型地标与音频对应的误差，越低越好；FPS 越高表示推理越快。用户研究对真实性和音画同步按 0（最差）到 10（最佳）评分，越高越好。
  • 对比方法：主定量表比较 Chen、Wiles、Chung、无附加组件的 Baseline，以及未采用解耦训练的 ATVG-ND；速度表还比较 Zhou，用户研究则比较 Chung 与 Zhou。
  • 关键结果：推理速度表中，ATVGnet 为 34.53 FPS，高于实时参照 30 FPS；Chung、Zhou、Wiles 分别为 19.10、10.00、10.53 FPS。
  • 关键结果：LRW 主表中，ATVGnet 的 LMD、SSIM、PSNR 为 1.37、0.81、30.91；图像质量两项为表中最高，但 LMD 并非最低，ATVG-ND 的 1.35 更低（LMD 越低越好）。
  • 关键结果：GRID 主表中，ATVGnet 的 LMD、SSIM、PSNR 为 1.29、0.83、32.15，三项均为表中领先值。
  • 关键结果：视频级用户研究中，作者报告 ATVGnet 的音画同步在全部数据来源上最高、真实性在大多数来源上最高；明确例外是 VoxCeleb 测试集的真实性略低于 Chung。
  • 消融实验：在输入真值地标的消融口径下，完整模型在 LRW 的 LMD、SSIM、PSNR 为 0.80、0.86、33.45，在 GRID 为 0.70、0.89、33.84；去掉 DMA 后分别变为 0.98、0.83、30.22 和 1.10、0.84、29.90，去掉 MMCRNN 后为 1.03、0.80、30.61 和 0.81、0.86、32.68。
  • 消融实验：其余检查显示，去掉 DAL 或 RD 也会降低部分指标；以上一假帧递归条件化的 ATVG-P 因误差随时间放大而退化。向生成地标加入更大标准差的高斯噪声会让主观图像质量下降，而同一语音配不同姿态身份图仍表现出姿态鲁棒性。
  • 实验条件：主定量表中的论文模型从头训练；对比方法均在 LRW 训练，其中 Chung 额外使用在 VGG Face 上预训练的 VGG-M，Wiles 额外使用预训练 MFCC 提取器。用户研究随机抽取 38 段视频，由 10 名参与者在打乱方法标识后盲评；消融输入真值地标而非 AT-net 预测，以隔离地标噪声。
