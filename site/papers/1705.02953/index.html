Temporal Segment Networks for Action Recognition in Videos

2017-05-08 · 原文 · 翻译 · 1705.02953

论文要解决的是深度视频动作识别只看单帧或短片段、难以覆盖整段视频长期结构的问题；TSN 用稀疏且全局的分段采样，把整段视频的信息纳入端到端学习，同时让采样计算量不随视频时长增长。 使用场景同时覆盖已裁剪动作片段和含大量背景的未裁剪长视频：前者聚合多片段分类分数，后者用多尺度时间窗口覆盖不同位置和时长的动作，再抑制无关背景并输出视频类别。 论文真正检验的研究问题有三层：长期时间结构能否被有效学习；同一动作模型能否用于更现实的未裁剪视频；在标注样本有限、光流代价高时，训练与大规模应用能否兼顾准确率和效率。 研究背景：视频动作识别依赖互补的外观与时间动态线索，但尺度变化、视角变化和相机运动使两类信息的提取与利用并不直接；当时端到端 ConvNet 相对手工特征带来的提升仍然有限。 核心痛点：现有深度方法多聚焦单帧或至多 10 帧左右的短期运动；用固定间隔密集采样延长时间范围会增加长视频计算与显存压力。未裁剪视频又常由背景占主导，有限规模数据易过拟合，而光流提取成为大规模部署瓶颈。 任务定义：输入是一段已裁剪或未裁剪视频；TSN 将其切成若干等时长片段，每段随机抽取一个短 snippet，由共享 ConvNet 产生类别分数，经分段共识与 Softmax 得到整段视频的动作类别概率。对未裁剪视频，再以多尺度时间滑窗和窗口级聚合形成最终视频预测。 研究目标：目标不是单纯加深骨干网络，而是在固定的稀疏采样预算下让训练覆盖完整视频，并验证分段数、聚合函数与训练实践能否同时改善裁剪和未裁剪视频识别，同时保持可部署的计算效率。

Card 02 论文概述

论文概述

  • 论文要解决的是深度视频动作识别只看单帧或短片段、难以覆盖整段视频长期结构的问题；TSN 用稀疏且全局的分段采样，把整段视频的信息纳入端到端学习，同时让采样计算量不随视频时长增长。
  • 使用场景同时覆盖已裁剪动作片段和含大量背景的未裁剪长视频：前者聚合多片段分类分数，后者用多尺度时间窗口覆盖不同位置和时长的动作，再抑制无关背景并输出视频类别。
  • 论文真正检验的研究问题有三层：长期时间结构能否被有效学习；同一动作模型能否用于更现实的未裁剪视频；在标注样本有限、光流代价高时，训练与大规模应用能否兼顾准确率和效率。
  • 研究背景：视频动作识别依赖互补的外观与时间动态线索，但尺度变化、视角变化和相机运动使两类信息的提取与利用并不直接；当时端到端 ConvNet 相对手工特征带来的提升仍然有限。
  • 核心痛点：现有深度方法多聚焦单帧或至多 10 帧左右的短期运动；用固定间隔密集采样延长时间范围会增加长视频计算与显存压力。未裁剪视频又常由背景占主导，有限规模数据易过拟合，而光流提取成为大规模部署瓶颈。
  • 任务定义：输入是一段已裁剪或未裁剪视频；TSN 将其切成若干等时长片段，每段随机抽取一个短 snippet，由共享 ConvNet 产生类别分数，经分段共识与 Softmax 得到整段视频的动作类别概率。对未裁剪视频，再以多尺度时间滑窗和窗口级聚合形成最终视频预测。
  • 研究目标：目标不是单纯加深骨干网络，而是在固定的稀疏采样预算下让训练覆盖完整视频，并验证分段数、聚合函数与训练实践能否同时改善裁剪和未裁剪视频识别，同时保持可部署的计算效率。
Card 03 核心贡献

核心贡献

  • 提出视频级 TSN：把整段视频等分后稀疏抽取 snippet，再以分段共识联合学习，从而在固定采样成本下建模长期时间结构。
  • 系统定义并分析最大池化、平均池化、线性加权、top-K 池化与注意力加权五类共识函数，使模型能在全片段利用和抑制背景之间选择。
  • 为未裁剪视频提出多尺度时间窗口集成 M-TWI：先在多种时长窗口内取类别最大响应，再跨窗口与尺度聚合，以处理动作位置、持续时间和背景干扰。
  • 给出有限样本下的完整训练与输入实践，包括跨模态初始化、partial BN、高比例 dropout、裁剪增强，以及用 RGB difference 取代昂贵光流的实时方案。
Card 04 方法描述

方法描述

  • 所属模块：TSN 是训练阶段的视频级封装：用分段采样把长视频变成少量 snippet，并以共识函数形成可反传的视频级监督；M-TWI 则是未裁剪视频推理层，在已学得的 TSN 动作模型之上选择和整合可能含动作的时间窗口。
  • 输入与表示：每个 snippet 可由四种模态表示：单张 RGB 图像、连续帧的 stacked RGB differences、堆叠 optical-flow fields、以及补偿相机运动的 stacked warped optical-flow fields。RGB 负责外观，后三者提供运动线索；各模态分别预测后再融合。
  • 模型结构：给定视频 V，先等分为 K 个片段 S；从每个片段抽取 Tk。共享参数 W 的 ConvNet F(Tk;W) 为各 snippet 输出类别分数，分段共识 G 将所有分数汇总，预测函数 H 采用 Softmax 输出视频级类别概率；所有 snippet 分支共享网络参数，多个模态的预测最后再融合。
  • 数据流：训练时依次执行全视频分段、每段随机抽样、模态构造、共享骨干打分、共识聚合、Softmax 与视频级交叉熵，并把所有 snippet 的梯度共同传回 W。裁剪视频测试时均匀采样 25 个 snippets，对角点、中心及翻转裁剪求平均。未裁剪视频按 1 FPS 取样，使用长度为 1、2、4、8、16 秒且步长为 0.8 × l 的窗口；窗口内按类别取最大值，同长度窗口再以 top-K 聚合，其中 K=max(15,⌈N_l/4⌉)，最后平均各尺度预测。
  • 关键技术：共识层提供 max、average、top-K、linear weighting 与内容自适应 attention weighting；训练侧把 RGB 预训练首层权重跨通道求均值并复制到光流或 RGB-difference 输入，partial BN 只更新首个 BN 层的统计量，其余层冻结，并在全局池化后使用 0.8 dropout；corner cropping 与 scale jittering 进一步正则化。
  • 公式与超参数：核心前向式为 TSN(T1,…,TK)=H(G(F(T1;W),…,F(TK;W)))：W 是各 snippet 共享的 ConvNet 参数，G 聚合各段类别分数，H 取 Softmax 得视频概率。类别交叉熵写为 L=-Σ_i y_i(g_i-log Σ_j exp(g_j))，其中 C 是类别数、y_i 是真值标签、g_j 是共识分数。实现采用 mini-batch SGD，batch size 128、momentum 0.9；UCF101 空间流初始学习率 0.001，每 1, 500 次迭代衰减并在 3, 500 次停止；时间流初始学习率 0.005，在 12, 000 与 18, 000 次衰减，20, 000 次停止；后续实验默认 K=7。
Card 05 数据集与资源

数据集与资源

  • 数据集：UCF101：已裁剪动作视频基准，按官方多划分协议评测。
  • 数据集：HMDB51：来自电影与网络等多来源的已裁剪真实动作视频基准。
  • 数据集：THUMOS14：包含训练、验证、测试和背景集合的未裁剪视频基准。
  • 数据集：ActivityNet v1.2：大规模未裁剪人类活动视频基准。
  • 规模与划分：UCF101 有 101 类、13, 320 个视频片段，采用三个训练/测试划分；HMDB51 有 51 类、6, 766 个视频片段，也采用三个划分并报告平均准确率。THUMOS14 用 UCF101 训练集与 1, 010 个验证视频训练，在 1, 575 个测试视频上评估；ActivityNet v1.2 有 100 类，训练、验证、测试分别为 4, 819、2, 383、2, 480 个视频。
  • 模型：消融实验采用兼顾精度与效率的 BN-Inception（inception v2）骨干，ActivityNet 挑战还实例化 Inception V3 与 ResNet-152；网络以 ImageNet 模型预训练。正文的架构与实现章节均未给出这些模型的参数规模。
  • 硬件：UCF101 训练使用 8 块 TITANX GPU：空间 TSN 约 0.6 小时、时间 TSN 约 8 小时；速度表也在 TitanX GPU 上测试。挑战模型在单节点 8 块 TitanX GPU 上可于 10 小时内训练完成。
  • 代码：论文明确声明方法代码与已训练模型公开，并在脚注给出 https://github.com/yjxiong/temporal-segment-networks/；其多 GPU Caffe 修改版另给出 https://github.com/yjxiong/caffe。
  • 训练平台：实现平台是修改版 Caffe 加 OpenMPI 的多 GPU 数据并行；光流与 warped optical flow 使用 OpenCV CUDA 实现的 TV-L1。正文实验设置与结论均是离线视频分类，没有报告仿真器、机器人或实车平台。
Card 06 评估与结果

评估与结果

  • 评估基准：HMDB51 与 UCF101：裁剪视频动作分类。
  • 评估基准：THUMOS14 与 ActivityNet v1.2：含大量背景的未裁剪视频动作分类。
  • 评估指标：HMDB51 与 UCF101 使用多划分平均分类准确率，越高越好。
  • 评估指标：THUMOS14 与 ActivityNet 使用 mean average precision（mAP），越高越好。
  • 对比方法：裁剪视频对比手工表示 iDT+FV、MoFAP，以及 Two Stream、C3D、TDD+FV、LTC、KVMF 等深度方法。
  • 对比方法：未裁剪视频对比 iDT、Two-Stream ConvNet、enhanced motion vector、3D ConvNet、object+motion 与 Depth2Action。
  • 对比方法：实时方案另与 Enhanced MV 和 Two-Stream 3DNet 比较识别准确率与 FPS。
  • 关键结果：HMDB51 上 TSN（7 segments）为 71.0%，对比 MPR 的 65.5%，作者称高 5.5%（按准确率差即五点五个百分点，越高越好）。
  • 关键结果：UCF101 上 TSN（7 segments）为 94.9%，对比 KVMF 的 93.1%，作者称高 1.8%（按准确率差即一点八个百分点，越高越好）。
  • 关键结果：THUMOS14 上 TSN（7 segments）达到 80.1% mAP，对比 object+motion 的 71.6%，作者称高 8.5%（按表中差值即八点五个百分点）。
  • 关键结果：ActivityNet v1.2 上 TSN（7 segments）达到 89.6% mAP，对比 Depth2Action 的 78.1%，作者称高 11.5%（按表中差值即十一点五个百分点）。
  • 关键结果：RGB+RGB Diff. 的 TSN 在 UCF101 达到 91.0% 准确率和 340 FPS，属于离线分类模型的高速推理结果。
  • 关键结果：ActivityNet 2016 挑战测试集上，作者团队在 24 支队伍中排名第一，mAP 为 93.23%，top-one accuracy 为 88.14%。
  • 消融实验：UCF101 split 1 的 two-stream 准确率从仅预训练空间流的 90.0%，升至加入跨模态初始化的 91.5%，再由 partial BN 与 dropout 提升到 92.0%。
  • 消融实验：UCF101 上分段数 K=1 时 two-stream 为 92.4%，K=7 时为 94.9%，K=9 仍为 94.9%，说明收益在更多分段后趋于饱和。
  • 消融实验：共识函数消融中，UCF101 的 average pooling 最佳为 94.9%；ActivityNet 上 average pooling 为 87.8%，top-K 为 88.1%，attention weighting 为 88.2%，复杂聚合更适合未裁剪背景。
  • 实验条件：主结果均为离线、监督式视频分类，而非零样本或闭环控制：裁剪集以 RGB 与 optical flow 等权融合，TSN 取 3 段或 7 段并使用平均共识；未裁剪集使用 top-K 共识与 M-TWI，主对比采用 train+val 训练、test 评估。
