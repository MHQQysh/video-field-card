Zooming Slow-Mo: Fast and Accurate One-Stage Space-Time Video Super-Resolution

2020-02-27 · 原文 · 翻译 · 2002.11616

Card 02 论文概述

论文概述

  • 解决低分辨率、低帧率视频同时提升空间分辨率和时间帧率的问题，直接生成细节清晰、运动连续的高分辨率慢动作视频。
  • 面向电影制作和高清电视等需要细节清晰、运动动态可辨的慢动作视频场景；输入只有稀疏低清帧，输出连续高帧率高清序列。
  • 核心检验是：把时间插帧和空间超分辨率放进共享的单阶段网络，并在特征层利用局部与全局时序上下文，能否比串联 VFI 与 VSR 的两阶段方案更准确且更高效，尤其是在快速大运动视频上。
  • 研究背景：时空视频超分辨率（STVSR）要从低分辨率、低帧率输入恢复高时空分辨率视频；传统手工正则方法依赖强假设，对复杂多样的时空视觉模式建模能力有限，而且优化代价高。
  • 核心痛点：把 VFI 插帧网络与 VSR 超分网络串联，会把本来相互关联的时间插值和空间超分拆开，无法共享这种关联；两边又各自需要大型帧合成或重建模块，造成参数量大、计算耗时，并且显式光流对齐容易受到光流误差与 warping 伪影影响。
  • 任务定义：给定低分辨率、低帧率视频序列，任务要生成对应的高分辨率、高帧率慢动作序列；输入只在间隔时刻有 LR 观测，缺失的中间时刻没有 LR 对应帧，因而必须同时补全时间与空间信息。
  • 研究目标：学习一个端到端的单阶段序列到序列映射，不显式合成中间 LR 图像，而是在特征层插值并聚合时序上下文，以兼顾重建质量、复杂运动处理能力和计算效率。
Card 03 核心贡献

核心贡献

  • 提出统一的单阶段 STVSR 框架，同时完成时间插值和空间超分，只需一个帧重建网络，利用两个子问题的内在关联降低两阶段组合的冗余。
  • 提出基于可变形采样的帧特征时间插值网络，在没有中间 LR 帧显式监督时从相邻特征提取局部时序上下文，并合成缺失时刻的 LR 特征。
  • 提出带显式可变形状态对齐的双向 ConvLSTM，使上一时刻的隐藏状态和细胞状态先对齐当前特征，再聚合前向与后向的全局时序信息。
  • 以 Vid4 和 Vimeo 上的定量、定性及效率实验验证单阶段设计，并在论文中明确给出源码发布地址。
Card 04 方法描述

方法描述

  • 所属模块：单阶段框架由特征提取器、帧特征时间插值模块、双向可变形 ConvLSTM 和 HR 帧重建器组成：前两者生成完整的 LR 特征序列，中间模块对齐并聚合全局时间上下文，重建器输出 HR、HFR 帧。
  • 输入与表示：输入为 n+1 个 LR 帧，张量大小为 (n+1)×3×W×H；共享特征提取器把每帧编码为 64×W×H，插值后形成 2n+1 个特征，目标输出为 (2n+1)×3×4W×4H 的 HR 帧序列。
  • 模型结构：特征提取端先用 3×3、3→64、stride=1 卷积，再堆叠 x5 个 3×3、64 通道残差块；重建端堆叠 40 个残差块，用两次 3×3、64→256 卷积加 PixelShuffle(scale=2) 完成 4× 上采样，再以 3×3、64→3 卷积输出 RGB。
  • 数据流：输入的间隔时刻 LR 帧先由时间共享的提取器独立编码；每对相邻特征经双向可变形采样与融合得到缺失时刻特征；按时间排序后的完整特征序列进入双向可变形 ConvLSTM，前向和后向隐藏状态拼接；每个聚合后的隐藏状态再由时间共享的重建器独立变成 HR 帧。
  • 关键技术：DFI 将左右相邻特征按通道拼接来预测两组可变形卷积偏移，分别采样两侧特征，再用可学习的 1×1 卷积核 α、β 线性融合；实际 deformable sampling 采用 PCD 金字塔、级联、可变形结构，以利用多尺度上下文。
  • 公式与超参数：插值公式可写为 F_mid^L=α*T_left(F_left^L,Φ_left)+β*T_right(F_right^L,Φ_right)，其中 T 是可变形采样、α 与 β 是融合核；状态更新先由当前特征与上一隐藏/细胞状态预测偏移，再用 DConv 对齐后送入 ConvLSTM。训练采用 Charbonnier 损失，对预测与真值的 L2 误差加 epsilon 的平方后开方，epsilon=1 × 10−3；k1=5、k2=40，batch size 为 24，Adam 学习率按 cosine annealing 从 4e − 4 衰减到 1e − 7。
Card 05 数据集与资源

数据集与资源

  • 数据集：Vimeo-90K 是训练集，含超过 60,000 个 7 帧训练序列；Vid4 与 Vimeo testset 是评估集。
  • 规模与划分：训练随机裁剪 32×32 的下采样序列，取奇数索引的 4 帧作为 LR、LFR 输入，以连续 7 帧、4× 空间尺度的 HR 序列监督。初始 Vimeo motion 子集含 fast 1,225、medium 4,977、slow 1,613 个 clips；随后从 medium 移除 5 个、从 slow 移除 3 个全黑 clips。
  • 模型：模型是论文自建的单阶段 STVSR 架构，Ours 参数量为 11.10 million；实现细节与附录网络结构均未报告外部基础模型名称或预训练权重。
  • 硬件：训练使用 2 张 Nvidia Titan XP GPU；模型大小和整套 Vid4 推理时间在单张 Nvidia Titan XP GPU 上测量。正文与附录未报告其他训练或推理硬件。
  • 代码：论文称源码已发布于 https://github.com/Mukosame/Zooming-SlowMo-CVPR-2020；目录元数据的 code_url 字段仍按输入记录继承为空。
  • 训练平台：实验是 Vimeo-90K、Vid4 与 Vimeo testset 上的离线视频恢复训练和评估；全文及附录没有使用仿真器、机器人或实车平台。
Card 06 评估与结果

评估与结果

  • 评估基准：Vid4 测试集以及按 fast、medium、slow motion 划分的 Vimeo testset；总运行时间另在完整 Vid4 上统计。
  • 评估指标：质量用 PSNR 与 SSIM（越高越好）；效率用参数量、完整 Vid4 总耗时和平均每帧耗时（越低越好），运行时间在单张 Nvidia Titan XP GPU 上测量。
  • 对比方法：两阶段基线由 SuperSloMo、SepConv、DAIN 三种 VFI 与 Bicubic、RCAN、RBPN、EDVR 四种 SR 组合；论文将 DAIN+EDVR 识别为所比较方法中表现最好的两阶段方案。
  • 关键结果：Ours 在 Vid4 上为 26.31 dB、0.7976 SSIM，在 Vimeo-Fast 上为 36.81 dB、0.9415，在 Vimeo-Medium 上为 35.41 dB、0.9361，在 Vimeo-Slow 上为 33.36 dB、0.9138；PSNR 与 SSIM 均越高越好。
  • 关键结果：相对 DAIN+EDVR，Ours 的 PSNR 在 Vid4、Vimeo-Slow、Vimeo-Medium、Vimeo-Fast 分别高 0.19dB、0.25dB、0.75dB 和 1dB（越高越好）。
  • 关键结果：Ours 为 11.10 million 参数，在整套 Vid4 上总耗时 10.36 s、平均 0.0606 s/frame；DAIN+EDVR 为 24.0+20.7 million 参数、总耗时 32.88 s、平均 0.1923 s/frame，因此 Ours 的模型更小且推理更快。
  • 消融实验：将 naive 插值换成 DFI 后，Vid4 PSNR 从 25.18 升至 25.34 dB（+0.16dB），Vimeo-Fast 从 34.93 升至 35.66 dB（+0.73dB）；PSNR 越高越好。
  • 消融实验：在 Vimeo-Fast 上，DFI+vanilla ConvLSTM 为 35.39 dB，低于仅 DFI 的 35.66 dB；DConvLSTM 提升到 36.56 dB，双向 DConvLSTM 达 36.81 dB，显示显式状态对齐和双向上下文对快运动更有效。
  • 实验条件：这是端到端监督训练后的离线数据集视频重建评估，不是零样本、闭环控制、仿真或实车实验，也未报告从外部基础模型微调。LR 以 bicubic 按 4 倍下采样生成，使用奇数索引 LR 帧预测连续 HR、HFR 帧；batch size 为 24，Adam 采用 cosine annealing，训练使用 2 张 Nvidia Titan XP GPU。
