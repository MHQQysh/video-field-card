AutoLoc: Weakly-supervised Temporal Action Localization

2018-07-22 · 原文 · 翻译 · 1807.08333

问题：现有弱监督时序动作定位只学习时间上的类别激活序列（CAS），再以阈值切段；CAS 内部的低谷会把一个动作切碎，阈值过低又会把前后背景并入。AutoLoc 改为直接回归动作片段的中心与时长。 场景：训练集中的未裁剪视频只有视频级动作标签，没有每个实例的起止边界；部署到测试视频时，系统仍须为每个动作实例输出类别、开始时间、结束时间与置信度。 研究问题：能否用 CAS 自动产生足以训练参数化边界预测器的片段级监督，使仅用视频级标签训练的模型摆脱阈值定位，并在标准 TAL 基准上接近甚至超过部分全监督方法？ 研究背景：全监督 TAL 需要为长且含大量背景的未裁剪视频逐实例标注动作类别、开始时间和结束时间，建立新大规模数据集时成本高、耗时长，因此论文转向只依赖视频级标签的弱监督训练。 核心痛点：已有弱监督方法主要训练分类器生成 CAS，测试时再阈值化：高阈值会把含激活低谷的同一实例切成多段，低阈值则会把动作前后的无关背景纳入，因而对 CAS 噪声不稳健。 任务定义：每个训练样本是一段未裁剪视频，训练监督只有该视频包含哪些动作；测试输出是按实例给出的动作类别、起止时间与置信度，正确检测还须类别正确且时间 IoU 超过评测门限。 研究目标：目标是在没有训练边界真值时学习可参数化的直接边界预测器：从 CAS 的片段内外激活反差自动发现片段级监督，以多尺度锚点和边界回归替代阈值切段。

Card 02 论文概述

论文概述

  • 问题：现有弱监督时序动作定位只学习时间上的类别激活序列（CAS），再以阈值切段；CAS 内部的低谷会把一个动作切碎，阈值过低又会把前后背景并入。AutoLoc 改为直接回归动作片段的中心与时长。
  • 场景：训练集中的未裁剪视频只有视频级动作标签，没有每个实例的起止边界；部署到测试视频时，系统仍须为每个动作实例输出类别、开始时间、结束时间与置信度。
  • 研究问题：能否用 CAS 自动产生足以训练参数化边界预测器的片段级监督，使仅用视频级标签训练的模型摆脱阈值定位，并在标准 TAL 基准上接近甚至超过部分全监督方法？
  • 研究背景：全监督 TAL 需要为长且含大量背景的未裁剪视频逐实例标注动作类别、开始时间和结束时间，建立新大规模数据集时成本高、耗时长，因此论文转向只依赖视频级标签的弱监督训练。
  • 核心痛点：已有弱监督方法主要训练分类器生成 CAS，测试时再阈值化：高阈值会把含激活低谷的同一实例切成多段，低阈值则会把动作前后的无关背景纳入，因而对 CAS 噪声不稳健。
  • 任务定义：每个训练样本是一段未裁剪视频，训练监督只有该视频包含哪些动作；测试输出是按实例给出的动作类别、起止时间与置信度，正确检测还须类别正确且时间 IoU 超过评测门限。
  • 研究目标：目标是在没有训练边界真值时学习可参数化的直接边界预测器：从 CAS 的片段内外激活反差自动发现片段级监督，以多尺度锚点和边界回归替代阈值切段。
Card 03 核心贡献

核心贡献

  • 提出 AutoLoc：仅用视频级标签训练，却在片段层面直接预测每个动作实例的时间边界，而不是在测试时对 CAS 做阈值切段。
  • 提出可微的 Outer-Inner-Contrastive（OIC）损失，以预测片段内部与其外部上下文的激活反差自动构造训练边界预测器所需的片段级监督。
  • 在 THUMOS’14 与 ActivityNet 两个标准基准上验证该框架，弱监督结果显著超过当时的弱监督方法，并与部分使用边界标注训练的全监督方法相当。
Card 04 方法描述

方法描述

  • 所属模块：AutoLoc 在共享的逐 snippet 特征上并行滑动两条分支：分类分支的 Activation Generator S 产生每类 CAS；定位分支的 Boundary Predictor B 产生与类别无关的候选边界；OIC 层用真实视频级动作对应的 CAS 为候选片段计分、筛选，并把损失反传给 B。
  • 输入与表示：输入视频被切成互不重叠的 15 帧 snippet。预训练的双流 UntrimmedNet/TSN 骨干分别从 RGB 与 Optical Flow 的 Inception-BN global-pool 层取 1024 维特征，拼接为每个 snippet 的 2048 维向量；含 T 个 snippet 的视频形成 2048×T 特征图。
  • 模型结构：B 接收 2048×T 特征图，先堆叠 3 个时间卷积层；每层有 128 个滤波器，时间核大小 3、stride 1、padding 1，随后接 Batch Normalization 与 ReLU。末端 pred 时间卷积用 2M 个滤波器，为 M 种锚点各输出中心偏移 t_x 和长度缩放 t_w，且预测与类别无关。
  • 数据流：在每个时间位置 s_x 生成长度 w_a 的多尺度锚点；B 输出 t_x、t_w 后计算 c_x=s_x+w_a·t_x 与 w=w_a·exp(t_w)，再得内边界 x_1=c_x-w/2、x_2=c_x+w/2。内边界按比例向两侧扩成外边界，OIC 依据对应类别 CAS 的内外均值差保留候选；最终把 snippet 边界换算为时间，输出类别、置信度和起止时间。
  • 关键技术：OIC 让片段内部激活高、紧邻外部激活低；训练时只遍历视频真值动作，测试时遍历所有动作。CAS 激活低于 0.1 的位置整组丢弃，每个位置只留 OIC 最小的锚点，再删除 OIC 大于 -0.3 的片段，并以 IoU 0.4 做 NMS；短片段的外边界至少各外扩一个 snippet，越界时在视频两端补零后裁剪。
  • 公式与超参数：核心目标为 L_OIC(φ)=A_o(φ)-A_i(φ)，即外环平均激活减内段平均激活，且论文给出对内外边界可反传的梯度。边界膨胀率 α=0.25；分类注意力门限为 7，CAS/OIC/NMS 的筛选门限依次为 0.1、-0.3、0.4。SGD 初始学习率 0.001，THUMOS’14 每 200 次迭代、ActivityNet 每 500 次迭代降低一个数量级，weight decay 为 0.0005；论文称两数据集的训练过程约 1 个 epoch 后可快速收敛。锚点长度在 THUMOS’14 为 1、2、4、8、16、32，在 ActivityNet 为 16、32、64、128、256、512。
Card 05 数据集与资源

数据集与资源

  • 数据集：THUMOS’14：时间定位任务含 20 类动作；使用 validation 的 200 段未裁剪视频训练，在含 213 段视频的 test 上评测。
  • 数据集：ActivityNet release 1.2：含 100 类活动；training 有 4,819 段视频，validation 有 2,383 段视频，前者训练、后者测试。
  • 规模与划分：主实验严格采用 THUMOS’14 validation→test（200→213 段视频）与 ActivityNet release 1.2 training→validation（4,819→2,383 段视频）；补充材料的 α 网格搜索则分别在各数据集训练划分上训练并同划分评估，不能与主测试结果混用。
  • 模型：先预训练 soft 版 UntrimmedNet，并以 TSN 双流 Inception-BN 网络作为 RGB/光流特征骨干；论文的正文模型说明与补充材料均未给出 AutoLoc 的总参数量。
  • 硬件：训练使用一块 NVIDIA GeForce GTX TITAN X GPU，软件栈为 CUDA 8.0 与 cuDNN v5；正文实验设置及补充材料未报告 CPU、内存或单次训练时长。
  • 代码：论文首页脚注明确给出源码与模型地址：https://github.com/zhengshou/AutoLoc。
  • 训练平台：实现框架为 Caffe；实验对象是两个离线视频基准，正文实验设置与补充材料未使用或报告仿真器、机器人、实车平台。
Card 06 评估与结果

评估与结果

  • 评估基准：THUMOS’14 temporal action localization：validation 训练、test 测试。
  • 评估基准：ActivityNet release 1.2 temporal localization：training 训练、validation 测试。
  • 评估指标：时间定位 mAP（越高越好）：预测类别须正确且预测片段与真值片段的时间 IoU 超过指定阈值；同一真值不允许重复检测。
  • 对比方法：THUMOS’14 同时比较仅视频级监督的 Sun et al.、Hide-and-Seek、Wang et al.，以及使用边界标注的 S-CNN、R-C3D、SSN 等全监督方法。
  • 对比方法：ActivityNet release 1.2 的主表比较弱监督 Wang et al. 与 AutoLoc，并列出全监督 SSN 作为参照。
  • 关键结果：THUMOS’14 test 在 IoU 0.5 时，AutoLoc 的 mAP 为 21.2%，高于弱监督 Wang et al. 的 13.7%（mAP 越高越好）。
  • 关键结果：ActivityNet release 1.2 validation 在 IoU 0.5 时，AutoLoc 与 Wang et al. 的 mAP（单位：%）为 27.3 与 7.4；跨 IoU 0.5–0.95 的 Avg mAP 为 16.0 与 3.6。
  • 关键结果：同一 ActivityNet 主表中，全监督 SSN 在 IoU 0.5 与 Avg 上的 mAP（单位：%）为 41.3 和 26.6，而弱监督 AutoLoc 为 27.3 和 16.0，说明这里仍有明显全监督差距。
  • 消融实验：ActivityNet validation 上，Avg mAP（单位：%）中枚举片段再用 OIC 选择为 8.5，高于 Wang et al. 的 3.6，但低于完整 AutoLoc 的 16.0。
  • 消融实验：把 OIC 换成只奖励内部激活的 Inner Only Loss 后，Avg mAP（单位：%）从 AutoLoc 的 16.0 降至 1.6，表明外部上下文对比是关键。
  • 消融实验：逐测试视频直接优化边界的 Avg mAP（单位：%）为 12.6，低于 AutoLoc 的 16.0；它需 25 次前向与 25 次反向迭代，而 AutoLoc 测试只需一次前向。
  • 消融实验：补充网格搜索在 THUMOS’14 validation 上选择 α=1/4：IoU 0.6 时 mAP（单位：%）为 17.9，而 α=1/2 与 α=1/8 分别为 16.5 和 16.4。
  • 消融实验：ActivityNet training 同划分搜索中，α=1/4 的 Avg mAP（单位：%）为 17.4，α=1/2 与 α=1/8 分别为 17.1 和 17.2；这些是调参结果而非 validation 主结果。
  • 实验条件：所有主结果都是离线视频 TAL：训练阶段只用视频级标签，评测阶段才用带边界真值计算 mAP。THUMOS’14 按 validation 训练、test 测试，ActivityNet release 1.2 按 training 训练、validation 测试；不是零样本，也没有机器人闭环或实车评测口径。
