V4D:4D Convolutional Neural Networks for Video-level Representation Learning

2020-02-18 · 原文 · 翻译 · 2002.07442

这篇论文解决的是片段级 3D CNN 看不到整段视频演化的问题：短片段各自预测、末端再平均，会丢掉动作阶段之间的细粒度联系以及跨片段的长程时空依赖。 实际使用场景是离线 RGB 视频动作分类。模型从完整视频均匀覆盖地抽取多个短时动作单元，既保留每个单元中的局部动作细节，又输出一个整段视频级的类别预测。 论文真正检验的研究问题是：在保留成熟 3D 主干短时表征的前提下，加入跨动作单元的 4D 卷积残差交互，能否比只做晚期平均的方案更好地建模全局时序，同时迁移到外观主导、运动主导和未剪辑视频。 研究背景：视频表征常把二维卷积扩展为 3D CNN，但受显存与计算量限制，实际训练通常只随机取一个短片段；推理再对不同片段的分类分数作平均。因此强大的短时表征并不自动等于完整视频表征。 核心痛点：片段只覆盖整段视频的一小部分，局部观察可能不足以辨别动作；简单平均会抹平片段之间的顺序与互动。TSN 虽然稀疏覆盖完整视频，却到很晚才融合分数，仍难捕捉细粒度时间结构。 任务定义：输入是一段 RGB 视频，将其均匀分成若干时间区段并从每段取得一个动作单元；每个单元是通道、局部时间、高、宽构成的张量。网络需要联合这些单元，输出整段视频的动作类别预测。 研究目标：目标不是延长单个片段，而是在高一维的动作单元轴上直接学习多个短时 3D 特征的演化；残差路径保留局部特征，4D 路径负责跨单元交互，从而兼顾短时细节和长程结构。

Card 02 论文概述

论文概述

  • 这篇论文解决的是片段级 3D CNN 看不到整段视频演化的问题：短片段各自预测、末端再平均，会丢掉动作阶段之间的细粒度联系以及跨片段的长程时空依赖。
  • 实际使用场景是离线 RGB 视频动作分类。模型从完整视频均匀覆盖地抽取多个短时动作单元，既保留每个单元中的局部动作细节，又输出一个整段视频级的类别预测。
  • 论文真正检验的研究问题是：在保留成熟 3D 主干短时表征的前提下，加入跨动作单元的 4D 卷积残差交互，能否比只做晚期平均的方案更好地建模全局时序，同时迁移到外观主导、运动主导和未剪辑视频。
  • 研究背景：视频表征常把二维卷积扩展为 3D CNN，但受显存与计算量限制，实际训练通常只随机取一个短片段；推理再对不同片段的分类分数作平均。因此强大的短时表征并不自动等于完整视频表征。
  • 核心痛点：片段只覆盖整段视频的一小部分，局部观察可能不足以辨别动作；简单平均会抹平片段之间的顺序与互动。TSN 虽然稀疏覆盖完整视频，却到很晚才融合分数，仍难捕捉细粒度时间结构。
  • 任务定义：输入是一段 RGB 视频，将其均匀分成若干时间区段并从每段取得一个动作单元；每个单元是通道、局部时间、高、宽构成的张量。网络需要联合这些单元，输出整段视频的动作类别预测。
  • 研究目标：目标不是延长单个片段，而是在高一维的动作单元轴上直接学习多个短时 3D 特征的演化；残差路径保留局部特征，4D 路径负责跨单元交互，从而兼顾短时细节和长程结构。
Card 03 核心贡献

核心贡献

  • 提出整体视频采样策略：把完整时长均匀划分为 U 个区段，训练时每段随机取动作单元，测试时取区段中心，使有限输入仍覆盖全视频。
  • 定义作用于 (C,U,T,H,W) 表示的 4D 卷积，并利用线性求和可交换性把它实现为现有库可执行的 3D 卷积序列，从而显式学习跨片段交互。
  • 设计可插入现有 3D CNN 的 Residual 4D Block：交换通道轴与动作单元轴、执行 4D 卷积、恢复轴序并与原 3D 特征相加，实现分层长短期融合。
  • 给出训练与视频级推理协议：共享主干并行编码各单元，在首个 4D Block 处分割网络，推理时重组更多单元形成多组视频表征，再平均组级预测。
  • 用三个主动作识别基准验证剪辑视频分类，并在附录增加 ActivityNet 未剪辑视频实验和 CAM 可视化，覆盖外观、运动与长时背景干扰三类情形。
Card 04 方法描述

方法描述

  • 所属模块：整体采样器负责让输入覆盖完整视频；共享权重的 3D 主干独立提取各动作单元的短时时空特征；Residual 4D Block 在单元轴上交换信息；末端全局平均池化把所有单元汇成视频级表征并送入分类器。
  • 输入与表示：视频表示为 V={A_i}，其中每个 A_i∈R^{C×T×H×W}，C、T、H、W 分别是通道、单元内时间、空间高与宽。堆叠后 4D 卷积接收 (C,U,T,H,W) 张量，U 专门表示沿完整视频排列的动作单元。
  • 模型结构：实现采用 I3D-S，即 SlowFast 的 Slow-path，并给出 ResNet18 与 ResNet50 两种主干；低层以空间卷积为主，高层引入时空卷积且不缩短时间长度。Residual 4D Block 可插在不同残差阶段，块内含轴置换、4D 卷积、反向置换、残差相加以及 BN/ReLU。
  • 数据流：训练时先把视频分段取样，各动作单元经共享的 3D 层并行得到 F_i；随后把单元序列送入 Residual 4D Block 学习跨单元演化，最后对整个序列全局平均得到视频表征。推理时先用 N_3D 编码 U_infer 个单元，再把特征均分为 U_train 个区段、每段选一个并枚举组合；每组经 N_4D 得分，所有组的分数再平均为最终预测。
  • 关键技术：4D 卷积把动作单元轴与单元内部时空轴同时纳入核；通过交换求和顺序，可用标准 3D 卷积实现。为控制参数与过拟合，实验重点采用 k×k×1×1 和 k×1×1×1 核；其中后一形式等价于沿拼接时间轴、膨胀率为 T 的时间膨胀卷积，而残差支路避免丢掉短时细节。
  • 公式与超参数：4D 卷积可写为 o_j^{u,t,h,w}=b_j+Σ_{c,s,p,q,r}W_{jc}^{s,p,q,r}v_c^{u+s,t+p,h+q,w+r}：每个输出位置累加输入通道与四个核轴，S×P×Q×R 给出核形状。残差块为 Y_{3D}=X_{3D}+φ_{(U,C)}(F_{4D}(φ_{(C,U)}(X_{3D});W_{4D}))，即先把 U 移到卷积所需位置，计算后恢复并加回 X。Mini-Kinetics 中每段先取 32 帧，再以步长 8 均匀取 4 帧；SGD 初始学习率 0.01、weight decay 10−5、momentum 0.9，在第 35、60、80 个 epoch 衰减，总计训练 100 个 epoch。
Card 05 数据集与资源

数据集与资源

  • 数据集：Mini-Kinetics：200 个动作类别；论文版本含 78,422 个训练视频、4,994 个验证视频，单个视频约 300 帧。
  • 数据集：Kinetics-400：论文可用版本含 240,436 个训练视频和 19,796 个验证视频。
  • 数据集：Something-Something-v1：共 108,499 个视频，其中训练、验证、测试分别为 86,017、11,522、10,960，单段含 36 到 72 帧。
  • 数据集：ActivityNet v1.3：附录所用未剪辑视频通常长 5 到 10 分钟，并包含大量与目标活动无关的时间区间。
  • 规模与划分：Mini-Kinetics 报告 200 类、78,422 个训练视频、4,994 个验证视频，单视频约 300 帧；Kinetics-400 仅报告 240,436 个训练视频和 19,796 个验证视频，且作者说明部分视频已不可用；Something-Something-v1 报告总计 108,499 个视频，训练/验证/测试分别为 86,017/11,522/10,960，单视频 36–72 帧。ActivityNet 附录未报告划分规模或训练样本数。
  • 模型：Mini-Kinetics 使用 ImageNet 权重初始化；基础主干是 I3D-S Slow-path 的 ResNet18 或 ResNet50。参数对比中 V4D ResNet18 为 33.1M，I3D-S ResNet18 为 32.3M；论文的 ResNet50 结果表没有列参数量。
  • 硬件：正文训练设置和附录均未报告 GPU/CPU 型号、设备数量、显存或训练时长；只在 Kinetics 分阶段训练处说明受计算资源限制。
  • 代码：论文说明通过交换求和顺序、调用 3D 卷积来实现 4D 卷积；但从首页、方法、实验到附录均未给出代码仓库、项目地址或发布状态。
  • 训练平台：实验平台均为离线 RGB 视频数据集上的动作分类，没有仿真器、机器人或实车平台。ActivityNet 附录还明确其输入只使用 RGB 模态。
Card 06 评估与结果

评估与结果

  • 评估基准：Mini-Kinetics：用于主要消融、复杂度比较和同类方法对比。
  • 评估基准：Kinetics-400：用于检验大规模剪辑视频识别能力。
  • 评估基准：Something-Something-v1：动作运动更复杂，用于检验短期与长期时间顺序。
  • 评估基准：ActivityNet v1.3：附录中的大规模未剪辑视频分类测试。
  • 评估指标：Mini-Kinetics 与 Kinetics 使用 top-1、top-5 分类准确率，表中单位为百分比，数值越高越好；Something-Something-v1 报告 top-1，同样越高越好。
  • 评估指标：ActivityNet 使用动作识别 mean average precision（mAP），数值越高越好。
  • 对比方法：Mini-Kinetics 的直接对照包括片段级 I3D-S、视频级 TSN+I3D-S，以及加深以补偿额外参数的 I3D-S ResNet18++。
  • 对比方法：Kinetics 对比 ARTNet+TSN、ECO、S3D-G、Nonlocal、SlowFast、I3D、Two-stream I3D 与 I3D-S。
  • 对比方法：Something-Something-v1 对比 MultiScale TRN、ECO、S3D-G、Nonlocal+GCN 与 TrajectoryNet。
  • 对比方法：ActivityNet 附录对比 BN-Inception 或 Inception V3 主干的 TSN 与 TSN-Top3。
  • 关键结果：Mini-Kinetics 受控比较的 top-1/top-5 分类准确率（%，越高越好）为：V4D ResNet18 在 4×4 训练、4×10×3 推理下为 75.6/92.7，参数量 33.1M；同一采样协议的 TSN+I3D-S ResNet18 为 73.0/91.3，参数量 32.3M；I3D-S ResNet18 在 4×1 训练、4×10×3 推理下为 72.2/91.2，参数量 32.3M。
  • 关键结果：Mini-Kinetics 前向开销比较：V4D ResNet18 与 TSN+I3D-S ResNet18 都使用 4×4×256×256 输入，FLOPs 分别为 58.8G 与 55.1G；I3D-S ResNet18 使用 16×256×256 输入，FLOPs 也为 55.1G。
  • 关键结果：Mini-Kinetics 广泛方法对比中，V4D ResNet50 的第一候选/前五候选准确率为 80.7/95.3；I3D+CGNL ResNet101 为 79.9/93.4。
  • 关键结果：Kinetics 上 V4D ResNet50 为 77.4 和 93.1；SlowFast ResNet50 为 77.0 和 92.6，前者两项都更高。
  • 关键结果：Something-Something-v1 上 V4D ResNet50 的第一候选准确率为 50.4，高于表中 TrajectoryNet 的 47.8。
  • 关键结果：ActivityNet 上 RGB-only V4D ResNet50 达到 88.9 mAP，高于 TSN-Top3 的 84.5。
  • 消融实验：4D 核形状消融中，3×1×1×1、3×3×1×1、3×3×3×3 的第一候选准确率依次为 73.8、74.5、74.7；论文后续选用参数与性能折中的 3×3×1×1。
  • 消融实验：单个 4D Block 放在 res3、res4、res5 时分别得到 74.2、74.5、73.6；同时放在 res3 与 res4 提升到 75.6，说明交互后继续用 3D 卷积细化更有效。
  • 消融实验：当 U_train 从 3、4、5 增至 6 时，第一候选准确率仅从 74.3、74.5、74.5 变到 74.6；作者据此认为模型对动作单元数较稳健，但这只是该取值范围内的观察。
  • 消融实验：时间顺序干预把原始 50.4% 降到 17.2%（反转单元内帧）或 20.1%（反转动作单元序列），分别检验短时与长时时序敏感性。
  • 实验条件：这些结果都是离线监督视频分类，不是零样本、机器人闭环或实车测试。Mini-Kinetics 从 ImageNet 初始化，公平对照统一采用 10 个动作单元与 3-crop 推理；Kinetics 采用每单元 8 帧、U=4 的分阶段训练；Something-Something-v1 使用 Kinetics 预训练的 V4D ResNet50；ActivityNet 推理使用 Multi-scale Temporal Window Integration，且只输入 RGB。
