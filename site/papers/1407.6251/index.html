FollowMe: Efficient Online Min-Cost Flow Tracking with Bounded Memory and Computation

2014-07-23 · 原文 · 翻译 · 1407.6251

这篇论文解决的是 tracking-by-detection 中的全局数据关联：经典最小费用流虽然能给出全局最优轨迹，却计算昂贵、要求整段视频一次性到齐，而且内存与计算量会随序列长度无界增长，因此无法直接变成长期在线跟踪器。 它面向自动驾驶和监控这类持续输入的视频场景：检测器逐帧给出候选框，跟踪器要在有限资源下不断把新检测接入既有轨迹，同时允许新证据修正近期关联，而不是把长视频切成彼此孤立的批次。 论文真正验证的问题分成三层：能否通过复用旧最短路只做必要计算而保持最优，能否在在线新增帧时仍保持全局最优，以及牺牲多大最优性才能把历史窗口、内存和单帧计算固定下来并达到实时运行。 研究背景：Tracking-by-detection 先在每帧独立检测目标，再把相邻时间的检测链接成数量未知的多条轨迹；网络流 formulation 可同时决定目标数和轨迹，并在给定一元检测代价与相邻帧关联代价时求全局最优。 核心痛点：局部逐帧匹配在遮挡、噪声检测和漏检下容易产生歧义，早期错误无法靠后续帧纠正；已有批处理最小费用流又必须预先拥有全部检测，计算与内存随视频增长，因而不适合持续运行的机器人系统。 任务定义：输入是逐帧检测集合，每个检测包含边界框位置、帧索引、框尺寸、外观和检测分数；输出是互不重叠的轨迹集合，每条轨迹由时间相邻的检测索引组成，目标函数在流守恒约束下最小化进入、退出、检测与链接代价。 研究目标：作者要求求解器同时具备按需计算、在线处理数据流和内存/计算有界三种性质；前两种性质保持精确最优，最后一种允许受控近似，但要在实际跟踪上接近最优。

Card 03 核心贡献

核心贡献

  • 提出 dSSP：把每轮重新运行完整 Dijkstra 改成动态优先队列，只把前驱失效或被更新的节点及其后继纳入传播，从上一轮残差图复用其余最短路计算，同时保持最小费用流解的最优性。
  • 提出 odSSP：新一帧检测到达时扩展旧网络，先只在新增边上做有向无环图最短路，再合并缓存的前驱图并动态广播变化，使在线时刻上的解仍是截至当前全部检测的最优解。
  • 提出 mbodSSP：用固定历史窗裁剪旧节点，但把离窗轨迹的累计前驱代价并入新窗口入口边，并缓存近期前驱图；当缓存缺失候选轨迹时在当前窗口退回 odSSP，从而保持可行关联。
  • 把精确动态、精确在线与有界近似三类求解器放在同一追踪模型、数据结构和基准下评测，联合展示跟踪精度、运行时间、内存增长以及历史窗大小的影响。
Card 04 方法描述

方法描述

  • 所属模块：整体由三个递进求解层组成：dSSP 负责在一个残差网络内增量更新最短路，odSSP 负责接收新帧并复用跨时刻前驱缓存，mbodSSP 再负责裁剪旧图和压缩历史代价，使无限视频转化为固定资源的在线计算。
  • 输入与表示：每个检测表示为位置、时间、尺寸、外观与检测置信度的元组；一条轨迹是时间相邻检测的序列，完整假设是互斥轨迹集合。检测节点在流图中拆为入节点和出节点，源/汇边表示轨迹进入与退出，相邻检测间的边表示关联。
  • 模型结构：概率模型由检测真伪观测项、轨迹进入/退出项、相邻检测链接项以及轨迹互斥约束组成；取负对数后变成单位容量的最小费用流网络，SSP 反复找负成本源汇最短路、反转路径边形成残差图，直到不存在负成本轨迹。
  • 数据流：在 dSSP 中，先对首条轨迹做有向无环图最短路，再反转当前路径；算法前向扫描刚变化的路径节点，更新失效前驱，把发生改变的后继加入优先队列，按距离弹出并继续松弛，队列清空后得到该轮最短路并解码所有反向边为轨迹。在线版接到新检测后只扩展图的末端，再把新节点解与旧缓存合并后执行同一传播。
  • 关键技术：关键技巧是前驱图缓存、只传播变化的动态优先队列，以及窗口裁剪时的代价汇总：离开窗口的旧节点被删除前，其累计路径代价被加到下一时刻对应入口边，因此轨迹身份可延续得比窗口更久；若新最优轨迹不在缓存中，则在保留窗口上调用 odSSP 重建有效缓存。
  • 公式与超参数：检测分数通过逻辑回归映射为代价 C_i=1/(1+e^{βd_i})；边关联由框重叠、朝向、颜色直方图、互相关、位置和光流重叠等六类相似度组成，并以 C_{u,v}=((1-s)+o)^T w 合成为可正可负的边代价。偏置 o 与尺度 w 在各训练集上用 block coordinate descent 学得并在实验中固定；mbodSSP 的历史长度由 τ 控制。

Card 06 评估与结果

评估与结果

  • 评估基准：KITTI-Car：分别用 DPM reference detections 与 Regionlet detections 评测车辆多目标跟踪。
  • 评估基准：PETS2009 S2.L1：使用既有检测和真值评测行人多目标跟踪。
  • 评估指标：KITTI 表报告 MOTA、MOTP、F1、FAR、MT、ML、IDS 与 Frag；正文把这些指标的定义指向所引评价文献，并未在文内重新说明每一项的优化方向。
  • 评估指标：PETS 表报告 MOTA、MOTP、MT、PT、ML、ID-switches 与 Fragmentations，用来同时观察整体准确性、定位精度、轨迹覆盖和身份连续性。
  • 对比方法：KITTI 将作者方法与四个当时方法及逐帧 Hungarian baseline 对比，同时比较 regular SSP、非最优 DP、dSSP、odSSP 与 mbodSSP 的时间和内存。
  • 对比方法：PETS2009 将 mbodSSP 和 SSP 与三组已有跟踪基线及 EKF 结果对比；该实验沿用 KITTI 的参数。
  • 关键结果：在 KITTI 的 DPM 检测下，mbodSSP 的 MOTA 为 0.52、F1 为 0.70、IDS 为 0；最优 SSP 对应 0.54、0.71、7，说明小窗近似的总体精度接近最优且身份切换更少。
  • 关键结果：换用 Regionlet 检测后，mbodSSP 与 SSP 的 MOTA 都是 0.67、F1 都是 0.83，显示检测质量提升比在两种流求解器之间切换带来的精度差异更大。
  • 关键结果：在 PETS2009 S2.L1 上，mbodSSP/SSP 的 MOTA 分别为 0.89/0.91，MOTP 都为 0.87，ID-switches 分别为 7/23；近似解总体准确率接近精确解，同时身份切换更少。
  • 关键结果：全局最优 dSSP 相对常规 Dijkstra 版 SSP 的平均运行速度提高约 3 倍，而且实验曲线显示 mbodSSP 的时间复杂度不随序列长度增长。
  • 关键结果：当 τ=10 时，非优化 Python 版 mbodDijkstra 单帧耗时低于 10ms，达到论文所称多数在线应用所需的实时量级。
  • 消融实验：历史窗消融直接改变 τ；作者重点指出 τ=10 已能把非优化实现压到 10ms 以下，同时 KITTI 跟踪性能仅有很小损失，验证了固定短窗与近最优精度之间的折中。
  • 实验条件：效率对比让全部求解器使用相同 Python 数据结构，并在一条无真值的长 KITTI 序列上测时间与理想化内存；精度表中的 mbodSSP 使用 τ=10，KITTI 的 DPM 实验把检测阈值设为 d_i=-0.3 以避免过早剪枝。
