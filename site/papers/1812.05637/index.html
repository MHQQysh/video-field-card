Dynamic Graph Modules for Modeling Object-Object Interactions in Activity Recognition

2018-12-14 · 原文 · 翻译 · 1812.05637

这项工作解决视频动作识别中复杂物体—物体交互被普通卷积表示隐式化的问题：识别器必须同时保留单帧内不同物体的空间关系，以及跨帧中同一物体或不同物体之间交互的时间变化。 具体场景既包括流式到达、只看到开头若干帧的在线识别，也包括整段处理：Something-Something 的短、裁剪、单标签手—物体动作，以及 ActivityNet 的长、未裁剪、多标签活动。 论文真正检验的是：随时间更新并显式传递区域消息的隐藏图，能否比把区域平均池化后送入 LSTM 更好地保留物体交互；随着视频前缀变长能否持续提高准确率；同一模块能否再提升静态骨干的整段识别。 研究背景：深度学习与新视频数据集推动了动作识别，但决定动作语义的复杂物体—物体交互仍常被忽略；这类动作既取决于同帧不同物体之间的关系，也取决于这些关系跨帧如何变化。 核心痛点：现有视频表示或 non-local 特征要么不能在对象层显式建模关系，要么不能处理流式视频；位置级 non-local 还会把相距很远、通常无关的位置联系起来，而把区域均值送入 LSTM 又会丢失区域的空间关系。 任务定义：输入视频先采样为帧；同一批输入帧分别进入三维卷积骨干和 RPN：RPN 只产生 RoI 框及坐标，框坐标投影到骨干特征图后，再由 RoIAlign 从特征图抽取区域特征。区域序列顺序更新带权有向隐藏图，并在每个特征时刻输出动作类别；静态版本另融合整段视频的全局骨干特征。 研究目标：目标是在同一可插拔图模块中同时显式捕获单帧空间交互与跨帧时间交互，使模型能从视频开始处渐进处理流式输入，并在短裁剪视频与长未裁剪视频上提升既有动作识别骨干。

Card 02 论文概述

论文概述

  • 这项工作解决视频动作识别中复杂物体—物体交互被普通卷积表示隐式化的问题：识别器必须同时保留单帧内不同物体的空间关系，以及跨帧中同一物体或不同物体之间交互的时间变化。
  • 具体场景既包括流式到达、只看到开头若干帧的在线识别，也包括整段处理：Something-Something 的短、裁剪、单标签手—物体动作，以及 ActivityNet 的长、未裁剪、多标签活动。
  • 论文真正检验的是：随时间更新并显式传递区域消息的隐藏图，能否比把区域平均池化后送入 LSTM 更好地保留物体交互；随着视频前缀变长能否持续提高准确率；同一模块能否再提升静态骨干的整段识别。
  • 研究背景：深度学习与新视频数据集推动了动作识别，但决定动作语义的复杂物体—物体交互仍常被忽略；这类动作既取决于同帧不同物体之间的关系，也取决于这些关系跨帧如何变化。
  • 核心痛点：现有视频表示或 non-local 特征要么不能在对象层显式建模关系，要么不能处理流式视频；位置级 non-local 还会把相距很远、通常无关的位置联系起来，而把区域均值送入 LSTM 又会丢失区域的空间关系。
  • 任务定义：输入视频先采样为帧；同一批输入帧分别进入三维卷积骨干和 RPN：RPN 只产生 RoI 框及坐标，框坐标投影到骨干特征图后，再由 RoIAlign 从特征图抽取区域特征。区域序列顺序更新带权有向隐藏图，并在每个特征时刻输出动作类别；静态版本另融合整段视频的全局骨干特征。
  • 研究目标：目标是在同一可插拔图模块中同时显式捕获单帧空间交互与跨帧时间交互，使模型能从视频开始处渐进处理流式输入，并在短裁剪视频与长未裁剪视频上提升既有动作识别骨干。
Card 03 核心贡献

核心贡献

  • 提出类似循环隐状态的动态隐藏图：它是允许自连接的完整有向图，每到一个新时刻先接收当前 RoI 的消息，再重算图内边并自更新，从而累积空间与时间交互。
  • 给出视觉图实例：用线性投影后的区域—节点外观相似度建立软连接，以 softmax 分配流入消息，再用学习门控融合旧节点状态和新消息，并按节点相似度动态更新有向边。
  • 给出位置图实例：以提案框和虚拟节点框的 IoU 作为连接权重，用坐标移位让节点框向高权重提案移动，因此可跟踪相互重叠或邻近物体的相对时空位置变化。
  • 设计图上虚拟注意力节点作为逐时刻分类上下文和下一时刻查询，并实现流式、静态两种完整模型；静态模型把图上下文与全局卷积特征融合后识别动作。
Card 04 方法描述

方法描述

  • 所属模块：动态图模块位于卷积骨干、RPN 与 RoIAlign 之后，充当跨时间的对象级记忆：它把当前区域消息写入隐藏图、在图内传播交互信息，再由注意力汇聚出供 MLP 分类的上下文，因此无需预先看到视频末尾。
  • 输入与表示：视频表示为按时间排序的特征图；每个特征图保留 top-N RPN 提案及边框坐标。每个 RoI 与隐藏节点均使用 1024 维特征，节点还携带左上角、右下角构成的虚拟边框坐标；首个时刻的提案初始化节点特征与坐标。
  • 模型结构：流式模型把采样输入帧分别送入三维卷积骨干与 RPN：前者产生按时间排列的特征图，后者在输入帧上提出 RoI 框；框坐标投影到骨干特征图后，RoIAlign 抽取区域特征，继而进入视觉图或位置图、虚拟注意力节点和 MLP，在每个特征时刻给出预测。静态模型同样把整段采样帧输入三维卷积骨干和 RPN，再将平均池化的全局骨干特征与图特征分别归一化、拼接，经全连接、批归一化和 ReLU 得到融合特征并分类。
  • 数据流：首先对首个特征图的提案做最大池化以初始化上下文，并用提案初始化隐藏图。随后每个新特征图的全部提案按视觉相似度或 IoU 向各节点传消息，节点融合消息后重新计算图内边并再次传播；注意力以旧上下文查询更新后的节点，汇聚新上下文送入分类器。下一时刻复用更新后的图和上下文，因而可对视频前缀连续预测。
  • 关键技术：视觉图以投影点积度量区域与节点、节点与节点的相似度，分别完成跨输入消息传递和图内自更新，并用 sigmoid 门控避免完全覆盖旧状态。位置图用 IoU 和 L1 归一化传递消息，以 ReLU 更新特征，同时把虚拟框移动到旧位置与提案加权位置之间。图上注意力引入排列不变的虚拟节点，既汇总当前判别区域，又作为下一时刻的查询。
  • 公式与超参数：视觉分支计算 Fv(b,x)=h(b)^Tg(x)，softmax 后得到消息权重，并以 x←σx+(1−σ)x̂、σ=sigmoid(Wx+Ŵx̂) 更新节点；位置分支令 Fl(b,x)=IoU(b,x)，经 L1 归一化后作 x←ReLU(x+x̂)，虚拟坐标取旧坐标与提案加权坐标的中点。注意力由旧 q 查询新节点并计算 q(t+1)=Σαx。区域和节点特征为 1024 维；静态融合的骨干特征为 2048 维、图特征为 1024 维。Something-Something 每帧保留 top 20 提案、隐藏图设 5 个节点，ActivityNet 为 top 40 提案、10 个节点。骨干训练使用 dropout 0.5、batch size 24、初始学习率 0.00125、SGD momentum 0.9、weight decay 0.0001；静态模型先 warm-up 3 epochs，再把学习率降低 10 倍。
Card 05 数据集与资源

数据集与资源

  • 数据集：Something-Something v1：超过 100K 个短视频，平均时长约 3–6 秒，共 174 个动作类别，每个视频恰有一个标签；采用官方划分。
  • 数据集：Something-Something v2：约 220K 个短视频，平均时长约 3–6 秒，与前一版本同为 174 个动作类别和单标签视频；采用官方划分。
  • 数据集：ActivityNet：训练集含 10K 个视频、15K 个活动实例和 200 类；验证集含 5K 个视频、7K 个活动实例；采用官方划分。
  • 规模与划分：两版 Something-Something 与 ActivityNet 均按官方划分训练和测试。训练 ActivityNet 骨干时，把活动实例切成约 5 秒且重叠率为 20% 的 clips；推理时则切成互不重叠的 5 秒 clips，并从每段均匀采样 32 帧。
  • 模型：骨干是先在 Kinetics 训练、再在目标数据集微调的三维卷积模型；RPN 使用在 Microsoft COCO 上预训练的 ResNet-50。完整模型固定骨干，只训练图模块、融合层与分类层；正文和附录报告了特征维度，但未给出总参数量。
  • 硬件：论文实验设置与实现细节附录逐项给出数据预处理、batch、优化器和学习率，但没有报告训练或推理所用 GPU、CPU 的型号、数量、显存或运行时间。
  • 代码：论文正文、结论、完整附录与参考文献尾部均未给出代码仓库地址，也未说明代码已经发布或承诺发布。
  • 训练平台：实验平台限于 Something-Something 与 ActivityNet 视频数据集上的网络训练和离线评测；全文未使用或报告仿真器、机器人、机械臂、实车等具身平台。
Card 06 评估与结果

评估与结果

  • 评估基准：Something-Something v1：短、裁剪、单标签视频；同时评估流式前缀识别与静态整段识别。
  • 评估基准：Something-Something v2：短、裁剪、单标签视频；报告验证集以及静态模型的排行榜测试结果。
  • 评估基准：ActivityNet：长、未裁剪、可含多个标签的视频；静态模型在整段视频层面评估。
  • 评估指标：Something-Something 使用 top-k 识别准确率，重点报告 top-1 与 top-5，数值越高越好。
  • 评估指标：ActivityNet 使用 mAP，并同时报告 top-1 与 top-3，三项均为数值越高越好。
  • 对比方法：流式实验比较区域特征均值池化后输入 LSTM 的 baseline、Visual Graph、Location Graph，并以 ECO Lite 作为近期在线方法参照。
  • 对比方法：静态实验与多种时序或图式动作识别方法以及作者自己的 backbone 对比，并在表中明确区分 RGB-only 与 Flow+RGB 输入口径。
  • 关键结果：流式 Something-Something v1 最后一个特征图的 top-1 准确率（表中为百分数）为 Visual Graph 41.7、Location Graph 38.2，ECO Lite 为 41.3；越高越好。
  • 关键结果：流式 Something-Something v2 最后一个特征图的 top-1 准确率（表中为百分数）为 Visual Graph 54.0、Location Graph 50.5；越高越好。
  • 关键结果：静态 Something-Something v1 验证集上，backbone 的 top-1/top-5 为 46.0/76.1，Visual Graph 为 47.1/76.2，Location Graph 为 47.1/76.3；论文称 top-1 绝对提升 1.1%，越高越好。
  • 关键结果：静态 Something-Something v2 验证集上，backbone 的 top-1/top-5 为 59.7/86.4，Visual Graph 与 Location Graph 均为 61.4/86.8；论文称 top-1 绝对提升 1.7%，越高越好。
  • 关键结果：ActivityNet 静态 RGB 评测中，backbone 的 mAP/top-1/top-3 为 70.2/69.2/83.5，Visual Graph 为 71.5/70.3/84.5，Location Graph 为 71.8/70.3/84.8；越高越好。
  • 消融实验：固定静态 backbone 后加入图模块：Something-Something v1 的 top-1 从 46.0 提到 47.1，v2 从 59.7 提到 61.4，对应论文报告的绝对增益 1.1% 与 1.7%。
  • 消融实验：两种图实例对照显示，流式 v1 的 Visual/Location 为 41.7/38.2，流式 v2 为 54.0/50.5；作者只把视觉图更高归因于其可能拥有更多参数，保留了推测语气。
  • 消融实验：时间前缀曲线显示两种图的准确率随输入帧增加而稳定上升，并在第 7 个特征图附近进入平台；区域均值加 LSTM 的 baseline 明显更低。
  • 消融实验：论文没有单列更细的正式消融，正文结果表与完整附录均未分别移除图内自更新、虚拟注意力或坐标移位来报告数值。
  • 实验条件：Something-Something 推理从整段均匀采 32 帧，短边缩放到 256 后中心裁剪为 224×224；ActivityNet 把视频切成互不重叠的 5 秒 clips，每段采 32 帧并以 top-k pooling 汇总。表格结果使用 RGB 输入；ActivityNet 对照还明确未用音频、光流或 ensemble。完整模型训练时固定三维卷积 backbone。
