Learning Spatiotemporal Features via Video and Text Pair Discrimination

2020-01-16 · 原文 · 翻译 · 2001.05691

它解决的是如何不用昂贵的人工动作标签，而以网页视频自然伴随的标题或字幕作为弱监督，从头学习可迁移的时空视频表征。 适用于能够同时采集视频与自然伴随文本的场景，例如 YouTube 标题、Instagram 字幕或自动语音识别文本；学得的视频特征既可冻结后接浅层分类器，也可微调到动作识别。 论文真正检验的是：跨模态配对判别能否在噪声文本和有限训练数据下学到通用视频特征，并在冻结特征、下游微调及零样本分类三种口径中保持竞争力。 研究背景：大规模人工标注视频数据可训练强表征并帮助小型下游数据集，但视频的时间结构和复杂语义使标注尤其昂贵；与之相对，网络视频通常天然带有标题、字幕等文本侧信息。 核心痛点：自然文本可能含噪声、与画面无关，视频网络又要从随机初始化开始；若把每个视频—文本对都当作独立类别，类别数随训练样本数增长，直接 softmax 计算昂贵；同时一开始联合微调语言模型会被随机视频特征产生的噪声扰乱。 任务定义：给定 N 个视频片段及其配对文本，分别用视觉映射 Fv 与文本映射 Ft 得到同一嵌入空间中的单位范数特征；训练目标不是预测人工动作类，而是提高正确视频—文本条件配对在两个方向上的概率，使一致配对接近、不一致配对远离。 研究目标：目标是仅依赖噪声而多样的伴随文本，从头学习可供多种下游任务使用的视频表征，并判断这种表征在冻结特征、微调迁移和零样本视觉—文本匹配时是否仍有效。

Card 02 论文概述

论文概述

  • 它解决的是如何不用昂贵的人工动作标签，而以网页视频自然伴随的标题或字幕作为弱监督，从头学习可迁移的时空视频表征。
  • 适用于能够同时采集视频与自然伴随文本的场景，例如 YouTube 标题、Instagram 字幕或自动语音识别文本；学得的视频特征既可冻结后接浅层分类器，也可微调到动作识别。
  • 论文真正检验的是：跨模态配对判别能否在噪声文本和有限训练数据下学到通用视频特征，并在冻结特征、下游微调及零样本分类三种口径中保持竞争力。
  • 研究背景：大规模人工标注视频数据可训练强表征并帮助小型下游数据集，但视频的时间结构和复杂语义使标注尤其昂贵；与之相对，网络视频通常天然带有标题、字幕等文本侧信息。
  • 核心痛点：自然文本可能含噪声、与画面无关，视频网络又要从随机初始化开始；若把每个视频—文本对都当作独立类别，类别数随训练样本数增长，直接 softmax 计算昂贵；同时一开始联合微调语言模型会被随机视频特征产生的噪声扰乱。
  • 任务定义：给定 N 个视频片段及其配对文本，分别用视觉映射 Fv 与文本映射 Ft 得到同一嵌入空间中的单位范数特征；训练目标不是预测人工动作类，而是提高正确视频—文本条件配对在两个方向上的概率，使一致配对接近、不一致配对远离。
  • 研究目标：目标是仅依赖噪声而多样的伴随文本，从头学习可供多种下游任务使用的视频表征，并判断这种表征在冻结特征、微调迁移和零样本视觉—文本匹配时是否仍有效。
Card 03 核心贡献

核心贡献

  • 提出跨模态配对判别（CPD）：从视频给定文本、文本给定视频的条件分布出发，用跨模态相关项直接建模成对关系，而不是在联合空间做自相关的多模态实例分类。
  • 用噪声对比估计把海量配对类别的多类归一化改写为数据对与噪声对的二分类，并用动态 memory bank 保存每个训练对的视觉和文本特征，降低计算与存储负担。
  • 设计两阶段课程训练：先冻结已预训练的语言编码器，只更新随机初始化的视频网络和映射层；视频网络获得初始化后，再以更小学习率联合优化视觉与文本网络。
  • 在 Kinetics-210k 标题对和未经人工筛选的 Instagram-300k 视频—字幕对上实例化同一框架，覆盖 PGC 与噪声更强的 UGC 数据，并用冻结、微调、小样本及零样本协议验证迁移性。
Card 04 方法描述

方法描述

  • 所属模块：CPD 的视觉支路负责从片段中学习时空特征，文本支路提供无需动作标签的语义监督；二者映射到共享空间后，以配对身份训练视觉表征。预训练语言模型还充当课程训练的稳定锚点，避免随机视频网络在训练初期破坏文本编码器。
  • 输入与表示：视频输入随机采样 8 帧、时间 stride 为 4；Word2vec 文本支路平均 300 维词向量，DistilBERT 支路平均标题词嵌入得到 768 维特征。两条支路最终都映射为 256 维并作 L2 归一化。
  • 模型结构：视觉编码器采用 3D CNN：小型配置为 3D ResNet34 与 112×112×8 输入，大型配置为 3D ResNet50 与 224×224×8 输入；conv1 到 res3 退化为空间二维卷积，仅 res4、res5 保留三维卷积且不做时间下采样。文本端在 Word2vec 或 DistilBERT 后接两层全连接、ReLU 和 Batch Normalization。
  • 数据流：文本先清洗并进入文本编码器，视频先抽取 clip 并进入 3D CNN；两路特征经全连接层投到共同的 256 维空间。配对判别模块拉近匹配视频—文本、推远不匹配对，同时从 memory bank 读取全数据集候选并在训练中动态更新特征；得到的视觉特征可直接冻结使用或继续微调。
  • 关键技术：关键组合是双向条件式跨模态配对判别、全数据集噪声对比估计、动态特征 memory bank 与两阶段课程学习。相较只在当前 mini-batch 内取负样本的 ranking loss，CPD 能从整个数据集构造负对，并按后验概率给难例不同梯度权重。
  • 公式与超参数：核心条件概率为 p(i_t|v)=exp(f_i^t·f^v/τ)/Σ_j exp(f_j^t·f^v/τ)，文本到视频方向同理，并最大化两个方向的配对似然；f^t、f^v 均受单位范数约束。NCE 以 h=p/(p+m·p_n) 将原多类目标近似为数据/噪声二分类。正文实现取 τ=0.07、m=16384；附录却写每个视频采样 m=4096 个无关文本特征，两处口径不一致。正文另给出 SGD momentum=0.9、weight decay=1e-4，两阶段学习率先为 0.1，随后语言模型为 3e-5、其余网络为 0.01，最多训练 300 epochs。
Card 05 数据集与资源

数据集与资源

  • 数据集：Kinetics-210k：由 Kinetics400 清洗后约 210k 个视频—标题对组成，不使用动作类别标签；标题分为原始 Kinetics-title、删除特殊符号/非英文/emoji 的 clean 版，以及由 StanfordNLP 仅保留动词和名词的 tree 版。
  • 数据集：Instagram-300k：按 Kinetics-400 动作标签检索但不做人工筛选，从原始 Instagram 网页视频集中随机抽取 300k；每个视频取中间 20 秒并清洗字幕特殊字符。
  • 数据集：UCF101 与 HMDB51：用于下游微调，分别含约 13k 个视频/101 类和约 7k 个视频/51 类；消融用首个 split，主比较对三个 split 取平均。
  • 数据集：Kinetics400：用于冻结特征线性/kNN 评估、少量标注微调及零样本分类；弱监督预训练阶段不使用其动作类标签。
  • 规模与划分：预训练规模分别约为 210k 与随机抽取的 300k 个视频—文本对；训练时另留 1k 个未见视频—文本对作检索验证集。UCF101/HMDB51 主结果平均三个 split，消融仅用首个 split；Kinetics400 小样本实验随机使用训练集的 1%、10%、20% 作为有标签子集。
  • 模型：架构节列出 3D ResNet34 与 3D ResNet50、Word2vec 与 DistilBERT，并给出输入体积、文本特征和共享嵌入维度；全文后续实验设置与附录均未报告这些模型的参数总量。
  • 硬件：实验设置仅报告使用 8 块 GPU 训练，没有给出 GPU 型号；Instagram-300k 还因计算资源有限而从原网页视频集随机抽样。正文实验设置及全部附录均未补充 CPU、内存或训练时长。
  • 代码：论文首页明确称代码已可用并给出 https://github.com/MCG-NJU/CPD-Video；附录仍保留“will be released”的旧措辞。顶层 code_url 依合同按输入元数据原样保留为空。
  • 训练平台：数据采集平台为 YouTube 与 Instagram，Kinetics 标题的句法清理由 StanfordNLP 辅助；论文实验与附录未报告仿真器、机器人、实车或专用采集硬件平台。
Card 06 评估与结果

评估与结果

  • 评估基准：Kinetics-400 验证集冻结特征评估：在 embedding 或 res5 特征上训练 kNN 与线性分类器，不微调视频骨干。
  • 评估基准：UCF101/HMDB51 表征迁移：以 Kinetics-210k 或 Instagram-300k 预训练模型初始化后微调整网；UCF101 split 1 另用于消融。
  • 评估基准：Kinetics400 少标注迁移：只开放训练集的 1%、10%、20% 标签后微调，并与从头训练、ImageNet inflation 比较。
  • 评估基准：UCF101 与 Kinetics-400 零样本分类：预训练后不再微调，把动作类名和视频映射到同一空间，以余弦距离最近的类作为预测。
  • 评估指标：主要指标是 Top-1 分类准确率（%），数值越高越好；冻结评估在 Kinetics-400 验证集报告该指标。
  • 评估指标：冻结表征同时报告 kNN 与线性分类器（LC）准确率；kNN 使用余弦距离且 k=25，二者均为越高越好。
  • 评估指标：零样本也报告 Top-1 准确率（越高越好），按视频嵌入与类别文本嵌入的余弦距离做最近类识别；随机类别设置重复 10 次取均值。
  • 对比方法：冻结特征协议对比带 Kinetics400 动作标签的端到端 3D ConvNet/ResNet、ImageNet 预训练 ResNet50，以及分别用 Instagram 字幕或 Kinetics 标题预训练的 CPD。
  • 对比方法：迁移协议对比随机初始化、纯视觉自监督方法，以及利用音频或文本的 CBT、AVTS、XDC、MIL-NCE、TWS；表中同时标出骨干、预训练数据和是否冻结。
  • 对比方法：少标注 Kinetics400 对比从头训练和 ImageNet Inflation，两种 CPD 初始化分别来自 Instagram-300k 与 Kinetics-210k。
  • 对比方法：零样本 UCF101 对比 Mettes & Snoek 的空间感知对象嵌入；Kinetics400 表中没有列出外部零样本基线。
  • 关键结果：冻结 Kinetics400 特征时，准确率单位为百分比：Kinetics-210k 预训练的 3D ResNet50 res5 特征取得 kNN 58.2、LC 63.8；同表带动作标签端到端训练的 3D ResNet50 为 73.2，冻结弱监督表征仍低于监督结果。
  • 关键结果：全量微调后，准确率单位为百分比：Kinetics-210k CPD 在 UCF101/HMDB51 为 90.5/63.6；Instagram-300k CPD 为 92.8/63.8，均使用 3D ResNet50，数值越高越好。
  • 关键结果：Kinetics400 仅有 1% 标签时，准确率单位为百分比：从头训练、ImageNet Inflation、Instagram-300k CPD、Kinetics-210k CPD 分别为 0.3、12.8、18.7、25.9；在极少标签下两种 CPD 初始化均高于 ImageNet 初始化。
  • 关键结果：零样本准确率单位为百分比：UCF101 全 101 类、三个 split 上，3D ResNet34 CPD 为 40.6，Mettes 为 32.8；Kinetics400 上 3D ResNet50 在全 400 类单 split 为 43.7，随机 20 类十次平均为 74.4。
  • 消融实验：目标函数消融（UCF101 首个 split，准确率单位为百分比且越高越好）：随机初始化 50.0，ranking loss 79.9，多模态实例判别 51.1，跨模态配对判别 82.2。
  • 消融实验：课程学习消融（准确率单位为百分比）：随机初始化 50.0，直接微调文本编码器 81.3，只完成课程阶段一为 82.2，再联合微调的阶段二为 84.2。
  • 消融实验：文本编码器消融（准确率单位为百分比）：DistilBERT 在 tree/clean 标题上为 82.1/84.2，Word2vec 为 83.1/82.5；强文本模型从保留更多噪声信息的 clean 标题获益，而 Word2vec 在精简 tree 标题上更好。
  • 消融实验：补充文本噪声分析显示，数值单位为百分比：Kinetics-title-clean 中 91.6 的标题至少命中动作类名一个词、38.4 命中完整类名，但相关词只占 26.0；附图的逐类结果未呈现词重叠率与零样本准确率正相关。
  • 实验条件：冻结特征评估每视频取 10 个 clip、每 clip 8 帧、stride 4，kNN 取 k=25；线性分类器用 Adam、初始学习率 1e-3，每 10 epochs 降低 10 倍，30 epochs 停止。迁移微调输入 16 帧、stride 4，SGD 初始学习率 1e-2、weight decay 5e-4；测试每视频取 10 clips×3 crops。UCF101/HMDB51 主结果取三个 split 均值，消融只用首个 split。零样本评估不微调；除 101 类设置外，随机选类 10 次取平均。
