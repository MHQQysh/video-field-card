StNet: Local and Global Spatial-Temporal Modeling for Action Recognition

2018-11-05 · 原文 · 翻译 · 1811.01549

这项工作解决大规模视频动作识别的时空表征矛盾：模型既要捕捉连续帧中的局部外观与短时依赖，也要整合跨片段的全局时间关系，同时避免深层三维卷积带来的庞大模型和高训练、推理成本。 使用场景是 RGB 视频动作分类：在 Kinetics 的大规模动作数据上训练和验证，再把所学表示迁移到 UCF101；论文还把自动视频理解联系到视频推荐和视频监控等应用。 论文真正检验的是：把连续帧堆成 super-image 做局部时空建模，再在其特征图序列上串联时间建模块与 TXB，能否在二维、三维卷积及循环模型基线面前取得更好的识别准确率—参数量/FLOPs 权衡，并保留迁移能力。 研究背景：录制设备普及使视频规模超过人工处理能力，动作识别因而需要自动视频理解；论文用“砌砖/铺石”与“叠牌/飞牌”说明，前者依赖局部外观，后者必须利用全局时空线索。 核心痛点：CNN+RNN 的循环时间模块使端到端优化困难，分开训练空间 CNN 与 RNN 又不利于联合表征；二维卷积只从采样 RGB 帧提取外观并平均片段分数，难以直接捕捉时空关系；把深层二维网络整体膨胀为三维网络则会造成过大的模型和训练、推理计算成本。 任务定义：给定一段视频，从全片稀疏采样 T 个时间片段，每个片段取 N 个连续 RGB 帧；网络要联合编码片段内局部时空关系与片段间长程时间关系，最终输出动作类别。 研究目标：目标是从成熟二维卷积骨干构造可端到端训练的轻量 StNet，在大规模动作识别上同时提高时空建模能力与准确率—复杂度权衡，并检验表示迁移到更小数据集时的泛化能力。

Card 02 论文概述

论文概述

  • 这项工作解决大规模视频动作识别的时空表征矛盾：模型既要捕捉连续帧中的局部外观与短时依赖，也要整合跨片段的全局时间关系，同时避免深层三维卷积带来的庞大模型和高训练、推理成本。

  • 论文真正检验的是：把连续帧堆成 super-image 做局部时空建模，再在其特征图序列上串联时间建模块与 TXB，能否在二维、三维卷积及循环模型基线面前取得更好的识别准确率—参数量/FLOPs 权衡，并保留迁移能力。
  • 研究背景：录制设备普及使视频规模超过人工处理能力，动作识别因而需要自动视频理解；论文用“砌砖/铺石”与“叠牌/飞牌”说明，前者依赖局部外观，后者必须利用全局时空线索。
  • 核心痛点：CNN+RNN 的循环时间模块使端到端优化困难，分开训练空间 CNN 与 RNN 又不利于联合表征；二维卷积只从采样 RGB 帧提取外观并平均片段分数，难以直接捕捉时空关系；把深层二维网络整体膨胀为三维网络则会造成过大的模型和训练、推理计算成本。
  • 任务定义：给定一段视频，从全片稀疏采样 T 个时间片段，每个片段取 N 个连续 RGB 帧；网络要联合编码片段内局部时空关系与片段间长程时间关系，最终输出动作类别。
  • 研究目标：目标是从成熟二维卷积骨干构造可端到端训练的轻量 StNet，在大规模动作识别上同时提高时空建模能力与准确率—复杂度权衡，并检验表示迁移到更小数据集时的泛化能力。
Card 03 核心贡献

核心贡献

  • 提出 super-image 局部建模：把每个时间片段的 N 个连续 RGB 帧沿通道堆叠，再以二维卷积同时编码局部外观和短程时间依赖。
  • 在 super-image 的特征图序列上插入时间建模块，逐级把局部时空特征扩展为覆盖视频片段序列的全局时空表示。
  • 设计 Temporal Xception Block（TXB），把普通一维时间卷积分解为通道向与时间向卷积，并融合长、短两条不同时间感受野分支，以减少参数和便于端到端优化。
  • 在 Kinetics400、Kinetics600 上同时比较识别准确率、参数量和推理 FLOPs，并用 Kinetics 预训练表示迁移到 UCF101，覆盖组件消融、主基准和迁移泛化三层验证。
Card 04 方法描述

方法描述

  • 所属模块：super-image 与骨干前段负责片段内局部时空建模；位于 Res3、Res4 之后的 temporal modeling blocks 负责在片段特征图之间建立长程关系；全局池化后的 TXB 再聚合视频级时间动态，供最终分类器使用。
  • 输入与表示：视频被划成 T 个时间片段，每段采样 N 个连续 RGB 帧并沿通道拼接为 super-image；输入张量为 T × 3N × H × W，当前设置 N=5。二维卷积分别处理 T 张 super-image，得到 T 份局部时空特征图。
  • 模型结构：StNet 可由 ResNet、InceptionResNet、ResNeXt 或 SENet 等二维骨干改造。以 ResNet 为例，Conv1、Res2、Res3 编码局部关系；Res3 和 Res4 后各接一个 Conv3d-BN3d-ReLU 时间建模块；Res5 后做全局平均池化与 reshape，再经过 TXB 和全连接分类层。
  • 数据流：首先在全视频上稀疏采样 T 组连续帧并形成 super-image；随后二维骨干在每组内部提取局部时空特征，两处时间建模块沿 T 维交换片段信息；Res5 输出经全局平均池化变为 T × Cin 序列，先做一维批归一化，再进入 TXB 的长、短分支；分支相加后经一维 BN、ReLU 与时间最大池化，得到视频级描述符并由全连接层预测类别。
  • 关键技术：时间建模块只在时间轴使用非平凡卷积核，空间核保持单位大小以节省计算。TXB 的通道向卷积在每个通道内部沿时间滑动，时间向卷积则在每个时间步跨通道混合；这种可分解计算配合残差式长短分支，兼顾时间感受野与参数效率。
  • 公式与超参数：批归一化按 Eq. (1) 计算 v^i=(u^i-m)/√var·α+β，m 和 var 为小批量累计均值与方差。通道向卷积按 Eq. (2) 在单通道时间维用长度为 3 的核求和；时间向卷积按 Eq. (3) 在每一时间步跨 Ci 个通道混合。当前设置 N=5、输出维 Co=1024；时间建模 Conv3d 权重初始化为 1/(3×Ci)、偏置为 0，BN3d 初始化为恒等映射；TXB 短、长分支的时间感受野分别为 1 和 5。
Card 05 数据集与资源

数据集与资源

  • 数据集：Kinetics400：400 个动作类别，每类超过 400 个片段，验证集约 20K 个视频片段；测试集真值不可用，论文在验证集评测。
  • 数据集：Kinetics600：600 个动作类别，训练集约 400K 个裁剪片段，验证集约 30K 个片段；论文在验证集评测。
  • 数据集：UCF101：101 个动作类别、13,320 个带标签视频片段，采用三个训练/测试划分做迁移评测。
  • 规模与划分：Kinetics 两个版本的主实验均因测试集没有真值而使用验证集；UCF101 使用其三个训练/测试划分，并报告三个划分的平均类别准确率。
  • 模型：二维部分可由 ImageNet 预训练骨干初始化，除首层 Conv1 需按多帧输入适配。Kinetics400 的 StNet-ResNet50、StNet-ResNet101 参数量分别为 33.16M、52.15M；Kinetics600 的 StNet-SE-ResNeXt101、StNet-IRv2 分别为 79.13M、72.13M。

Card 06 评估与结果

评估与结果

  • 评估基准：Kinetics400 验证集上的 RGB 动作分类与 TXB 消融。
  • 评估基准：Kinetics600 验证集上的 RGB 动作分类、整网组件消融和可视化。
  • 评估基准：UCF101 三个训练/测试划分上的 Kinetics 预训练模型迁移。
  • 评估指标：Top-1／Prec@1 平均类别准确率，数值越高表示识别效果越好。
  • 评估指标：

Params 参数量，数值越低表示模型越轻量。

  • 评估指标：FLOPs，即推理阶段浮点乘法总数，数值越低表示推理计算开销越小。
  • 对比方法：TXB 层面比较 TSN 骨干、逐项去除一维 BN／通道向卷积／时间向卷积／长短分支，以及 ordinary temporal convolution、LSTM 和 GRU。
  • 对比方法：Kinetics 主表比较 C2D、C3D、I3D、S3D、MF-Net、Nonlocal-I3D、TSN、P3D 与不同骨干的 StNet，统一关注 RGB 准确率、参数量和 FLOPs。
  • 对比方法：UCF101 迁移表比较 C3D+Res18、I3D+BNInception、TSN+BNInception、TSN+IRv2 与三种 StNet 骨干。
  • 关键结果：Kinetics400 的单 clip 对比中，StNet-ResNet50 准确率为 69.85%、推理量为 189.29G FLOPs；C3D-ResNet50 为 64.65%、164.84G。
  • 关键结果：Kinetics600 上，StNet-IRv2 准确率为 78.99%、推理量为 439.57G FLOPs；相同 IRv2 骨干的 TSN 为 76.22%、410.85G。
  • 关键结果：TXB 特征序列实验中，proposed TXB 的准确率表值为 74.62 且仅有 4.6M 参数；ordinary temporal convolution 的对应表值为 74.28、9.6M。
  • 关键结果：UCF101 三划分平均类别准确率中，StNet-Res50、StNet-Res101、StNet-IRv2 分别为 93.5%、94.3%、95.7%，对应 FLOPs 为 53G、87G、123G。
  • 消融实验：TXB 逐项移除实验中，去掉一维 BN、C-Conv、T-Conv、短分支、长分支时准确率表值分别为 73.55、74.14、74.06、74.33、74.21，完整 TXB 为 74.62。
  • 消融实验：整网渐进消融中，TSN 基线为 72.2%；启用 super-image 带来 2.0% 绝对提升；再加入两个 temporal modeling blocks 达 76.0%，完整加入 TXB 后为 76.3%。
  • 消融实验：同一特征序列设置下，TXB 的准确率／参数量为 74.62／4.6M，LSTM 为 73.21／10.9M、GRU 为 73.66／8.3M、ordinary temporal convolution 为 74.28／9.6M。
  • 实验条件：Kinetics 主对比均在验证集、仅用 RGB，StNet 条目采用单 clip 推理。整网组件消融使用 InceptionResNet-V2，T=7、N=5，帧短边缩放到 331，训练随机裁剪 299×299、测试中心裁剪 299×299；UCF101 迁移仅用 RGB，并报告三个划分的均值。
