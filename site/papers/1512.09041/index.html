Actor-Action Semantic Segmentation with Grouping Process Models

2015-12-31 · 原文 · 翻译 · 1512.09041

论文解决演员—动作语义分割中的长程依赖：系统要给视频每个像素同时赋演员与动作标签或空标签，但此前三层 CRF 只在局部邻域交换两类标签，联合演员—动作的逐类像素准确率仅为 26.46%。 它面向需要知道“谁在何处做什么”的视频理解场景；论文用家庭厨房机器人举例，系统必须区分并定位 adult-eating、dog-eating 与 baby-crying，才能据此决定如何准备和何时提供食物。 论文真正检验的是：能否用当前分割反向选择多尺度超体素树切片，再让被选分组重连局部 CRF，并引入视频级演员—动作识别信号；这种双向迭代是否能在 A2D 上同时改善逐类与全局像素准确率。 研究背景：演员—动作语义分割把动作识别、演员类别与时空定位统一成逐像素联合标注；A2D 包含刚性与关节型演员以及多种动作，并允许同一视频出现多个演员—动作组合。 核心痛点：既有三层模型虽联合推理演员与动作，却把交互限制在局部 CRF 邻域；此外，两类标签处在不同粒度层级，演员更偏空间外观、动作更依赖时空运动，因此同一局部尺度难以兼顾。 任务定义：输入是视频及其时空分段；输出为每个像素的一对演员、动作标签或空标签。模型还需让视频级识别提供全局“哪些组合存在”的约束，而像素级分支负责精确定位这些组合出现在哪里。 研究目标：目标是让局部分割、视频级识别与超体素层级在推理中持续双向交换信息：标签场选择语义一致的树切片，树切片再对相应分段施加非局部一致性，并验证这种动态分组是否优于固定局部 CRF。

Card 02 论文概述

论文概述

  • 论文解决演员—动作语义分割中的长程依赖：系统要给视频每个像素同时赋演员与动作标签或空标签，但此前三层 CRF 只在局部邻域交换两类标签，联合演员—动作的逐类像素准确率仅为 26.46%。
  • 它面向需要知道“谁在何处做什么”的视频理解场景；论文用家庭厨房机器人举例，系统必须区分并定位 adult-eating、dog-eating 与 baby-crying，才能据此决定如何准备和何时提供食物。
  • 论文真正检验的是：能否用当前分割反向选择多尺度超体素树切片，再让被选分组重连局部 CRF，并引入视频级演员—动作识别信号；这种双向迭代是否能在 A2D 上同时改善逐类与全局像素准确率。
  • 研究背景：演员—动作语义分割把动作识别、演员类别与时空定位统一成逐像素联合标注；A2D 包含刚性与关节型演员以及多种动作，并允许同一视频出现多个演员—动作组合。
  • 核心痛点：既有三层模型虽联合推理演员与动作，却把交互限制在局部 CRF 邻域；此外，两类标签处在不同粒度层级，演员更偏空间外观、动作更依赖时空运动，因此同一局部尺度难以兼顾。
  • 任务定义：输入是视频及其时空分段；输出为每个像素的一对演员、动作标签或空标签。模型还需让视频级识别提供全局“哪些组合存在”的约束，而像素级分支负责精确定位这些组合出现在哪里。
  • 研究目标：目标是让局部分割、视频级识别与超体素层级在推理中持续双向交换信息：标签场选择语义一致的树切片，树切片再对相应分段施加非局部一致性，并验证这种动态分组是否优于固定局部 CRF。
Card 03 核心贡献

核心贡献

  • 提出 Grouping Process Model：把分段级标注与层级超体素分组动态结合，让当前标签改变 CRF 变量的连接结构，而不是预先固定高阶区域。
  • 设计双向迭代推理：视频标注子问题用带标签成本的图割求解，树切片子问题用二元线性规划求解，使分组线索与标注线索连续交换。
  • 把视频级演员—动作识别作为全局多标签成本，并以其支持情况门控条件高阶一致性势：当激活超体素的分段级主导演员（动作项同理）得到视频级联合标签支持时，才对该超体素内不一致标签施加惩罚。
  • 在 A2D 的全测试视频上，相对下一最佳方法取得论文所述约 60% 的逐类相对提升；逐类表还显示 GPM-GBH 在多数类别提高、若干类别持平，而 dog-crawling 是下降例外。
Card 04 方法描述

方法描述

  • 所属模块：系统由分段级双层 CRF、视频级多标签识别和超体素树切片三部分组成：CRF 定位演员与动作，视频级分类器判断全局可能存在的联合标签，GPM 则借助层级分组把两路信息传播到远距离像素。
  • 输入与表示：视频先表示为时空分段图 V，演员标签集为 X、动作标签集为 Y，每个分段变量同时取 l_i^X 与 l_i^Y，联合空间 Z=X×Y；另在粗到细超体素树 T 的每个节点放置二值激活变量 s_t，并以视频级二值变量 v_z 表示某联合标签是否存在。
  • 模型结构：总能量联合优化分段标签 L、树切片 s 和视频级标签 v：E^v 是演员/动作双层 CRF，E^V 提供视频级一元成本及与分段标签的一致性成本，E^h 同时约束有效树切片、标签纯度以及激活超体素内部的非局部一致性。
  • 数据流：先移除分组项求一个粗分段标注 L；随后固定 L，按每个超体素覆盖标签的熵和选择先验求最优树切片 s；再固定 s，把每个激活节点覆盖的分段局部全连接并重新求 L。两步交替数轮，标签推动分组，分组再细化标签边界。
  • 关键技术：树切片要求每条根到叶路径恰有一个激活节点，避免同一像素被多个尺度重复覆盖；视频级标签成本抑制全局分类器不支持的演员或动作，而条件高阶势只在超体素主导演员与视频级支持一致时启用，从而选择性重分组。
  • 公式与超参数：树节点的分组代价为 E^h(s_t|L_t)=(H(s_t)|s_t|+θ_h)s_t，其中 H 是覆盖标签分布的熵；总演员—动作能量把 E^v(L|V)、Σ_z E^V(v_z|V)、E^V(L,v)、E^h(s|T) 与条件高阶项相加。为使视频级标签成本有效，作者约束 θ_B>2θ_V；其余参数按像素准确率手工分阶段调节。
Card 05 数据集与资源

数据集与资源

  • 数据集：A2D：含七类演员与八类动作的 YouTube 视频演员—动作语义分割数据集，逐像素标签是演员、动作对或空标签。
  • 规模与划分：实验沿用 A2D 原论文的训练/测试划分，约三分之一视频含多个演员—动作标签；正文未给出视频总数或各划分样本数。两种超体素树都取四层：TSP 树细层为 500–1500 个节点、粗层为 50–150 个节点，GBH 从数百个超体素逐层降至不足一百个。
  • 模型：分段级用 TSP 分段及与 A2D 基线相同的外观、运动特征，分别训练演员、动作和演员—动作对的一对其余线性 SVM；视频级用 improved dense trajectories 和 Fisher vectors 训练演员—动作对线性 SVM。
  • 硬件：树切片二元线性规划使用 IBM CPLEX，像素标注用带标签成本的图割；对于几千个标注节点、几百个超体素节点的典型视频，作者只给出数量级为数秒的推理时延。参数按像素级准确率启发式手工搜索。论文方法、实验与参考文献页未报告 CPU、GPU、内存、计算节点配置或精确运行环境，因此该粗粒度时延不能视为可复现吞吐。
  • 代码：分段级局部势复用 A2D 基线的公开代码，AHRF 也使用其公开完整流水线，FCRF 由作者扩展到相同特征；论文仅承诺正式发表时发布自身实现及扩展版 AHRF/FCRF，未给出仓库 URL。
  • 训练平台：实验平台是 A2D 视频的离线逐像素标注：系统输出完整视频像素标签，只在有真值的抽样帧上计分；没有机器人、实车或仿真器闭环实验。
Card 06 评估与结果

评估与结果

  • 评估基准：A2D 官方演员—动作语义分割基准：同时评价联合演员—动作任务与单独演员、动作任务，系统输出全视频逐像素标签并在有真值的抽样帧计分。
  • 评估基准：结果按全部测试视频、仅单演员—动作视频、含多演员—动作视频三种口径报告；论文说明后者约占数据集三分之一。
  • 评估指标：Ave. 是逐类平均像素准确率，Glo. 是全局像素准确率；表中分别对 Actor、Action 与联合 <A,A> 报告，均为越高越好。
  • 对比方法：对比包括 A2D 的 Trilayer、层级随机场 AHRF、全连接 CRF FCRF，以及作者的分段级 E^v、加入视频级势后的 E^v+E^V、使用 TSP 或 GBH 超体素树的完整 GPM。
  • 关键结果：全部测试视频的联合 <A,A> 上，总表中的 GPM-GBH Ave./Glo. 为 43.9/83.8，Trilayer 为 26.5/72.9；表值均按像素准确率的百分比口径读取。
  • 关键结果：单演员—动作视频的联合 <A,A> 上，GPM-GBH 达到 57.6 Ave. 与 84.5 Glo.，Trilayer 为 33.9 与 72.7。
  • 关键结果：多演员—动作视频的联合 <A,A> 上，GPM-GBH 为 33.9 Ave. 与 82.5 Glo.，Trilayer 为 20.4 与 73.4。
  • 关键结果：作者在正文中把总体差距概括为逐类准确率 17%（60% 相对提升），并称全局像素准确率提升超过 10%。
  • 关键结果：定性图示给出两个失败案例：案例 (h) 中 ball-rolling 标注正确，但 adult-running 被误判为 adult-walking；案例 (i) 中 adult-crawling 标注正确，却漏掉 adult-none；这些是作者报告的局限，不是新增量化结果。
  • 消融实验：加入视频级势把全部测试视频联合任务从 E^v 的 24.8 Ave./75.0 Glo. 提到 E^v+E^V 的 42.4/84.8，说明全局存在性线索对局部标签有显著帮助。
  • 消融实验：在 E^v+E^V 上再加入 GBH-GPM 后，联合 Ave. 从 42.4 升至 43.9，但 Glo. 从 84.8 降至 83.8；作者推测轻微全局下降主要来自占像素多数的背景类。
  • 消融实验：两种层级的联合结果接近：GPM-TSP 为 43.3 Ave./84.2 Glo.，GPM-GBH 为 43.9/83.8；作者只谨慎认为 GBH 在多数单类上略好，并将其可能原因归于两种分割合并机制的互补。
  • 消融实验：逐类表进一步检验分组：相较 E^v+E^V，GPM-GBH 在多数类别提高；cat-running 保持 48.0→48.0、ball-flying 保持 11.3→11.3，dog-crawling 则从 45.8 降至 44.1。正文作者将其概括为除 dog-crawling 外均改善，但按表值应表述为多数提升、若干持平、dog-crawling 下降。
  • 实验条件：沿用 A2D 原划分和特征；基础 CRF 使用 TSP 分段，GBH 与多次 TSP 各构造四层超体素树。参数先调视频级、再调分段级、最后在双向推理中调 GPM；最终只在标注帧计算像素准确率，论文未报告随机种子、置信区间或显著性检验。
