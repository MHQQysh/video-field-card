EDVR: Video Restoration with Enhanced Deformable Convolutional Networks

2019-05-07 · 原文 · 翻译 · 1905.02716

论文解决多帧视频恢复中两个耦合难题：大而复杂运动下如何可靠对齐邻帧，以及各帧、各位置受遮挡、视差和模糊影响而信息量不同时如何有效融合。 具体使用场景是视频超分辨率与视频去模糊：系统接收一段连续低质量帧，恢复中间参考帧；同一骨架也被设计为可扩展到去噪、去块等视频恢复任务。 论文真正检验的是：特征级、由粗到细的 PCD 是否比单尺度或简单堆叠可变形卷积更能处理复杂运动，以及 TSA 的像素级时空加权是否带来可测的恢复增益。 研究背景：深度学习已显著推动图像恢复，但早期视频方法往往只是把图像恢复扩展到多帧，未充分利用邻帧冗余；REDS 又引入了比既有数据更大、更复杂的运动，为公平比较提供了公开视频基准。 核心痛点：显式光流方法需要先估计运动再做 warping，遇到遮挡和大运动时难以得到精确光流，单尺度隐式补偿也难覆盖大位移；融合端若把所有帧和位置等同处理，会把失配、视差和模糊区域一并送入重建。 任务定义：给定以 I_t 为中间参考帧的一段连续低质量序列，其余帧作为邻帧，目标是估计尽可能接近真值 O_t 的高质量参考帧 Ô_t；超分辨率输出更高空间分辨率，去模糊则恢复原输入分辨率。 研究目标：构建一个可覆盖超分辨率、去模糊等任务的统一视频恢复框架，把对齐和融合作为核心可学习模块，并验证 PCD、TSA 与二阶段细化在不同数据分布和退化类型下的有效性。

Card 02 论文概述

论文概述

  • 论文解决多帧视频恢复中两个耦合难题：大而复杂运动下如何可靠对齐邻帧，以及各帧、各位置受遮挡、视差和模糊影响而信息量不同时如何有效融合。
  • 具体使用场景是视频超分辨率与视频去模糊：系统接收一段连续低质量帧，恢复中间参考帧；同一骨架也被设计为可扩展到去噪、去块等视频恢复任务。
  • 论文真正检验的是：特征级、由粗到细的 PCD 是否比单尺度或简单堆叠可变形卷积更能处理复杂运动，以及 TSA 的像素级时空加权是否带来可测的恢复增益。
  • 研究背景：深度学习已显著推动图像恢复，但早期视频方法往往只是把图像恢复扩展到多帧，未充分利用邻帧冗余；REDS 又引入了比既有数据更大、更复杂的运动，为公平比较提供了公开视频基准。
  • 核心痛点：显式光流方法需要先估计运动再做 warping，遇到遮挡和大运动时难以得到精确光流，单尺度隐式补偿也难覆盖大位移；融合端若把所有帧和位置等同处理，会把失配、视差和模糊区域一并送入重建。
  • 任务定义：给定以 I_t 为中间参考帧的一段连续低质量序列，其余帧作为邻帧，目标是估计尽可能接近真值 O_t 的高质量参考帧 Ô_t；超分辨率输出更高空间分辨率，去模糊则恢复原输入分辨率。
  • 研究目标：构建一个可覆盖超分辨率、去模糊等任务的统一视频恢复框架，把对齐和融合作为核心可学习模块，并验证 PCD、TSA 与二阶段细化在不同数据分布和退化类型下的有效性。
Card 03 核心贡献

核心贡献

  • 提出 PCD 对齐模块：以特征金字塔从粗到细估计运动，把低分辨率层的偏移与已对齐特征上采样到高分辨率层，并在金字塔之后级联额外可变形卷积继续细化。
  • 提出 TSA 融合模块：用参考帧与各邻帧嵌入的逐位置相关性生成时序权重，先调制并拼接已对齐特征，再用金字塔空间注意力扩大感受野并做像素级重标定。
  • 给出统一的 EDVR 数据流：高分辨率去模糊输入可先降采样并经 PreDeblur 改善对齐，PCD 与 TSA 后接残差重建和输出残差相加，使同一骨架适配多种视频恢复任务。
  • 为极端模糊和跨帧不一致设计二阶段恢复：用较浅的第二个 EDVR 细化第一阶段输出，并在四类竞赛退化以及公开超分、去模糊基准上分别评估。
Card 04 方法描述

方法描述

  • 所属模块：高空间分辨率输入先以步幅卷积降采样以节省计算，而凡属模糊输入均可在 PCD 前启用 PreDeblur 改善对齐；PCD 负责把每个邻帧特征对齐到参考帧；TSA 选择并聚合时空信息；残差块重建模块生成图像残差，输出端上采样后与直接上采样图像相加。
  • 输入与表示：输入为 2N+1 个连续低质量帧 I_[t−N:t+N]，中间 I_t 是参考帧，其他为邻帧；各帧先变为特征 F_[t+i]，PCD 输出对齐特征 Fᵃ_[t+i]，最终预测高质量参考帧 Ô_t。默认训练使用 N=2。
  • 模型结构：网络骨干先用五个残差块提取特征，PCD 采用三级金字塔（L=3）；主重建模块含 40 个残差块，二阶段浅层模型含 20 个，每个残差块为 128 通道。高分辨率去模糊输入先用步幅卷积降采样，输出端再恢复原尺寸。
  • 数据流：先从参考帧与每个邻帧构建多尺度特征；PCD 从最粗层开始预测偏移和对齐结果，并逐层上采样传给更细层，最后级联细化。TSA 将每个对齐特征与参考特征做嵌入相关，逐像素加权后拼接卷积融合，再施加空间注意力。融合结果通过残差重建；超分路径末端上采样并加到直接上采样输入，去模糊路径则把低分辨率计算结果上采样回原尺寸。
  • 关键技术：PCD 用调制可变形卷积的可学习偏移替代显式光流，并以金字塔和级联把对齐精化到亚像素级，整网联合训练而无需额外对齐监督或光流预训练。TSA 的时序注意力随空间位置变化，空间注意力再以金字塔扩大感受野。困难样本还可由较浅的第二阶段 EDVR 继续去除严重运动模糊并缓解帧间输出不一致。
  • 公式与超参数：可变形对齐计算为 Fᵃ_t+i=Σ_k w_k·F_t+i·Δm_k，偏移由 ΔP_[t+i]=f([F_[t+i],F_t]) 预测；时序权重 h=sigmoid(θ(Fᵃ_[t+i])ᵀφ(Fᵃ_t))，再逐像素乘到对齐特征并拼接卷积。可变形卷积核为 3×3、K=9，PCD 为 L=3。超分/去模糊 RGB patch 分别为 64×64 和 256×256，batch size 为 32、采用五帧输入（N=2）；Charbonnier 的 ε=1×10−3；Adam 的 β₁=0.9、β₂=0.999，初始学习率 4×10−4。
Card 05 数据集与资源

数据集与资源

  • 数据集：REDS：NTIRE19 发布的高质量 720p 视频数据集，覆盖更大、更复杂的运动，并用于训练、REDS4 测试和竞赛评估。
  • 数据集：Vimeo-90K：用于训练面向 Vid4 与 Vimeo-90K-T 的超分模型；Vimeo-90K-T 含多样运动与场景。
  • 数据集：Vid4：常用视频超分测试集，运动较有限，真值帧本身还存在可见伪影。
  • 规模与划分：REDS 原始划分为 240 个训练 clips、30 个验证 clips、30 个测试 clips，每个 clip 含 100 帧。因竞赛测试真值不可用，作者从训练/验证部分选 REDS4 的 000、011、015、020 四段作测试，其余重组为 266 个训练 clips。
  • 模型：PCD 随整个 EDVR 端到端联合学习，不使用额外对齐监督或光流等其他任务预训练；较深网络由较浅网络参数初始化以加快收敛。论文报告了残差块深度与通道配置，但未给出总参数量，也未采用外部基础模型。
  • 硬件：实现使用 PyTorch，训练硬件为 8 张 NVIDIA Titan Xp GPU；正文实验设置、结论与参考文献尾部未报告训练时长或推理硬件。
  • 代码：论文首页明确给出代码地址 https://github.com/xinntao/EDVR；目录元数据的 code_url 字段为空，因此此处只记录论文内发布声明，不改写继承字段。
  • 训练平台：软件平台为 PyTorch，数据与评测平台为 NTIRE19/REDS 的离线视频恢复基准；正文与实验部分不涉及仿真器、机器人或实车平台。
Card 06 评估与结果

评估与结果

  • 评估基准：Vid4：四倍视频超分辨率，在亮度 Y 与 RGB 通道上评测。
  • 评估基准：Vimeo-90K-T：四倍视频超分辨率，在 RGB 与亮度 Y 通道上评测。
  • 评估基准：REDS4：干净退化下的四倍视频超分辨率与视频去模糊，均在 RGB 通道评测。
  • 评估基准：NTIRE19 四赛道：超分干净、超分模糊、去模糊干净、去模糊压缩伪影。
  • 评估指标：PSNR（单位 dB，越高越好）；消融正文也直接用 dB 描述增益。
  • 评估指标：SSIM（无量纲，越高越好）；结果表按“PSNR/SSIM”成对报告。
  • 对比方法：视频超分辨率对比 RCAN、DeepSR、BayesSR、VESPCN、SPMC、TOFlow、FRVSR、DUF、RBPN，覆盖单帧、显式光流、动态滤波与循环/反投影路线。
  • 对比方法：视频去模糊在 REDS4 对比 DeepDeblur、DeblurGAN、SRN-Deblur、DBN。
  • 关键结果：Vimeo-90K-T 的 RGB 结果中，EDVR 达到 35.79 dB / 0.9374，DUF 为 34.33 dB / 0.9227；两项指标均越高越好。
  • 关键结果：REDS4 干净四倍超分均值中，EDVR 为 31.09 dB / 0.8800；RCAN 为 28.78 dB / 0.8200，DUF 为 28.63 dB / 0.8251。
  • 关键结果：REDS4 干净去模糊均值中，EDVR 为 34.80 dB / 0.9487，PSNR 与 SSIM 均为表中最佳。
  • 关键结果：NTIRE19 榜单的超分干净、超分模糊、去模糊干净、去模糊压缩四赛道，EDVR 分别取得 31.79/0.8962、30.17/0.8647、36.96/0.9657、31.69/0.8783，四列均列第一。
  • 消融实验：小模型消融中，单个可变形卷积改为四个可变形卷积提升 0.2 dB；进一步换成 PCD 后相对四卷积方案接近提升 0.4 dB；加入 TSA 又提升 0.14 dB，计算量保持相近。
  • 消融实验：PCD 可视化中，加入 PCD 后对齐特征间的光流更小且更干净；TSA 可视化显示较小运动的帧和区域往往获得更高注意力。
  • 消融实验：训练集与测试集分布不匹配会造成明显数据集偏差，正文报告性能大约下降半到一点五 dB，并据此指出跨数据分布泛化值得单独研究。
  • 消融实验：二阶段消融中，SR 干净由 31.09/0.8800 升至 31.54/0.8888，SR 模糊由 28.88/0.8361 升至 29.41/0.8503；去模糊干净由 34.80/0.9487 升至 36.37/0.9632，压缩退化由 30.24/0.8567 升至 31.00/0.8734。
  • 实验条件：主流方法对比禁用二阶段与 self-ensemble，使用全部输入帧且一般不裁边；仅 DUF 因严重边界效应裁去八个像素。竞赛榜单则启用二阶段，并对输入做翻转和旋转得到四种增强，逐一恢复、逆变换后取平均。
