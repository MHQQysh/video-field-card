CDC: Convolutional-De-Convolutional Networks for Precise Temporal Action Localization in Untrimmed Videos

2017-03-04 · 原文 · 翻译 · 1703.01515

要解决的是未裁剪长视频中的精确时间动作定位：系统既要判断每个动作属于什么类别，也要找出每个实例的开始与结束，而不能把边界锁死在预先生成的粗粒度片段上。 适用于一个视频含多个动作实例并夹杂复杂背景的离线分析，例如 THUMOS’14 中的逐帧标注与片段定位，以及 ActivityNet 中高层活动的时间定位；输出可用来修细已有 proposal 的边界。 论文真正检验的是：在 C3D 已能抽取时空语义却压缩时间分辨率后，能否用联合“空间卷积下采样＋时间反卷积上采样”的 CDC 滤波器恢复逐帧预测，并比插值、分离卷积/反卷积和循环模型得到更准的标签与边界。 研究背景：时间动作定位不只做视频级识别；面对含多实例和复杂背景的未裁剪视频，它同时要求动作类别与实例起止时间。论文仍利用高召回 proposal 抑制直接聚合逐帧结果时的噪声，但把定位模型的重心转向稠密帧级置信度。 核心痛点：滑窗或候选片段分类器只能给预定边界打分，边界无法由模型本身调整；单帧分类器忽略跨帧结构，RNN 虽建模时间依赖却不显式建模原始视频的时空信息，而 C3D 从 conv1a 到 conv5b 又把时间长度压缩八倍，损失精细边界所需的粒度。 任务定义：输入是原始视频段及其候选片段；网络需要为每一帧输出 K 个动作类别与一个背景类的置信度，再把帧级分数转成每个检测实例的类别、细化后起止帧和区间置信分。 研究目标：目标是在保留三维卷积所获高层时空语义的同时，把网络输出的时间长度恢复到输入长度并把空间维压成单点，从而用连续的帧级分数修正 proposal 的粗边界。

Card 02 论文概述

论文概述

  • 要解决的是未裁剪长视频中的精确时间动作定位：系统既要判断每个动作属于什么类别，也要找出每个实例的开始与结束，而不能把边界锁死在预先生成的粗粒度片段上。
  • 适用于一个视频含多个动作实例并夹杂复杂背景的离线分析，例如 THUMOS’14 中的逐帧标注与片段定位，以及 ActivityNet 中高层活动的时间定位；输出可用来修细已有 proposal 的边界。
  • 论文真正检验的是：在 C3D 已能抽取时空语义却压缩时间分辨率后，能否用联合“空间卷积下采样＋时间反卷积上采样”的 CDC 滤波器恢复逐帧预测，并比插值、分离卷积/反卷积和循环模型得到更准的标签与边界。
  • 研究背景：时间动作定位不只做视频级识别；面对含多实例和复杂背景的未裁剪视频，它同时要求动作类别与实例起止时间。论文仍利用高召回 proposal 抑制直接聚合逐帧结果时的噪声，但把定位模型的重心转向稠密帧级置信度。
  • 核心痛点：滑窗或候选片段分类器只能给预定边界打分，边界无法由模型本身调整；单帧分类器忽略跨帧结构，RNN 虽建模时间依赖却不显式建模原始视频的时空信息，而 C3D 从 conv1a 到 conv5b 又把时间长度压缩八倍，损失精细边界所需的粒度。
  • 任务定义：输入是原始视频段及其候选片段；网络需要为每一帧输出 K 个动作类别与一个背景类的置信度，再把帧级分数转成每个检测实例的类别、细化后起止帧和区间置信分。
  • 研究目标：目标是在保留三维卷积所获高层时空语义的同时，把网络输出的时间长度恢复到输入长度并把空间维压成单点，从而用连续的帧级分数修正 proposal 的粗边界。
Card 03 核心贡献

核心贡献

  • 提出联合 CDC 滤波器，在同一个可学习算子中做空间卷积下采样和时间反卷积上采样，使每个时间输出同时承载动作语义与细粒度动态。
  • 在 C3D 前端之上堆叠 CDC 层形成可端到端训练的定位网络，从原始视频直接生成逐帧类别分数，并用这些分数细化候选片段的时间边界。
  • 在逐帧标注与时间动作定位两类实验中系统比较帧模型、循环模型、插值、分离卷积/反卷积和既有定位器，验证联合滤波与细时间粒度对标签和边界精度的作用。
Card 04 方法描述

方法描述

  • 所属模块：3D ConvNets 前端从原始帧抽取高层时空语义；CDC6 把空间特征压成单点并开始恢复时间分辨率，CDC7、CDC8 继续逐级时间上采样；逐帧 softmax 再把每个时间位置变为动作或背景置信度，供 proposal 分类与边界细化。
  • 输入与表示：网络输入为 RGB 视频段 X，张量形状为 (3, L, 112, 112)，其中 L 是帧数；C3D 前端的 pool5 输出 (512, L/8, 4, 4)，通道承载抽象特征，时间轴已被压缩而空间仍为 4×4，训练监督则是逐帧类别标签。
  • 模型结构：前端采用 C3D 的 conv1a–conv5b 与只在高宽池化的 pool5。其后 CDC6 输出 (4096, L/4, 1, 1)，核、步幅、填充分别为 (4, 4, 4)、(2, 1, 1)、(1, 0, 0)；CDC7 与 CDC8 使用 (4, 1, 1) 核、(2, 1, 1) 步幅和 (1, 0, 0) 填充，最终输出 (K+1, L, 1, 1)。
  • 数据流：训练时把视频按不重叠的 32 帧窗口切分，只保留至少含一个动作帧的窗口，并用逐帧标签优化。测试时把每个 proposal 两端各扩展原长度的 1/8，只计算与扩展候选相交的窗口；类别取帧平均置信度最大的类。若不是背景，则对该类分数做高斯核密度估计，以 β=μ−σ 为阈值从两端向内收缩，最后把细化区间的帧平均分作为检测分数。
  • 关键技术：单个 CDC 滤波器把一组独立空间卷积核沿时间耦合：每个时间输出有专属卷积核、共享输入感受野，同时整体表现为时间一维反卷积。与先卷积再反卷积相比，它不迫使多个时间输出共享同一份高层语义；预训练全连接滤波器被复制到对应 CDC 滤波器作为初始化，以缓解联合滤波器参数更多带来的训练困难。
  • 公式与超参数：前向计算为 Y[c]=Σ_aΣ_b F[c,a,b]X[a,b]，即时间索引 c 汇聚同一空间感受野；帧级 softmax 后，以 L_loss=−(按训练片段数 N 归一化)Σ_nΣ_t log P_n^(z_n)[t] 汇总所有帧的分类损失。优化使用 SGD：CDC8 学习率 0.0001，其余层 0.00001，momentum 0.9、weight decay 0.005；CDC6、CDC7 的 dropout 为 0.5，THUMOS’14 上约 4 个 epoch、半天内收敛。
Card 05 数据集与资源

数据集与资源

  • 数据集：THUMOS’14：二十类动作；用 2,755 个裁剪训练视频与 1,010 个未裁剪验证视频（3,007 个动作实例）训练，测试使用 213 个非纯背景视频（3,358 个实例）。
  • 数据集：ActivityNet Challenge 2016：200 类活动，约 10K 个训练视频（15K 实例）与 5K 个验证视频（7.6K 实例），每个视频平均 1.65 个时间标注实例。
  • 规模与划分：THUMOS 数据把裁剪训练视频与未裁剪验证视频共同用于学习，并在非纯背景测试视频上评测；ActivityNet 主实验用训练视频学习、验证视频评测，附录还在测试集比较只用训练集与合并训练、验证集两种训练口径。
  • 模型：骨干采用 Sports-1M 预训练的 C3D，前段可直接初始化，FC6、FC7 分别适配为 CDC6、CDC7，CDC8 因类别通道不同而随机初始化。论文未给出参数总数，但报告典型 CDC 网络约一 GB 存储。
  • 硬件：实现细节明确给出单张十二 GB NVIDIA Titan X：窗口长度网格搜索后选 32 帧、batch size 为 8；致谢另称研究使用的 Tesla K40 由 NVIDIA 捐赠，但没有把它与某个具体训练阶段一一对应。正文实验与附录均未报告多 GPU 配置。
  • 代码：论文给出源码与训练模型地址 https://bitbucket.org/columbiadvmm/cdc；实现基于 Caffe 和 C3D。顶层 code_url 仍按输入元数据逐字保留为空，不把正文 URL 擅自写回元数据字段。
  • 训练平台：研究对象与运行载体是未裁剪视频和 Caffe/C3D 视频网络，不涉及仿真器、机器人或实车平台；方法、实验与附录均未报告机器人或实车部署。
Card 06 评估与结果

评估与结果

  • 评估基准：THUMOS’14：覆盖二十类动作，分别评测逐帧动作标注和时间动作定位。
  • 评估基准：ActivityNet Challenge 2016：覆盖二百类高层活动，评测验证集与测试集上的时间活动定位。
  • 评估指标：逐帧任务把每一类的全部测试帧按该类置信度排序，计算 AP，再跨类别取 mAP；两者均为越高越好。
  • 评估指标：时间定位以预测片段为排序单位；类别正确且与真值的 temporal IoU 大于阈值才算正确，同一真值不接受重复检测，最终计算 mAP（越高越好）。THUMOS’14 报告 IoU 0.3–0.7，ActivityNet 报告 0.5、0.75、0.95 及 Average-mAP。
  • 对比方法：逐帧实验比较 Single-frame CNN、Two-stream CNN、LSTM、MultiLSTM、C3D + LinearInterp、分离的 Conv & De-conv、固定三维卷积前端的 CDC 与完整 CDC。
  • 对比方法：THUMOS 时间定位与 Karaman、Wang、Heilbron、Escorcia、Oneata、Richard and Gall、Yeung、Yuan 及 S-CNN 比较；在同一 S-CNN proposals 下还比较插值、分离卷积/反卷积与固定前端版本。
  • 对比方法：ActivityNet 将 Wang and Tao 的挑战赛第一名片段在 CDC 细化前后对照，附录又加入 Singh and Cuzzolin、Singh 等公开基线。
  • 对比方法：附录还在 S-CNN 与 ResC3D+S-CNN 两种 proposal 方法上评测 CDC，用于检验细化效果是否依赖单一候选生成器。
  • 关键结果：THUMOS’14 逐帧 mAP：CDC 为 44.4，高于 Conv & De-conv 的 41.7、MultiLSTM 的 41.3 与 C3D + LinearInterp 的 37.0（越高越好）。
  • 关键结果：THUMOS’14 时间定位 mAP 在 IoU=0.3、0.4、0.5、0.6、0.7 时分别为 40.1、29.4、23.3、13.1、7.9；同阈值下 S-CNN 为 36.3、28.7、19.0、10.3、5.3。
  • 关键结果：ActivityNet 验证集上，用 CDC 细化 Wang and Tao 片段后，mAP 在 IoU=0.5 从 45.1 到 45.3，在 0.75 从 4.1 到 26.0，在 0.95 从 0.0 到 0.2，Average-mAP 从 16.4 到 23.8（越高越好）。
  • 关键结果：在单张十二 GB NVIDIA Titan X 上，CDC 网络约 500 FPS，可在一秒内处理 25 FPS、时长二十秒的视频片段；这是网络本身速度，不包含 proposal 与后处理组成的完整定位流水线。
  • 关键结果：ActivityNet 测试集的 mAP（列为 IoU=0.5、0.75、0.95、Average-mAP，越高越好）：CDC (train) 为 43.1、25.6、0.2、22.9；CDC (train+val) 为 43.0、25.7、0.2、22.9，后者合并训练集和验证集训练。
  • 消融实验：固定 3D ConvNets 时，THUMOS’14 逐帧 mAP 为 37.4；端到端训练后为 44.4，说明让前端随 CDC 层共同微调有益。
  • 消融实验：把 CDC6 换成分离的 conv6 + deconv6 时逐帧 mAP 为 41.7，联合 CDC 为 44.4，说明优势不只是做了时间上采样。
  • 消融实验：边界扩展比例 α 从 1/8 到 1/4 时，IoU=0.5 的 THUMOS’14 mAP 保持在 23.1–23.6，说明合理扩展范围内较稳定。
  • 消融实验：时间输出从每八帧一个标签逐级提升到每帧一个标签时，THUMOS’14、IoU=0.5 的定位 mAP 随时间粒度提高而上升。
  • 消融实验：在 ResC3D+S-CNN proposals 上，IoU=0.5 的 THUMOS’14 mAP 由无 CDC 的 22.5 升至使用 CDC 的 24.7；使用 CDC 时，在 IoU=0.3、0.4、0.5、0.6、0.7 下依次为 41.3、30.7、24.7、14.3、8.8（越高越好）。
  • 实验条件：THUMOS’14 定位使用公开的 S-CNN proposal、标准 NMS，并统一把候选两侧各扩展原长度的 1/8；训练与推理按不重叠的 32 帧窗口处理。模型由 Sports-1M 预训练 C3D 初始化，再在目标数据上端到端训练，并非零样本。ActivityNet 主实验用训练集训练、验证集评测，候选片段来自 Wang and Tao。
