HOTA: A Higher Order Metric for Evaluating Multi-Object Tracking

2020-09-16 · 原文 · 翻译 · 2009.07736

HOTA 解决多目标跟踪评价把检测、跨帧关联和定位割裂开、且旧主指标偏向其中一侧的问题；它把三者纳入一个既可统一排序、又可分解诊断的指标。 它用于把逐帧物体检测及其身份轨迹与标注轨迹比较的场景，包括监控、机器人和自动驾驶，也可迁移到边界框、分割掩码、三维框、人体姿态与点轨迹等表示。 论文真正检验的是：检测级匹配与全视频高阶关联能否形成不偏向检测或关联的单分数，同时保持对五类错误的可分解性和单调性，并比 MOTA、IDF1 更贴近人类对跟踪质量的判断。 研究背景：多目标跟踪以连续视频为输入，既要判断每帧有哪些对象及其位置，也要把跨帧检测关联为身份一致的轨迹。评价指标决定漏检、误检、定位和身份关联错误如何进入总分，因此会直接影响基准排序与研究优化方向。 核心痛点：MOTA 在检测级做局部关联计分，显著偏向检测且不把定位质量并入主分数；IDF1 采用整轨迹唯一匹配，加入正确检测也可能降分；Track-mAP 要求带置信度排序的候选轨迹，既不对应最终跟踪结果，也与不要求轨迹置信度的常用基准不兼容。 任务定义：给定逐帧的标注检测 gtDet 与预测检测 prDet，以及各自跨帧一致的 gtID、prID，评价器依据表示相关的定位相似度 S 和阈值 α 做逐帧一对一匹配，再度量检测正确性、轨迹关联一致性和定位质量。输出是可排序的总体 HOTA 分数及用于诊断不同错误的子分数。 研究目标：目标是得到一个公平组合跟踪各方面的单一分数，用全视频范围的高阶关系评价长期关联，同时还能分解为解释检测、关联与定位失误的子指标。

Card 02 论文概述

论文概述

  • HOTA 解决多目标跟踪评价把检测、跨帧关联和定位割裂开、且旧主指标偏向其中一侧的问题；它把三者纳入一个既可统一排序、又可分解诊断的指标。
  • 它用于把逐帧物体检测及其身份轨迹与标注轨迹比较的场景，包括监控、机器人和自动驾驶，也可迁移到边界框、分割掩码、三维框、人体姿态与点轨迹等表示。
  • 论文真正检验的是：检测级匹配与全视频高阶关联能否形成不偏向检测或关联的单分数，同时保持对五类错误的可分解性和单调性，并比 MOTA、IDF1 更贴近人类对跟踪质量的判断。
  • 研究背景：多目标跟踪以连续视频为输入，既要判断每帧有哪些对象及其位置，也要把跨帧检测关联为身份一致的轨迹。评价指标决定漏检、误检、定位和身份关联错误如何进入总分，因此会直接影响基准排序与研究优化方向。
  • 核心痛点：MOTA 在检测级做局部关联计分，显著偏向检测且不把定位质量并入主分数；IDF1 采用整轨迹唯一匹配，加入正确检测也可能降分；Track-mAP 要求带置信度排序的候选轨迹，既不对应最终跟踪结果，也与不要求轨迹置信度的常用基准不兼容。
  • 任务定义：给定逐帧的标注检测 gtDet 与预测检测 prDet，以及各自跨帧一致的 gtID、prID，评价器依据表示相关的定位相似度 S 和阈值 α 做逐帧一对一匹配，再度量检测正确性、轨迹关联一致性和定位质量。输出是可排序的总体 HOTA 分数及用于诊断不同错误的子分数。
  • 研究目标：目标是得到一个公平组合跟踪各方面的单一分数，用全视频范围的高阶关系评价长期关联，同时还能分解为解释检测、关联与定位失误的子指标。
Card 03 核心贡献

核心贡献

  • 提出 HOTA：在检测级匹配后，为每个匹配检测计算其标注轨迹与预测轨迹的全局关联对齐，再用双重 Jaccard 结构汇总为统一跟踪分数。
  • 把总体分数分解为 DetA、AssA、LocA，以及检测召回、检测精度、关联召回、关联精度，从而分别对应五类基本跟踪错误。
  • 系统分析 HOTA、MOTA、IDF1 与 Track-mAP 的匹配域、关联域、偏置、单调性和可解释性，并用设计空间反例说明 HOTA 各组成选择的作用。
  • 在 MOT17 上对 37 个已发表且经同行评审的跟踪器重新计算 HOTA 及其子分数，比较它与 MOTA、IDF1 的排序和相关性。
  • 设计指标两两显著分歧的头对头视频用户研究，直接检验 HOTA、MOTA、IDF1 哪一种排序更符合人类对跟踪质量的视觉判断。
Card 04 方法描述

方法描述

  • 所属模块：HOTA 不是新的检测器或跟踪网络，而是接收标注轨迹和预测轨迹的评估器。它输出用于整体排名的 HOTA，并同时输出检测、关联、定位及召回/精度子指标，因而把统一比较与错误诊断放在同一套计算中。
  • 输入与表示：标注与预测都表示为每帧检测集合；同一真实对象的 gtDet 共享 gtID，同一预测轨迹的 prDet 共享 prID。检测表示可为二维框、三维框、分割掩码、人体姿态或点，只需定义落在零到一之间的相似度 S；仅当 S≥α 时一对 gtDet/prDet 才能匹配。
  • 模型结构：计算分为四层：先在每帧形成检测级一对一匹配并得到 TP、FN、FP；再围绕每个 TP 构造 TPA、FNA、FPA；随后用检测 Jaccard 与逐 TP 的关联 Jaccard 组成双重 Jaccard；最后跨定位阈值平均，并展开为 DetA、AssA、LocA 及四个召回/精度分量。
  • 数据流：对每个 α，先用匈牙利算法选择匹配，依次最大化 TP 数、TP 上的平均关联分数 A、TP 上的平均定位相似度 S。未匹配标注和预测成为 FN、FP；每个 TP c 再按 ID 一致性统计 TPA(c)、FNA(c)、FPA(c)，求 A(c) 和 HOTAα。α 从 0.05 到 0.95、步长 0.05 重复完整匹配，最后对各 HOTAα 取均值。
  • 关键技术：关键点是高阶关联：每个匹配检测都与整段视频里所有相关检测比较，而不只看前一帧；同时保留检测级匹配，使一条轨迹可在不同时间与不同轨迹段对齐。匹配使用 TP 数、关联质量、定位质量的分级目标；关联分数纳入匹配轨迹中的漏检和误检，再以 DetA 与 AssA 的几何平均平衡两类误差并保持单调性。
  • 公式与超参数：对给定真阳性 c，A(c)=|TPA(c)|/(|TPA(c)|+|FNA(c)|+|FPA(c)|)，三项分别统计与 c 同 gtID 且同 prID、同 gtID 但不同或缺失 prID、同 prID 但不同或缺失 gtID 的关联。HOTAα=√(Σ[c∈TP]A(c)/(|TP|+|FN|+|FP|))=√(DetAα·AssAα)。最终 HOTA 是 α 从 0.05 到 0.95、步长 0.05 时各 HOTAα 的均值；α 是最低定位相似度，TP、FN、FP 均在该 α 下重新匹配得到。

Card 06 评估与结果

评估与结果

  • 评估基准：MOTChallenge MOT17 主实验：对 37 个同行评审跟踪器计算 HOTA、MOTA、IDF1 和 HOTA 子指标并比较排序。
  • 评估基准：MOT17 人类视觉评估：把同一短视频上的两种跟踪结果并排展示，检验不同指标给出的优劣判断。
  • 评估指标：HOTA（越高越好）是总体排名指标；DetA、AssA、DetRe、DetPr、AssRe、AssPr、LocA 均为越高越好的诊断分数，分别衡量检测、关联、召回/精度与定位。
  • 评估指标：MOTA、IDF1 均按越高越好作为实证对照；Track-mAP 只进入理论比较，因为 MOTChallenge 提交不含它所需的轨迹置信度。
  • 对比方法：方法层面对照覆盖 MOTA 的检测级短期关联、IDF1 的轨迹级唯一匹配、Track-mAP 的置信度候选轨迹，以及 HOTA 的检测级匹配加全局高阶关联。
  • 对比方法：用户研究做 HOTA 对 MOTA、HOTA 对 IDF1、MOTA 对 IDF1 的头对头比较；参与者可选择左侧更好、右侧更好、两者相同或跳过。
  • 关键结果：在 MOT17 的 37 个同行评审跟踪器中，MPNTrack17 按 HOTA 排第 1，HOTA 为 46.6 分；其 DetA 为 46.2、AssA 为 47.3，所有这些分数均越高越好。
  • 关键结果：线性拟合的决定系数越高表示关系越强：MOTA 对 DetA、AssA 分别为 0.96、0.46；IDF1 分别为 0.58、0.97；HOTA 分别为 0.67、0.94，显示 HOTA 同时随检测与关联质量变化。
  • 关键结果：排除选择两者相同的回答后，全体参与者在 HOTA 对 MOTA 时分别有 61.6% 与 38.4% 的判断一致率；在 HOTA 对 IDF1 时分别为 72.0% 与 28.0%，一致率越高表示指标越贴近人类判断。
  • 关键结果：用户研究共有 230 名参与者，其中 62 名是多目标跟踪研究者、122 名是计算机视觉研究者，共产生 2075 次独立的跟踪器比较。
  • 消融实验：论文没有训练模型消融，而是做指标设计消融：用论文中的反例图比较 Jaccard、F1、MODA，并比较关联分数是否纳入未匹配检测；只有 Jaccard 且纳入这些检测时满足所需的对称与单调行为。
  • 消融实验：另一组设计分析比较有无平方根以及有无 DetA：平方根把 DetA 与 AssA 解释为几何平均并避免重复计数；保留 DetA 会惩罚完全未匹配轨迹，并防止新增正确匹配反而降低总分。
  • 实验条件：MOT17 主实验只纳入已发表、经同行评审且文献信息可查的方法，全部跟踪器以给定公共检测为输入；因提交不含轨迹置信度，未计算 Track-mAP。用户研究只选两指标排序相反且各自绝对分差大于 0.05 的头对头视频，左右位置随机，播放速度为自然帧率的一半。
