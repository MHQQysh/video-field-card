Knowledge Integration Networks for Action Recognition

2020-02-18 · 原文 · 翻译 · 2002.07471

要解决的问题是：只靠视频级动作标签让网络隐式学习，难以主动利用人体区域与场景上下文；KINet 希望借助教师伪标签显式学习这两类知识，同时避免为大规模动作视频增加昂贵的逐像素人工标注。 适用场景是只有视频级标签的离线动作分类：模型从整段视频稀疏采样；当低分辨率或运动模糊使关键物体不清晰时，人体外观、姿态与场景仍可提供辨别线索。 论文真正检验的是：伪标签监督下可学习的辅助分支是否比冻结外部网络更适配动作主任务，以及中层 CBI 与高层 AKG 能否把人体、场景知识转化为可跨数据集迁移的准确率增益。 研究背景：人体动作是高层语义概念，可能由人物穿着、人体姿态和场景共同界定；在低清或运动模糊视频里，单一物体线索可能缺失，因此上下文能补足动作表征。 核心痛点：已有做法要么仅用视频级标签让 CNN 隐式学习，要么依赖 A2D 式逐像素演员与动作标注；前者不显式建模上下文，后者标注昂贵且多数大规模动作分类集并不提供。另一些方法直接调用独立训练并冻结的外部语义网络，又限制了辅助表示对动作主任务的适配。 任务定义：输入是一段视频；TSN 动作主分支在整段视频上稀疏采样片段并形成视频级动作预测。训练时另外预测人体分割和场景类别，二者由教师伪标签监督；高层图推理后只使用动作节点完成最终分类。 研究目标：目标是在无需额外人工人体或场景标注的情况下，把中层卷积特征与高层语义关系两个层次的外部知识编码进端到端动作识别器，并考察准确率、骨干适配性与跨数据集迁移能力。

Card 02 论文概述

论文概述

  • 要解决的问题是：只靠视频级动作标签让网络隐式学习，难以主动利用人体区域与场景上下文；KINet 希望借助教师伪标签显式学习这两类知识，同时避免为大规模动作视频增加昂贵的逐像素人工标注。
  • 适用场景是只有视频级标签的离线动作分类：模型从整段视频稀疏采样；当低分辨率或运动模糊使关键物体不清晰时，人体外观、姿态与场景仍可提供辨别线索。
  • 论文真正检验的是：伪标签监督下可学习的辅助分支是否比冻结外部网络更适配动作主任务，以及中层 CBI 与高层 AKG 能否把人体、场景知识转化为可跨数据集迁移的准确率增益。
  • 研究背景：人体动作是高层语义概念，可能由人物穿着、人体姿态和场景共同界定；在低清或运动模糊视频里，单一物体线索可能缺失，因此上下文能补足动作表征。
  • 核心痛点：已有做法要么仅用视频级标签让 CNN 隐式学习，要么依赖 A2D 式逐像素演员与动作标注；前者不显式建模上下文，后者标注昂贵且多数大规模动作分类集并不提供。另一些方法直接调用独立训练并冻结的外部语义网络，又限制了辅助表示对动作主任务的适配。
  • 任务定义：输入是一段视频；TSN 动作主分支在整段视频上稀疏采样片段并形成视频级动作预测。训练时另外预测人体分割和场景类别，二者由教师伪标签监督；高层图推理后只使用动作节点完成最终分类。
  • 研究目标：目标是在无需额外人工人体或场景标注的情况下，把中层卷积特征与高层语义关系两个层次的外部知识编码进端到端动作识别器，并考察准确率、骨干适配性与跨数据集迁移能力。
Card 03 核心贡献

核心贡献

  • 提出三分支 KINet：动作主分支与人体解析、场景识别辅助分支在两个预训练教师的伪标签监督下协同训练，从而显式学习上下文而不要求动作数据集增加人工密集标注。
  • 提出 CBI，把辅助分支的中层特征作为动作特征的门控调制，经残差式交互、通道拼接与压缩直接注入动作分支。
  • 提出 AKG，在各时段的动作、人体和场景高层向量上建图，用带掩码的关系边和图卷积聚合语义，最终只取动作节点用于分类。
  • 通过组件消融、参数量与多骨干比较验证方法，并把 Kinetics-400 表示迁移到 UCF-101；双流 KINet 的 top-1 准确率分别为 77.8% 与 97.8%。
Card 04 方法描述

方法描述

  • 所属模块：动作主分支负责最终视频分类；人体辅助分支学习合并后的人体前景分割，场景辅助分支学习场景类别。预训练的人体解析与场景识别教师产生伪标签，CBI 负责中层交互，AKG 负责高层关系融合。作者还尝试通过蒸馏加入物体分支，但出现性能下降和不稳定结果，且未报告具体数值；作者推测可能因低分辨率或运动模糊使精确物体难辨，以及检测或分割类别有限、动作涉及物体更多且噪声 proposal 难以蒸馏。
  • 输入与表示：输入表示沿用 TSN：训练时将整段视频均匀分成 Nseg = 3 个片段，每段随机取一帧；动作分支可用 RGB 单流。主表双流配置以 KINet 作为 RGB 流、以普通 TSN 作为光流流，对应两项准确率 77.8 / 93.1；三个分支分别做全局平均池化后，各自产生 Nseg 个 d 维向量。
  • 模型结构：低层骨干由三项任务共享，高层分成互不共享参数的动作、人体、场景分支；CBI 位于中层，高层经全局平均池化后构成 N = 3 × Nseg 个节点的 AKG。图卷积输出与输入同形，最终只保留动作节点用于预测。
  • 数据流：视频帧先送入人体解析与场景教师得到伪标签；KINet 共享低层特征后分为三路，辅助路由伪标签计算损失并在 CBI 处调制动作特征；三路高层向量经全局平均池化进入 AKG 关系推理，取动作节点形成视频分类，训练时联合优化三项任务。推理只服务动作识别时，可移除人体解析 decoder 与场景识别全连接 classifier；论文明确移除的是这两个辅助输出头。
  • 关键技术：CBI 对辅助特征与动作特征做逐元素乘法，接残差式 BN 与 ReLU，再把三路特征按通道拼接并用 1 × 1 卷积恢复通道数。AKG 仅保留与动作节点相连的边并屏蔽 human-scene 边；候选关系含点积、嵌入点积和 ReLU 拼接，经 softmax 归一化后用单层 GCN 推理，后续实验选择点积。
  • 公式与超参数：关系分数可取点积 f(x_a,x_b)=x_a^T x_b、嵌入点积或 ReLU 拼接；边权经 softmax 归一化，图卷积为 Z=σ(I_mask⊙GXW)，正文只堆叠 1 层。联合损失为 L=λ_action L_action+λ_human L_human+λ_scene L_scene，主任务权重为 1，两项辅助任务各为 0.01。训练时 Nseg = 3；Kinetics 初始学习率为 0.01，在第 20、40、60 个 epoch 各降 10 倍，总计 70 个 epoch，权重衰减为 10 的负 5 次方、动量为 0.9；UCF-101 微调 80 个 epoch。推理均匀采样 25 个 segment，每帧做 10 个 crop，共 250 张图，并以 Nseg = 3 的滑窗平均。
Card 05 数据集与资源

数据集与资源

  • 数据集：LIP 用于训练人体解析教师；其 19 个人体部位标签被合并为单一人体分割目标，以减轻低分辨率伪标签噪声。
  • 数据集：Places365 用于训练场景教师，论文说明它包含 365 个场景类别。
  • 数据集：Kinetics-400 是主训练与验证动作集，含 400 类、约 240k 个训练视频和 20k 个验证视频。
  • 数据集：UCF-101 用于迁移评估，含 101 类、共 13,320 段视频；ImageNet 只用于初始化网络权重。
  • 规模与划分：Kinetics-400 采用约 240k 与 20k 的训练/验证划分；UCF-101 按 3 个训练/测试划分分别评估后取平均。LIP 的人体监督从 19 类部位合并为单前景，Places365 保留 365 类场景伪标签。
  • 模型：动作主干采用 TSN 二维网络，主结果覆盖 ResNet50、BN-Inception 与 Inception V3；人体教师是 PSPNet（DenseNet-121 骨干），场景教师是 ResNet152，框架以 ImageNet 预训练权重初始化。

Card 06 评估与结果

评估与结果

  • 评估基准：Kinetics-400：大规模动作识别基准，报告 RGB 单流与双流 KINet。
  • 评估基准：UCF-101：将 Kinetics 预训练表示微调后，按标准 3 个训练/测试划分取平均。
  • 评估指标：视频级 top-1 准确率，数值越高越好。
  • 评估指标：Kinetics-400 还报告视频级 top-5 准确率，数值越高越好。
  • 对比方法：组件与参数消融以 TSN-ResNet50 为基线，比较多任务蒸馏、CBI 布置、AKG 关系函数、完整 KINet，以及更深的 TSN-ResNet200。
  • 对比方法：Kinetics-400 主表同时列出二维、三维与双流方法，以区分骨干及输入流设置。
  • 对比方法：UCF-101 表比较双流 TSN、双流 I3D、StNet-RGB 和双流 KINet；另以固定与可学习辅助分支检验联合微调。
  • 关键结果：Kinetics-400 表中准确率单位为 %：RGB KINet-ResNet50 的 top-1 / top-5 为 72.4 / 90.3；TSN-ResNet50 为 69.5 / 88.9；完整 KINet 的 top-1 绝对增益为 +2.9 个百分点。
  • 关键结果：同一 Kinetics 表中，双流 KINet（Inception V3）为 77.8 / 93.1，SlowFast 为 79.8 / 93.9（依次为 top-1 / top-5，单位：%）；因此该表中的 KINet 并非最高 top-1。
  • 关键结果：UCF-101 上，双流 KINet 的 top-1 为 97.8；双流 TSN（Inception V3）为 97.3，双流 I3D 为 98.0（单位：%）。
  • 关键结果：在 playing basketball 激活图的定性可视化中，作者观察到 KINet-ResNet50 相比 TSN-ResNet50 呈现更清晰的人体与场景概念；这是可视化观察，不是新增定量指标。
  • 消融实验：知识蒸馏多任务消融中，human、scene、二者同时的 top-1 分别为 70.3、70.0、70.6，增益分别为 +0.8、+0.5、+1.1；基线为 69.5（单位：%）。
  • 消融实验：CBI 布置中，在 res4 和 res5 各放一个 CBI 时为 71.8、增益 +2.3；只在 res4 放一个或两个 CBI 时分别为 71.1 和 71.2（单位：%），作者选择前者兼顾精度与效率。
  • 消融实验：AKG 点积、嵌入点积、ReLU 拼接分别为 71.7 / 71.6 / 71.2，增益为 +2.2 / +2.1 / +1.7（单位：%）；后续实验选择点积。
  • 消融实验：固定辅助分支为 70.5，可学习辅助分支为 72.4，基线为 69.5（单位：%）；结果支持伪标签联合微调比直接冻结教师更适合动作识别。
  • 消融实验：KINet-ResNet50 有 56.9M 参数、准确率 72.4；TSN-ResNet200 有 64.5M 参数、准确率 70.7（准确率单位：%），说明增益不能仅归因于更多参数。
  • 消融实验：Kinetics-400 多骨干 top-1（越高越好）中，ResNet50 从 69.5 提升到 72.4（+2.9），BN-Inception 从 69.1 提升到 71.8（+2.7），Inception V3 从 72.5 提升到 74.1（+1.6），三种骨干均有增益。
  • 实验条件：Kinetics 训练以 ImageNet 权重初始化，每帧先缩放为 256 × 340，再做多尺度裁剪增强；Nseg = 3，使用 SGD，初始学习率为 0.01，在第 20、40、60 个 epoch 各降 10 倍，总计 70 个 epoch，权重衰减为 10 的负 5 次方、动量为 0.9。UCF-101 从 Kinetics 权重微调时，除第一个 batch-normalization 层外其余均冻结，训练 80 个 epoch，并平均 3 个划分。测试均匀采样 25 个 segment，每帧做 10 个 crop，共 250 张图，以 Nseg = 3 的滑窗平均；均为有监督离线视频分类，不是零样本、闭环或实机评测。
