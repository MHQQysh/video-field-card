Towards Good Practices for Very Deep Two-Stream ConvNets

2015-07-08 · 原文 · 翻译 · 1507.02159

论文针对短视频动作识别中“网络越深却未必越好”的现象，提出两种可能解释：当时双流 ConvNets 相比图像领域的深模型更浅、建模容量有限，而 UCF101 仅有 13, 320 个片段，直接训练深网又容易过拟合。 具体使用场景是给一段短动作视频判类别：空间流接收单帧 RGB，时间流接收连续光流堆叠，两路各自产生类别分数，并通过测试采样、裁剪平均和加权融合得到视频级动作判断。 论文真正检验的是：深骨干配合双分支 ImageNet 预训练、小学习率、裁剪增强和高 dropout，能否提升 UCF101 的平均动作识别准确率；THUMOS15 的既有结果只提示，未采用这些实践时更深的时间流不一定更好。多 GPU 系统另行验证训练速度与每 GPU 内存。 研究背景：视频动作识别当时有两条主线：一类沿 improved trajectories 提取手工局部特征并以 Fisher vector 编码，另一类从 RGB 帧或光流场端到端学习表示，其中具有竞争力的深度方案是空间流与时间流组成的 two-stream ConvNets。 核心痛点：动作概念更复杂，并与交互物体、场景上下文和人体姿态相关；作者直觉认为，更复杂的问题可能需要容量更高的模型。但原双流网络只有 5 个卷积层和 3 个全连接层，而动作数据远小于 ImageNet，UCF101 只有 13, 320 个片段，在小数据上训练很深模型会面临过拟合挑战。 任务定义：输入视频分别形成 224×224×3 的单帧 RGB 和 224×224×20 的十帧堆叠光流；两个网络各自产生动作类别分数，测试时跨采样帧与裁剪区域平均，再以时间流权重 2、空间流权重 1 做线性融合。 研究目标：研究目标不是提出新的视频骨干，而是考察图像分类中的 GoogLeNet 与 VGGNet-16 能否适配为视频双流网络，并寻找在小型动作数据集上稳定训练、减轻过拟合的实践；多 GPU 实现则作为独立工程目标，用于降低训练时间与每 GPU 内存。

Card 03 核心贡献

核心贡献

  • 把 GoogLeNet 和 VGGNet-16 适配为 very deep two-stream ConvNets：空间网保持图像模型结构，时间网把首层改为接收十帧光流堆叠，从而在外观与运动两路同时提升深度和容量。
  • 给出面向小型动作数据集的成套训练实践：空间流和时间流都从 ImageNet 预训练，使用更小且分段衰减的学习率、角点与多尺度裁剪增强，并为全连接层配置高 dropout。
  • 将 Caffe 与 OpenMPI 扩展为数据并行多 GPU 训练，并通过汇聚各 worker 的激活来避免同步全连接参数；作者报告在 4 块 GPU 的设置下，VGGNet-16 与 GoogLeNet 的训练分别获得 3.7x 和 4.0x 加速，并称每 GPU 使用“4x less memory”，但未说明对照硬件细节。
  • 主结果表将原 two-stream 论文的 ClarifaiNet 结果，与采用本文训练实践的 GoogLeNet、VGGNet-16 空间流、时间流和融合结果并列比较；其中 VGGNet-16 双流在三个划分上的平均准确率为 91.4%。
Card 04 方法描述

方法描述

  • 所属模块：空间网负责从单帧 RGB 提取外观线索，时间网负责从堆叠光流提取运动线索；训练实践模块针对小数据下的初始化、正则化和采样多样性问题，多 GPU 模块用于降低训练时间与显存，最终的分数融合模块输出视频级动作类别。
  • 输入与表示：空间流输入为 224×224×3 图像；时间流输入为 224×224×20，即十帧光流场堆叠形成 20 通道。光流先线性离散到 [0, 255]，时间网首层把 ImageNet RGB 滤波器沿通道求平均，再复制 20 份作为初始化。
  • 模型结构：候选深骨干为含 Inception 模块的 22 层 GoogLeNet，以及包含 13 个卷积层和 3 个全连接层的 VGGNet-16。空间网直接沿用图像模型；时间网除首层输入通道和卷积核不同外，沿用对应深结构，最后与空间网构成双流。
  • 数据流：先为视频提取 TVL1 光流，形成单帧图像与十帧光流堆叠两路输入；用 ImageNet 权重初始化两路，在角点与多尺度裁剪增强下微调；训练采用多 GPU 数据并行，并汇聚各 worker 激活；测试时两路各采样输入、生成十裁剪并平均分数，再用加权线性组合融合。
  • 关键技术：作者观察到随机裁剪更可能集中于画面中心，因此角点裁剪只取四角和中心，旨在增加输入变化并帮助缓解过拟合；多尺度裁剪把 256×340 输入的宽高从 {256,224,192,168} 随机取值后缩放到 224×224，同时引入尺度与长宽比扰动。时间流全连接层 dropout 为 0.9、0.8，空间流为 0.9、0.9。
  • 公式与超参数：时间流学习率从 0.005 开始，每 10,000 次迭代衰减为此前的十分之一，在 30,000 次停止；空间流从 0.001 开始，每 4,000 次衰减为此前的十分之一，在 10,000 次停止。测试时每路选 25 个帧/光流位置，每个位置取四角、中心及其水平翻转共 10 个输入；融合分数为 2×时间流分数+1×空间流分数。
Card 05 数据集与资源

数据集与资源

  • 数据集：UCF101：101 个动作类别、13, 320 段视频，每类至少 100 段并按每类 25 组组织；采用三个训练/测试划分。
  • 数据集：ImageNet：作为空间网与时间网预训练初始化权重的来源。
  • 数据集：THUMOS15 validation：只引用作者先前工作中未采用本文训练实践的结果，用作跨数据集回顾，不属于当前 UCF101 主实验。
  • 规模与划分：每个 UCF101 划分约含 10,000 个训练片段和 3300 个测试片段；最终指标按 THUMOS13 方案在三个划分上计算类别平均识别准确率，再对划分取平均。论文未重述 ImageNet 预训练集或 THUMOS15 validation 的规模与划分。
  • 模型：论文实证比较 ClarifaiNet、GoogLeNet 与 VGGNet-16；空间网、时间网均使用 ImageNet 模型预训练，其中时间网通过通道平均与复制改造首层权重。全文的网络架构、训练和实验部分未给出这些网络的参数总量或模型文件哈希。
  • 硬件：作者报告在 4 块 GPU 的设置下，VGGNet-16 与 GoogLeNet 的训练分别获得 3.7x 和 4.0x 加速，并称每 GPU 使用“4x less memory”；全文训练与实验设置未注明 GPU 型号、CPU、主机配置或对照硬件细节。
  • 代码：多 GPU 系统的论文脚注地址为 https://github.com/yjxiong/caffe/tree/action_recog；全文与脚注未报告许可证、依赖版本或固定提交哈希。
  • 训练平台：网络训练系统基于 Caffe 与 OpenMPI；实验使用 OpenCV 的 TVL1 光流实现，作者选择它是因为准确性与效率之间的平衡。全文未涉及仿真器、机器人或实车平台。
Card 06 评估与结果

评估与结果

  • 评估基准：UCF101：按 THUMOS13 评测方案使用三个训练/测试划分，主表报告每类平均识别准确率。
  • 评估基准：THUMOS15 validation：仅作为作者早先未采用本文训练实践时的回顾性对照，不是与 UCF101 主结果同数据、同协议的受控消融。
  • 评估指标：动作识别 accuracy，越高越好；UCF101 先在每个划分内按类别平均，再报告三个划分的平均值。
  • 对比方法：架构比较覆盖 ClarifaiNet、GoogLeNet、VGGNet-16 的空间流、时间流与双流融合。
  • 对比方法：状态方法比较覆盖 iDT+FV、iDT+HSV、MIFS+FV、TDD+FV、DeepNet、Two-stream 和 Two-stream+LSTM。
  • 关键结果：UCF101 三划分平均：VGGNet-16 空间流 78.4%、时间流 87.0%、双流 91.4%；对应 GoogLeNet 为 75.3%、85.8%、89.3%，ClarifaiNet 为 73.0%、83.7%、88.0%。
  • 关键结果：主结果表并列报告 very deep two-stream 的 91.4% 与原 Two-stream 的 88.0%，论文将差值写作 3.4%；架构与训练配方同时变化，不能把它解释为训练实践的受控增益。VGGNet-16 空间流与时间流相对浅网约高 5% 和 4%，这里的“约”沿用作者表述。
  • 关键结果：与深度方法比较时，91.4% 比此前 Two-stream+LSTM 的 88.6% 高 2.8%；若把手工/深度编码方法也纳入状态方法总表，TDD+FV 为 90.3%，因此不能把 2.8% 解释成对全表次优方法的领先。
  • 消融实验：论文没有逐项移除预训练、学习率、裁剪或 dropout 的同数据受控消融；THUMOS15 对照表只回顾未采用这些实践的 validation：时间流 ClarifaiNet、GoogLeNet、VGGNet-11 分别为 47.0%、39.9%、42.6%，深模型反而没有更好。
  • 消融实验：作者把 UCF101 与 THUMOS15 的差异解释为这些实践可能有效，具体点名时间网 ImageNet 预训练和更多数据增强，但原文使用 conjecture，因而只能视为跨数据集观察支持的推测，不能写成已经隔离变量的因果结论。
  • 实验条件：UCF101 使用三个训练/测试划分；TVL1 光流由 OpenCV 计算。测试时每路采样 25 个位置，每个位置取 10 个裁剪并平均，双流融合权重为时间流 2、空间流 1。论文未报告多随机种子、标准差、置信区间或显著性检验。
