Thin-Slicing Network: A Deep Structured Model for Pose Estimation in Videos

2017-03-31 · 原文 · 翻译 · 1703.10898

这篇论文解决无约束视频中的人体姿态估计：逐帧 ConvNet 在自遮挡、运动模糊和训练集中罕见姿态下容易漏检或混淆关节，把单帧模型直接用于视频还会产生可见抖动；作者因此要同时利用骨架空间关系与邻帧时间线索。 具体使用场景是自然、无约束的视频序列：系统一次接收一小段相邻帧，先为每帧回归身体关节热图，再用稠密光流对齐邻帧信息，最后输出该片段中各帧的关节位置；论文在 Penn Action 与 JHMDB 的预录制视频上离线评测。 论文真正检验的是：把关节回归器、光流传播和任意环状时空图上的消息传递统一为可端到端训练的结构化网络，是否不仅优于纯 ConvNet 和仅空间推理，还能通过联合训练改善底层一元关节预测。 研究背景：人体姿态估计是计算机视觉基础问题，可服务生命科学、动画、机器人、增强现实和虚拟现实，也能支持视频活动识别；视频相较单图还提供人体运动的时间一致性，可由光流传播和时空推理利用。 核心痛点：无约束在线视频常见遮挡、非常规姿态和运动模糊；即使加入单帧骨架空间先验，关节检测仍会出错，逐帧应用还会形成抖动。显式构造空间与时间依赖又会得到大树宽环图，使精确推理不可行。 任务定义：给定由少量相邻帧组成的 thin-slice，任务是预测姿态序列；每帧姿态是各身体部位在图像空间中的 2D 坐标集合。模型以 ConvNet 热图作为一元外观分数，以骨架边描述帧内空间兼容性，并以经光流对齐的同一关节边约束邻帧时间一致性。 研究目标：研究目标是在不假定显式人体运动模式的前提下，把关节外观回归、稠密光流对齐与环状时空结构推理整合成一个可端到端训练的网络，从而在遮挡、模糊及左右对称混淆下获得准确且时间稳定的关节序列。

  • 核心痛点：无约束在线视频常见遮挡、非常规姿态和运动模糊；即使加入单帧骨架空间先验，关节检测仍会出错，逐帧应用还会形成抖动。显式构造空间与时间依赖又会得到大树宽环图，使精确推理不可行。

  • 研究目标：研究目标是在不假定显式人体运动模式的前提下，把关节外观回归、稠密光流对齐与环状时空结构推理整合成一个可端到端训练的网络，从而在遮挡、模糊及左右对称混淆下获得准确且时间稳定的关节序列。
Card 03 核心贡献

核心贡献

  • 提出以环状时空图刻画视频姿态一致性的 Thin-Slicing Network：空间边编码骨架关系，时间边借助稠密光流使用邻帧图像证据，而不依赖预设的人体运动先验。
  • 设计可训练的时空推理层，在任意环状图的空间边与时间边上执行近似消息传递，并以 generalized distance transform 高效完成每条弹簧消息的最大化。
  • 把 fully convolutional 关节回归器、flow warping 和高层结构推理置于统一可微架构中，使时空误差能够反向更新底层外观特征，而非把图模型作为独立后处理。
  • 在 Penn Action 与 JHMDB 两个视频姿态基准上同时对比纯 ConvNet、仅空间推理和既有方法，并通过独立训练、移除推理层及改变时间连接范围分析联合时空训练的作用。
Card 04 方法描述

方法描述

  • 所属模块：Thin-Slicing Network 由三个功能模块组成：fully convolutional joint regression 产生每帧关节置信热图；flow warping 用稠密光流把邻帧热图对齐到目标帧；spatio-temporal inference 在空间骨架边和时间同关节边上聚合消息，生成最终关节位置。
  • 输入与表示：输入是视频的一段 thin-slice，即少量相邻帧。每个身体部位先表示为逐像素 heat-map；图节点对应部位，姿态 p 是各部位在图像空间中的 2D 坐标集合，时间边连接相邻帧中的同一部位，光流提供跨帧对齐位移。
  • 模型结构：结构模型以 G=(V,E) 表示环状时空图：空间边连接相邻肢体并额外连接左右对称部位，时间边连接相邻帧的同一部位；节点一元项来自 ConvNet 外观热图，边上的可学习二次弹簧项编码空间兼容性和时间漂移，所有层纳入同一可微网络。
  • 数据流：数据流依次为：相邻帧进入共享的全卷积回归层，得到各帧各关节的初始热图；计算邻帧稠密光流并沿轨迹移动置信值，把邻帧热图对齐到目标帧；当前帧热图与对齐热图共同进入时空推理层；空间与时间边迭代传递消息后输出每帧最终关节坐标。
  • 关键技术：近似推理采用 Max-Sum 式 loopy belief propagation：每个节点同时沿所有边双向广播消息，用 generalized distance transform 以关于候选位置数的线性复杂度完成对子节点位置的最大化；前向保存最优位置，反向以次梯度只沿该位置传播。实验默认进行三轮消息传递。
  • 公式与超参数：单帧得分为 S(I,p)=Σ_i φ_i(p_i|I)+Σ_(i,j)∈E_s ψ_ij(p_i,p_j)，其中 ψ_ij=w_ij·[Δx,Δx²,Δy,Δy²]^T；片段目标再累加光流对齐后同一关节的时间弹簧项。训练先以 l2 热图损失预训练，再以 hinge loss 联合训练；输入为 368×368 px，thin-slice 为 5 帧，batch 分别为 20 和 6，学习率分别为 0.0005 和 0.0001，dropout 分别为 0.5 和 0.7。

数据集与资源

  • 数据集：Penn Action：含逐帧人体关节位置与遮挡标签的无约束动作视频基准。
  • 数据集：JHMDB：提供全量版本及完整人体均在画面内的 sub-JHMDB 子集，用于视频姿态估计。

Card 06 评估与结果

评估与结果

  • 评估基准：Penn Action 原始训练/测试划分上的视频人体姿态估计测试集。
  • 评估基准：JHMDB 三个官方划分的全量集平均结果，以及完整人体均在画面内的 sub-JHMDB 子集。
  • 评估指标：PCK：若预测关节落在 α·max(h,w) 的真值半径内即判为正确，汇总为关节检测准确率；准确率越高越好，α 越小则判定越严格。
  • 评估指标：主结果采用 PCK@0.2；full JHMDB 还报告更严格的 PCK@0.1，Penn Action 另绘制 accuracy–normalized distance 曲线。
  • 对比方法：内部对照包括纯 fully ConvNet baseline、只在单帧使用空间消息的 S-infer，以及同时使用空间与时间消息的 ST-infer；外部对照覆盖 N-best、Joint Action Recognition/Pose Estimation、Pose for Action 和 Chained Predictions 等视频姿态方法。
  • 关键结果：Penn Action 的 PCK@0.2 平均值为 96.5，高于 pure ConvNet baseline 的 87.0、S-infer 的 91.4 和表中最佳既有方法 Chained Predictions 的 91.8（表内数值单位为百分比点，越高越好）。
  • 关键结果：full JHMDB 的 PCK@0.2 平均值为 81.6，高于 baseline 的 70.9 与 S-infer 的 76.5（表内数值单位为百分比点，越高越好）。
  • 关键结果：在更严格的 full JHMDB PCK@0.1 下，ST-infer 平均值为 68.7，高于 baseline 的 54.5 与 S-infer 的 60.2（表内数值单位为百分比点，越高越好）。
  • 关键结果：sub-JHMDB 的 PCK@0.2 平均值为 92.1，高于 baseline 的 82.3、S-infer 的 86.9 和表中最佳外部对照 Pose for Action 的 73.8（表内数值单位为百分比点，越高越好）。
  • 消融实验：在 Penn Action 上冻结卷积层、只训练时空推理参数时，PCK@0.2 平均值为 92.8；完整联合训练为 96.5，说明联合优化优于独立训练（单位为百分比点，越高越好）。
  • 消融实验：移除已联合训练模型的时空推理层、仅保留经过联合反传更新的 ConvNet 时，平均值为 91.0，相比独立训练 baseline 的 87.0 提高 4%；这表明联合误差反传也改善一元回归器。
  • 消融实验：把时间边从相邻一帧扩展到跨两帧时，Penn Action 的 PCK@0.2 平均值为 96.4，而标准 ST-infer 为 96.5，作者报告没有显著提升（单位为百分比点）。
  • 实验条件：所有结果都是带关节标注的视频数据集上的监督、离线评测：Penn Action 使用原论文约对半的训练/测试划分，JHMDB 对三个官方划分取平均；完整模型先预训练 fully ConvNet，再在 thin-slice 上联合训练 flow warping 与时空推理，并非零样本、闭环机器人或实车测试。
