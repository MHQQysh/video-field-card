Test-time Correction: An Online 3D Detection System via Visual Prompting

Hanxue Zhang、Zetong Yang、Yanan Sun、Li Chen、Fei Xia、Fatma Güney、Hongyang Li

OpenDriveLab / HKU连续视觉检测在线测试时校正视觉提示
原文 · AlphaXiv PDF

原始摘要

This paper introduces Test-time Correction (TTC), an online 3D detection system that rectifies test-time errors using auxiliary feedback. Existing detectors receive an Online Adapter, a prompt-driven query generator. Image-based visual prompts arise from mismatches with 2D detections, road descriptions, or user clicks. Prompts from risky objects are maintained in a buffer to enable continuous correction in future frames. Experiments report improved instant error rectification under limited labels, zero-shot settings, and adverse conditions.

论文概述

让在线三维检测器把当前反馈写入视觉提示缓存，在后续帧持续修正高风险目标。

核心贡献

TTC 为冻结三维检测器增加 Online Adapter，把辅助反馈转成图像式视觉提示，并通过提示缓存让一次纠错延续到未来帧。

方法描述

系统从二维检测不一致、道路描述或用户点击构造高风险目标提示；提示驱动查询生成器修正当前检测，同时写入缓存供后续帧再次检索。
